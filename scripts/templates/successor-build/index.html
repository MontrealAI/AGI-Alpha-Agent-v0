A few clear answers.

Have I created Specialist ASI?

You have built a reproducible candidate example. Specialist ASI is a mission-bounded designation earned through independent comparative proof. SUCCESSOR Ω additionally requires separate accountable admission. This workshop grants neither.

What do I own?

You control your downloaded files, mission notes and results. The included Alpha code is Apache 2.0 and the AGI Jobs compiler is MIT licensed. Third-party rights remain in force. Exclusive IP, legal ownership of commissioned work and provider portability must be established separately.

Where are the neural models?

This first example uses deterministic code so you can inspect every result. A neural-symbolic successor may add replaceable models and executable world programs through separately bounded jobs. It still needs the same mission, evidence, costs, rollback and admission checks.

How does this relate to the four SUCCESSOR Ω guides?

It makes their common cycle tangible: select a reversible mission, constitute bounded jobs, form and freeze a candidate, compare it, preserve useful evidence, and keep admission separate. Public browser cases are a teaching Gym; they cannot substitute for protected independent evaluation.
