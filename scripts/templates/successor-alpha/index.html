    A few things worth knowing.

    What can I do for free?

    Run the included example or your own bounded public CSV catalogs, inspect all results and download the capability, report and workspace. This browser mission uses no model API and requires no account or wallet.

    What counts as Alpha here?

    You receive usable reconciled data and a reusable capability. Compare every method on your actual workload. Those results help assess an Alpha opportunity; independent superiority and realized economic value require further evidence, including integration costs and human effort.

    What do I keep?

    You control the files you download: a workspace, reusable code, inputs, output and project history. Included code is Apache 2.0. Input rights and any rights in commissioned or third-party work remain yours to establish.

    Does this certify Specialist ASI or authorize deployment?

    No. This is a working, bounded local demonstration. Independent evaluation on protected fresh work and explicit accountable authorization are separate steps. The Gym develops capability; it does not certify it.
