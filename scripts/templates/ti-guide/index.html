An identifying column names the same item in both lists, such as a product code. Repeated identifiers are kept; every matching pair is compared.

CSV means comma-separated columns with a header row. Identifiers and values match exactly, including spaces, case and number formatting. Only other columns with identical names are compared. Up to 32 columns, 4,096 characters per cell and 10,000 matching pairs.

This edition compares lists. It does not run free-text tasks, use a live language model, or decide which source is correct.

LOCAL PROCESSING · NO UPLOAD
Show how this works

This guide uses AGI ALPHA’s released catalogue comparison and discrepancy grouping code. Exact string matching and deterministic rules run in a local worker. All conflicting pairs and unmatched rows remain traceable. Source row numbers count data rows after the header, not physical text lines.

Columns with different names are listed as unexamined. Duplicate identifiers produce all matching pairs within the limit. No fuzzy matching, automatic edits, external review, payment, or native Harness/Fleet execution is performed. CSV exports prefix formula-like cells with an apostrophe; the workspace retains exact inputs.
