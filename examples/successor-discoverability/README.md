## One operating path

From the Alpha repository root, with Node installed:

```sh
node examples/successor-discoverability/build.mjs
node examples/successor-discoverability/run.mjs discoverability-output-new
```

The output directory must not already exist. Defaults run 1, 10 and 100 heterogeneous missions for each of three treatments, then bounded failure and recovery controls. The runner verifies the exact imported source closure before measurement and writes raw observations, representative workbench packs, a report, an execution-source manifest and a hash-chained event history. It requires no wallet, credentials, package download or paid service. The inputs are explicitly synthetic.

To use the interface, open the generated `docs/research/discoverability/index.html` in an environment whose browser policy permits the file, or through the repository's existing reviewed publication route. Choose a mission, construct the measurement program, acquire synthetic observations, inspect the decision and costs, then change the requirement or nuisance model. The page is one self-contained HTML file with its exact source closure embedded; it does not call an unavailable backend or execute settlement. Static file generation and module controls were tested. Actual desktop/mobile browser QA was blocked in the supplied browser environment and remains unqualified.

Stop cancels at bounded checkpoints. Session exports preserve completed and interrupted acquisition records. Restoring an export verifies its integrity and bindings, redecodes observations and remains inert: it grants no execution, financial or admission authority. The cache is bounded to eight entries and lives in memory. Restart rebuilds it; exported evidence is not native durable enterprise recovery.

## What is constructed and inherited

The input lists finite possible worlds, the required decision in each world, primitive channel equations, an additive nuisance matrix, bounded read errors and a finite integer contrast grammar. The compiler searches for weights that cancel every declared nuisance column and then finds the minimum static acquisition-cost set that separates all incompatible decisions. It does not discover the forward model or its physical truth.

The productive asset is a source-bound experiment program with a decision certificate, plus a reusable structural template library. A successor reuses structural construction only when the nuisance matrix, grammar and channel structure match. It recomputes world responses, decisions, separation and cost. Problem identities, observation bounds and budget remain checked.

Three mission families use different forward models:

| Family | Useful modeled decision | New construction |
| --- | --- | --- |
| Digital diagnosis | Retain a logic module or choose the required replacement | Contrasts separating executable gate responses despite offset/drift |
| Synthetic mixture disposition | Decide whether a mixture meets a declared composition requirement | Contrast programs for a two-component, four-band assay |
| Held-out network diagnosis | Choose a route, then identify a degraded edge and its severity | Path measurements under clock nuisance; a larger contrast grammar after quadratic drift invalidates the parent |

The network family was authored by a separate agent after the compiler freeze. This supplies implementation separation within one research effort, not an external independent validation. Replaying the now-public family does not reproduce its original withholding.

Raw observations accept integers or exact `{numerator, denominator}` pairs. Comparisons use BigInt rational arithmetic. Fresh readings are acquired only for nonzero weights. Each experiment receives new bounded errors; their Cartesian uncertainty does not require a probabilistic independence claim.

Touching measurement intervals are ambiguous. Complete finite-grammar failure returns `UNIDENTIFIABLE_WITHIN_GRAMMAR` with an overlap witness. Budget exhaustion is inconclusive and never becomes a negative scientific result. A too-expensive optimum remains `OVER_MISSION_BUDGET`.
