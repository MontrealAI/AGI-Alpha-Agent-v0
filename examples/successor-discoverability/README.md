# SUCCESSOR Omega: Discoverability Compiler (experimental candidate)

This additive capability constructs bounded integer measurement programs from authorized primitive channels.
It verifies the **required decision**, rather than accepting a good fit to an insufficient observation interface.

## Current boundary

This is a new, isolated source candidate at the released Alpha workbench extension seam.
It is not a replacement for Foundry, the six-stage Discovery Lab, thermal PR #4871,
or the native enterprise harness. The #4855 source lease and #4863 restriction remain intact.
Nothing here changes a runtime registry, release pipeline, settlement contract or admission rule.

The compiler and development-domain acquisitions execute synthetic finite models.
A compiled program is a proposal requiring review, not an independently accepted capability.
No customer demand, commercial proceeds, physical instrument or live settlement is established.

## Model and construction

Each permitted channel has an integer predicted signal, a positive acquisition cost and a bounded noise radius.
The model lists finite latent worlds and the beneficiary's required decision in each world.
Shared additive nuisance is represented by a channel-by-nuisance integer matrix.

The compiler enumerates primitive bounded integer weight programs, cancels every declared nuisance column
exactly and selects the cheapest robustly separating program set within the complete admitted grammar.
Every experiment acquires **fresh independent bounded-error readings**. Reusing one noisy acquisition across
experiments would change this contract and requires new analysis. Signal and nuisance equations are supplied
model assumptions, not discovered physical laws.

Two world decisions are separated only when at least one complete measurement interval is strictly disjoint.
Touching intervals remain ambiguous. A refusal includes an overlapping-transcript witness for an incompatible
pair within the finite grammar. It is not impossibility outside the grammar or evidence that the real world is
inside the model. Exhausted construction/search returns BUDGET_EXHAUSTED, never a completed negative result.

The decoder recomputes the program's scope, nuisance cancellation, response bounds, cost and decision separation
before using newly supplied observations. Ground truth belongs only to the synthetic evaluator.

## Development missions

- Digital module diagnosis derives response signatures from executable XOR/AND/OR/NAND/stuck-output functions.
- Mixture disposition derives response signatures from a two-component, four-band synthetic forward assay.
- A third inverse-domain mission is reserved for independent reveal after the compiler freeze.

The same construction grammar is available to conventional optimal-design baselines. Ties and losses are valid.
Resource units are acquisition counts weighted by the declared task costs, **not US dollars**.
The cached strategy reuses only immutable structural experiment templates; targets and responses are recomputed.
The fresh strategy reconstructs them. Restart loses that in-memory cache. It does not replace durable runtime history.
