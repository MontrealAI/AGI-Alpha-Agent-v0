# Public operator-preparation reading card

This pilot produces an inspectable, fixed three-clause reading card from actual
public Manager operator documentation. It executes the existing native source
selector, all four credible controls and an independent source/coverage checker.
The selected exact passages can help an operator locate guidance about pre-key
build validation, hidden local key entry and outstanding signed capabilities.
Read the complete linked guide before any operation. The card is a documentation
reading aid; it grants no signing, execution, ENS, funding or activation authority.

The source snapshots come from public Manager commit
`8b0cf7fbc09e48ffe55d8ed35df8cd40920231d2`. Their raw hashes and immutable URLs are
in `input.json` and independently pinned in the reproduction driver. Excerpts
collapse whitespace only. Priorities and prerequisite edges are local review
judgments. Source fidelity is checkable; reader usefulness and comprehension are
not calibrated by these annotations. Two preselected documentation excerpts are
not independently sampled research campaigns.

Run from a reviewed source checkout with the locked runtime dependencies:

```sh
python -m scripts.reproduce_public_preparation_pilot --state /absolute/new-pilot-home --output /absolute/new-public-evidence.json --approve-free-local-pilot
```

The JSON contains the card in
`native.result.results.candidate[0].text`, original references, all five development
attempts, terminal baselines, separate independently recomputed checks and actual
reopen/import evidence. No manual artifact rewriting is necessary. The independent
import must contain the complete original validated envelope and null authority;
a failed import cannot count as successful history recovery.

For clean-package qualification, install the built wheel into an isolated
environment, leave the checkout and invoke this driver by its absolute path.
Its fixture directory remains a source-evidence input; the runtime then resolves
from the installed package. Bind the resulting report to that wheel's digest and
exact source commit. The included `retained-run.json` is a real source-checkout
run and does not stand in for this final installed-package qualification.

The retained deterministic result is narrow: the constructed method's structural
score is 684,210 millionths, equal to unrestricted exact search. Audit-after-draft
and weighted selection score 500,000; lead order scores 26,315. These values
measure the supplied prerequisite graph, not safety certification, market value,
reader understanding or general discovery ability. Local reuse remains pending
independent review. A different public input or model can yield no improvement;
that outcome must remain visible.

## Optional actual local model

Supply an explicitly reviewed `LocalModelConfig` from
[the existing local-model guide](../LOCAL_MODEL.md):

```sh
python -m scripts.reproduce_public_preparation_pilot --state /absolute/new-model-pilot-home --output /absolute/new-model-evidence.json --approve-free-local-pilot --model-config /absolute/local-model.json
```

The model sees development clauses only, proposes closed native selection
programs, and cannot rewrite the charter, evaluator or confirmation set. One exact
model-call approval and separate native execution approval are recorded. The
supplied explicit free-pilot flag approves this bounded test run. Local billing
is an operator attestation; remote and paid providers remain unsupported.

The existing mandatory `agent-release.yml` real-model job now calls
`scripts.validate_agent_model --with-ti-public-pilot` inside its checksum-pinned
llama.cpp/Qwen3-4B session. That job reuses the real loaded weights, model revision
and actual provider provenance. Its full candidate/source record is retained in
`real-inference.json`. A timeout or rejected proposal consumes its permit, emits
sanitized `ti-public-pilot-failure.json` and fails the job; the test does not retry
until it obtains a favorable answer. No model advantage is required for passing
software acceptance. HTTP contract-fixture tests are labeled fixtures and cannot
replace the real-weight job.

The real-weight job has not been run in this local environment: the server binary,
weights and local socket support are unavailable here. Hosted acceptance must
complete on the exact final commit before publication; no live-model result is
claimed by `retained-run.json`.

## Costs and limitations

Every proposal attempt and terminal comparison has logical work costs. The report
also measures discovery phases, construction/evaluation, terminal controls,
independent checking, total wall time and process CPU time in integer
microseconds. Actual independent history import/reopen is included in total time.
The retained run took approximately 0.20 seconds; this is one machine observation,
not a speed guarantee.

The cost record explicitly includes unknown maintenance, human effort, device
energy and hardware amortization. There is no monetary break-even or whole-life
profitability claim. The pilot performs no chain operation and all currency
allowances remain zero. General formulation invention, calibrated reader benefit,
statistical Level 3/4 superiority and organizationally independent review remain
unestablished. The original paper, companion artifacts and public link are
unchanged.
