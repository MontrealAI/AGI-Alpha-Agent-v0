## Installed extension boundary

`OperatorRegistry.register()` accepts installed trusted pure Python operators. Before approval it binds actual source, callable bytecode, nested code constants, JSON instance/class configuration, defaults, keyword defaults, closure values and referenced JSON configuration. Unsupported captured state and unknown helper callables are rejected. This is a reviewed host-code interface, not a sandbox for untrusted plugins. Imported source text and JSON never select executable host code. Credential-shaped content is rejected before retention; public-source confirmation and human judgment remain necessary.

The supported pilot has no model calls, wallet, token allowance, signing or network execution. Its `USDCBaseUnits`, `AGIALPHABaseUnits` and `money_minor` limits are all zero. The existing runtime's separately configured model suppliers, Computer Use execution and payment integrations retain their own qualification and authorization boundaries.
