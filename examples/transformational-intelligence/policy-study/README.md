# Learning a bounded discovery policy across complete campaigns

This example selects **how to search for a summary method**, then freezes that discovery policy before running new complete campaigns. A whole campaign includes development, construction, finalist selection, freeze and terminal evaluation. Individual clauses are not counted as independent experimental units.

The three installed policies are unchanged enumeration of all operators, direct exploration of a complementary representation/production pair, and a fixed-frame control. Each starts from the same lead selector with no archive, the same charter, tools, permissions, budgets and structural instrument. The training objective subtracts a declared logical search cost from the terminal structural score. Selection cannot change the user's goal, fixed artifact, evaluator, access or currency caps. Ties retain the incumbent policy.

The JSON inputs are explicitly **constructed public fixtures**, with two training campaigns and four separately supplied confirmation campaigns. The last confirmation campaign is a rejection case where the fixed frame already has the best summary. They are not externally collected release notes, independent reader experiments or hidden test data. Known normalized clause reuse is rejected across study, ordinary native, model, imported and archived records in the same Journal. Semantic independence and custody require outside process evidence. There is no calibration or statistical promotion claim.

From an installed or prepared Alpha checkout, use absent paths outside the repository:

```sh
PYTHONPATH=. python scripts/reproduce_transformational_study.py \
  --spec examples/transformational-intelligence/policy-study/spec.json \
  --training examples/transformational-intelligence/policy-study/training.json \
  --confirmation examples/transformational-intelligence/policy-study/confirmation.json \
  --state /ABSOLUTE/PATH/new-study-journal \
  --output /ABSOLUTE/PATH/new-study-evidence.json \
  --approve-free-local-study
```

The explicit flag approves only this bounded free local study. The script opens the confirmation file after freezing the learned policy. All native campaigns, unsuccessful/inconclusive comparisons, full comparator outputs and actual logical charges remain in the signed private Journal. The evidence export contains child records, never its signing key. It grants no execution, payment, publication or method-library promotion authority.

For manual review and control, `alpha-agent --home PATH successor-study --output NEW.json create SPEC.json` proposes a binding. Separate `approve`, `train`, `confirm`, `pause`, `resume`, `cancel`, `show` and `export` actions retain their history. Parent pause and cancellation are checked inside native transactions, including ordinary native API calls. Cancellation is terminal; an uncertain process interruption can resume only the same reserved batch and exact source. Duplicate training cannot reset a terminal comparison.

The observed comparison is bounded Level 3 policy-selection engineering in this declared finite family. It does not establish general learning-to-discover, model advantage, reader benefit or escape from an unknown ceiling. The unrestricted exact selector remains a strong within-campaign control. Search and execution units and elapsed time are retained; construction, migration, maintenance, device energy and human effort remain unmeasured. Economic break-even is not established.
