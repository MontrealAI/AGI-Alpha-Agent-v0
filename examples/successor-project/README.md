Changed saved input creates another new cycle; previous exact bytes, failures and rejected reviews are retained, and dependent evaluations are stale.

## Identity and storage

Each project has an opaque ID, monotone revision, digest and cycle chain. Each cycle has a separate ID, parent-cycle digest, native artifacts and explicit mapping. Native schemas are not modified. Links use exact UTF-8 SHA-256, distinct from the native domain-separated hashes; neither establishes authenticity. Source pins identify the bundled validator implementation, not an authenticated producer. The generator verifies native file hashes pinned to exact remote commit `021b3337de07e9a0cdd105fac967a0dc650de122`; both file contents were independently retrieved through the repository connector and compared. Different source identities are historical until a fresh cycle explicitly rebuilds the planning brief and selects the native task under current code.

IndexedDB saves validate before mutation, then compare the entire validated prior snapshot inside a single readwrite transaction. Stale same-project imports cannot overwrite a newer record. Conflicting or failed UI saves retain an exportable read-only copy. Restoring is not automatically a save.

The shared strict codec limits a dossier to **2 MB**, 8 cycles, 24 native snapshots per cycle and 64 history events. Limits fail closed without deleting older failures. Before committing a run start, the engine validates a prospective maximum-reason interruption snapshot, reserving a recoverable stop even if output is too large. At capacity, export the unchanged dossier and retain it; a new cycle is possible only within remaining aggregate/cycle capacity. No pruning or overwrite is automatic.

The existing 21 Job lifecycle templates produce **unfunded proposals** linked to exact current evidence. Principal, reviewer, budget, expiry and protocol are unset. Manager/USDC and JobRegistry/AGIALPHA remain separate unavailable commissioning routes; Fleet has no accepted execution envelope or grant. No protected cases, credentials or secrets belong in this general browser dossier.
