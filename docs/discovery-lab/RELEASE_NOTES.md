materials-testing mission. Visitors can change measurement accuracy, intended uses, observations,
operations, memory, worker placement, fault hypotheses, checkpoints and resource budgets. Those

## Qualification scope

The model has three or four binary controls and bounded, supplied construction grammars. Acquisitions,
logical operations, encoded bytes, virtual workers and observed local elapsed time are separate units.
The report distinguishes constructor work, independent checking, recurring uses, successors and the
whole retained history. Public seeds are reproducible regression cases, not protected holdouts.

Exact-source tests, configured public review and CI, reconciled baselines, native source/runtime
qualification, release packaging and actual public acceptance must all identify the delivered version.
Until those gates pass, this remains a source candidate. No physical material result, general invention,
industrial deployment, revenue, token value, external execution or spending is established.
