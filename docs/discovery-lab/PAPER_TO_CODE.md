## Research contract

The new campaign is a finite synthetic workcell. Supplied semantics, primitive
operations, construction grammars and task families are inputs. Measurement
programs, reasoning interfaces, joint realizations, conditional policies,
boundary contracts and platform constructions must be computed outputs. The
purpose, evaluator and grammar are frozen before construction. A stronger
successor receives a new charter revision while preserving old obligations.

The papers' numerical results have different assumptions and units. None of
their headline counts or savings is an end-to-end result of this campaign.
Independently implemented finite checkers provide software evidence. They do not
establish physical validity or external scientific peer review.

## Mechanisms that must remain explicit

### Measurement and uncertainty

The revised Out-Learn model is `y = g * polarity * response + polynomial drift + error`.
The signal is constant within a block; gain is positive and stable across the
qualified reference/use scope; drift coefficients can change between blocks.
Those are supplied simulator assumptions, not discoveries by the constructor.

For degree `d`, the paper supplies an exact finite program grammar of `d+2`
readings. Barycentric weights are normalized to have unit response and zero
moments through degree `d`. Every emitted program must check those equations.
Program cost charges readings, internal polarity changes and last sample time.
Calibration and use are selected together using the intended number of uses.
An insufficient search cap means **inconclusive**, not proven infeasible.

Raw reference evidence yields a gain interval. Each query yields a feasible
response interval and a checked error bound. Passing that result to reasoning
cannot turn an ambiguous threshold into an exact answer. A changed drift degree,
gain, reference or measurement scope invalidates the corresponding bridge.

### Executable reasoning and actual released capacity

A decoder is only qualified on its admitted contexts. Updates receive the current
code and operation, without hidden source access. Every modeled state must satisfy
`update(encode(state), operation) = encode(operation(state))`.
Pairwise compatible states do not automatically form a valid merged partition.
A static coloring of future conflicts does not automatically supply an updater.

Re-encoding a retired representation requires retained sufficient source evidence
or paid new observations. Source archive bytes and access are not free because
the active label is small. Additional operations can erase compression benefits.

Joint service execution must preserve each service on independent inputs. Worker
savings must come from the emitted realization and its counted resources. A
vacancy must have an actual admitted route to the installation site. Every phase
retains service availability; an empty-worker icon is not a release certificate.

### Planning, reusable execution and stronger successors

Out-Strategise's deferred-construction result assumes nondestructive tests of the
unchanged plant and no earlier benefit, deadline or observation from preparation.
A workcell where installation enables a test needs the current installed state
in the search. Its compiler cannot reuse that normal form without those premises.

Out-Execute profiles contain every boundary assignment, including infeasible
entries, with a current attaining witness for every finite entry. A factor
touching two private groups invalidates an unexpanded decomposition. Equality of
one selected optimum is insufficient for universal reuse. Full profile equality
can retain an outside decision while requiring a different current local witness.

The revised Out-Evolve response-class result is conditional on the constructed
composition and readout. A higher-order monomial can vanish at every low-Hamming
calibration point and still violate the model elsewhere. The small workcell must
establish its structure from full supplied semantics and independent finite
checks, and charge that qualification separately from calibration.

For a compatible new control, the old response at the new control's zero setting
must remain identical within the declared interval contract, and the interaction
bound must remain valid. Merely preserving control names is insufficient.
Nonzero calibration error must be propagated through subset inversion; a compact
coefficient vector is not an exact response oracle. A failed successor leaves
the accepted predecessor usable only within its original scope.

## Qualification and comparisons

The campaign must retain a strong unrestricted planner with the same primitives,
fixed architecture with more search, full-state reasoning, separate service
realization, full and no diagnosis, full recomputation, equally capable
incremental contracts, fixed certificates, and successor from scratch.
Ties and cheaper accepted competitors are valid outcomes. Each stage needs a
negative control and an ablation; no requirement says each stage must help every
fixture. Public seeds are reproducible regression inputs, not protected holdouts.

The resource account distinguishes acquisitions, search/compilation/checking,
memory/storage, worker use, installations and measured elapsed time. Cold start,
recurring use, amortization, successor increment and cumulative lineage totals
must remain separate. Failed candidates, independent checks and requalification
are charged. Inherited construction is charged once in cumulative lineage cost.
Synthetic currency caps remain zero.

Manager USDC and Jobs AGIALPHA are alternative routes for one logical commission.
Receiver admission and executor competence need exact schemas, source/runtime
identities and resource/verification coverage. A draft remains unsubmitted.
An unprovisioned executor remains unprovisioned. Local synthetic replay,
qualified local execution and real external execution require distinct labels.
