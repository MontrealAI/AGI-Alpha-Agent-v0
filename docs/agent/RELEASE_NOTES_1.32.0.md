# 1.32.0 — Inspectable work and supplied-input journeys

This additive release candidate combines the Nova-Seed recovery experience with explicit
Jobs/Fleet compatibility, native execution controls and original demo workspaces. A source
version is not publication: the exact release manifest, successful acceptance run, uploaded
checksums and matching public-site record identify the delivered build.

## Included capabilities

- Recoverable Studio journeys, bilingual controls, preserved reading preferences and the
  purple homepage; original research narratives and flowcharts remain available.
- Atomic native shared-budget reservations with revision and identity binding, terminal
  recovery capacity and fail-closed disconnected behavior. Reservations constrain this
  coordinator's planning; they do not prevent arbitrary external wallet transactions.
- Read-only receipt-bound principal-return attribution, explicit unknown costs and per-edge
  evidence. No unsupported profit or productivity outcome is inferred.
- Separately selectable JobRegistry v2 `$AGIALPHA` adapters, exact source/profile/assignment
  admission and signed artifact commitments. Historical MARK routing remains unchanged.
- An unsigned WorkSpec editor with exact UTF-8 commitments, bounded validation and local
  export. Producing a file does not assign a job or authorize execution.
- A separate supplier-browser adapter and English/French native operator workspace: explicit
  admission, preparation, start, STOP/reconciliation, deterministic output checking, separate
  review and signed export. Loading the page or importing a file does not call a provider.
- Original cross-industry and Business2 browser workspaces over supplied assessments and
  observations, deterministic explanations, exact commitments and recoverable evidence.
- Business1 supplied-state evaluation with authenticated input-bound HTTP/bridge results,
  explicit pending external actions, input-dependent AIGA local plans and validated OMNI city
  fallback. Offline notebook exports reopen in their original browser workspaces and recompute.
- Macro scenario input sensitivity, common tail metrics, bounded allocations and unsigned
  draft quantities that remain zero for zero/sub-contract inputs.
- MiniWorld oracle-supervised initial/recurrent objectives and strict CPU qualification gates.
  Actual learning/search is qualified only when all pinned CPU tests pass without skips.

## Evidence boundaries

The supplier integration was exercised against a fresh local modular JobRegistry using an
actual fixed Chromium worker and scripted provider-shaped responses. The reviewed artifact
was submitted and separately approved/finalized by test fixtures; a wrong-delivery-limit
browser run was rejected before export. This establishes that laboratory path only. Docker
commissioning, paid/live model behavior, real token settlement and independent external
security review remain separate gates. Provider costs remain unknown where usage/invoices
are absent. Synthetic token payouts and scripted setup savings are not user income or
measured human time savings.

The Fleet runtime retains its explicitly pinned executor source and its own qualification.
Compatibility with this release must be checked against exact canonical fixtures; a shared
token or deployment manifest alone never enables an adapter. Public Pages explains and
runs static/local computations; native execution requires a separately running local agent.

The 80-case product catalog and 26-entry demo inventory are coverage maps, not claims that
all operational requirements or external-resource gates have been satisfied. Release evidence
must distinguish passed engineering checks, optional dependency skips, unsupported paths and
live/provider/human-study work that has not been commissioned.

## Breaking Changes and upgrade notes

- Legacy cross-industry discovery calls now require an explicit supplied-input, sample or
  provider-generation mode; no implicit canned result is returned. Queue errors exit clearly.
- Business2 service planning/research requires a valid `BUSINESS2_INPUT` file and returns
  structured computed results inside the existing topic envelopes. Commentary is opt-in.
- Macro scenarios reject nonfinite, oversized or out-of-range inputs. Aggregate path-steps
  are capped at 2,000,000. Draft orders disclose assumptions and never invent a minimum trade.
- Legacy bodyful trigger requests are rejected instead of silently dropping the payload.
  Business1 callers use the explicit evaluation endpoint with a complete supplied state;
  score-only jobs cannot be treated as executed business work.
- MiniWorld training targets and reward architecture change; old research weights should not
  be treated as qualified checkpoints for the repaired learner.

No deployed contract, wallet authority, token conversion or production trust profile is
silently changed. Retain private recovery files and review the native adapter guides before
using separately configured services.
