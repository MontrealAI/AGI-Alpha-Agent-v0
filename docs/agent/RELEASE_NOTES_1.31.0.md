# 1.31.0 candidate — Nova-Seed Mainnet Studio

The additive [Nova-Seed Studio](../ascension/mainnet/index.html) connects project preparation to
the shared MARK wallet. The original Ascension Lab, Protocol Desk, native workflows, SUCCESSOR Ω,
historical contracts and deployment archive remain available.

- Author exact verifiable jobs, compile their indexed FusionPlan, encrypt the complete executable
  package with the existing capsule format, test decryption and retain a portable Recovery Kit.
- Review public fields, publish encrypted capsule/evidence/metadata through the session-scoped
  storage adapter or verify an existing publication, then bind the package to its deployment.
- Prepare wallet-managed mint, review, funding, activation and routing transactions with the shared
  transaction journal, explicit consent, simulation, current-state checks and receipt verification.
- Resume existing seeds and interrupted transactions; keep ownership, campaign authority, job
  delivery, runtime connection and settlement as separate observed states.
- English/French guidance, larger text, keyboard navigation and mobile layouts share one guided route.
- Current-source local EVM tests and browser acceptance supplement all existing release gates.
  Evidence binds the actual source/assets; fixtures and operational-mainnet observations remain separate.

The October 11 suite is immutable and remains closed to new exposure. This release does not deploy
replacement contracts, change governance, grant admission, authorize funding or establish a live canary.
No qualified mainnet write profile is included. The release manifest records the exact tests that ran;
physical wallet/mobile/hardware trials, an external storage-account trial, independent security review,
real-dependency fork evidence and separately authorized mainnet commissioning remain distinct obligations.
