## What changes

- Strict versioned protocol objects and domain-separated canonical commitments bind missions, exact
  releases, comparators, examination conditions, work terms and accountable decisions.
- The offline public technical mission measures streaming metrics aggregation with constructed bounded
  challengers, a competent incumbent, alternatives, WORLD predictions and explicit correctness gates.
  Negative results, retaining a better alternative and missing external evidence remain useful outcomes.
- The native lifecycle adds durable institution state, atomic shared resource reservations, attributable
  decisions, scoped action-time grants, revocation, impairment, permitted memory and successors whose
  proof and authority begin empty. The existing native signed journal format is preserved.
- The Ascension adapter distinguishes indexed plan leaves from the market's zero-index Spec hash and
  binds richer sealed terms to the observed assignment. Useful negative evaluation can be accepted and
  settled without admitting its candidate. Existing $AGIALPHA economics and Solidity meanings remain.
- The English/French browser rehearsal uses fixed bounded engines and carries a validated request to the
  installed CLI. Returned evidence is bound to the original request and separately retained trusted key.
- Distribution uses a small native core and bounded browser/site packs. Every published file is checked
  against the **450,000,000-byte** limit, with original content retained and safely reconstructed.

## Installation, upgrade and rollback

Use the matching release wheel, `requirements-agent.lock`, `SHA256SUMS` and `install_agent.py` to create
a **new** environment. The guide's first offline rehearsal requires no wallet, account, API key or model
weights. Arbitrary generated-code execution retains explicit Docker opt-in and has no host fallback.
For browser/site packages follow the [pack restoration instructions](SUCCESSOR_PACKAGING.md).

Pause the old agent, verify and privately back up its state, and retain its independent checkpoint.
Keep the old environment and state directory. Run the candidate with a new home and restore only through
the documented explicit workflow. Portable institutional knowledge exports exclude operational grants
and private signing credentials; they are different from private disaster-recovery backups. Do not run
two serving versions against one home. To roll back, stop the candidate and restore the previously
verified backup into a separate home using the retained previous environment, then reassess permission.

cache upgrade, exact baseline preservation and bounded distribution round trips. Public acceptance
must identify the exact same commit and version as the packaged bytes before publication.

Read the final validation evidence and requirement matrix for actual passes, failures and untested
platforms. Gate definitions do not mean a run passed. A deterministic supplier adapter verifies its
local interface and recovery behavior; it does not establish actual neural execution or frontier
supplier replacement. Distinct local roles/keys are local provenance, not external verifier independence.
Missing external frontier/customer evidence remains explicit, and no mainnet spending, token migration,
ENS mutation, production grant, independent Alpha or Specialist ASI designation is asserted here.
