## Installation, upgrade and rollback

Use the matching release wheel, `requirements-agent.lock`, `SHA256SUMS` and `install_agent.py` to create
a **new** environment. The guide's first offline rehearsal requires no wallet, account, API key or model
weights. Arbitrary generated-code execution retains explicit Docker opt-in and has no host fallback.
For browser/site packages follow the [pack restoration instructions](SUCCESSOR_PACKAGING.md).

Pause the old agent, verify and privately back up its state, and retain its independent checkpoint.
Keep the old environment and state directory. Run the new version with a new home and restore only through
the documented explicit workflow. Portable institutional knowledge exports exclude operational grants
and private signing credentials; they are different from private disaster-recovery backups. Do not run
two serving versions against one home. To roll back, stop the new process and restore a verified backup
into a separate home using the retained previous environment only if the backup satisfies the latest
independently retained checkpoint. Do not erase later revocations or work by choosing an older checkpoint.
If current history cannot be restored compatibly, keep the operator stopped. Follow the
[private recovery procedure](SUCCESSOR_OPERATIONS.md#private-disaster-recovery-same-identity-and-keys)
before reassessing permission.

cache upgrade, exact baseline preservation and bounded distribution round trips. Public acceptance
must identify the exact same commit and version as the packaged bytes before publication.

Read the final validation evidence and requirement matrix for actual passes, failures and untested
platforms. Gate definitions do not mean a run passed. A deterministic supplier adapter verifies its
local interface and recovery behavior; it does not establish actual neural execution or frontier
supplier replacement. Distinct local roles/keys are local provenance, not external verifier independence.
Missing external frontier/customer evidence remains explicit, and no mainnet spending, token migration,
ENS mutation, production grant, independent Alpha or Specialist ASI designation is asserted here.
