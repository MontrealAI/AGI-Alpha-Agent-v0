# Your first useful plan / Votre premier plan utile

**[Start here — open the guided experience](../start/index.html)** ·
**[Commencer en français](../start/index.html?lang=fr)**

No technical experience, account, wallet, payment, installation or AI service key is needed.
This page runs a small planning calculation on your device. It does not perform the tasks for you.

## Three easy steps

1. **Choose.** Enter your available minutes. Keep the four sample tasks or change their names,
   durations and importance points. Use whole numbers: 1–480 minutes and 1–10 importance points.
2. **Review.** Select **Find my plan**. Read the selected and omitted tasks and the minutes remaining.
   The planner compares all 16 combinations and maximizes the importance points within your time.
   Tasks must be independent and fit in full; it does not account for dependencies or interruptions.
   Check your assumptions and tick the review box, or select **Change my choices**.
3. **Keep.** Select **Continue to save**, then **Download my plan**. The text file is easy to read.
   **Save evidence** downloads JSON with the exact inputs, task names and calculated result.
   A checked box records your review; it is not independent verification or permission to act.

The planner does not send task entries to a server, use analytics, save them in browser storage,
connect a wallet or call an AI provider. Hosting still receives ordinary page and asset requests.
Reloading clears your entries; keep the downloaded file before leaving. Other workspaces have their
own storage and recovery behavior, described in the [browser guide](PAGES_GUIDE.md).

## Make yourself comfortable

- Use **Larger text**, browser zoom, or **Français** at the top. These preferences are for this page visit.
- Use Tab and Shift+Tab to move between controls, Enter to activate a button, and Space for a checkbox.
- There is no countdown or automatic progression. Changing a plan clears the previous review and result.
- Error messages name the field to fix. Select the linked message to reach that field.
- If no task fits, increase available time or reconsider the estimates. An empty selection is a valid result.
- If the planner does not load, reload online in an updated browser. The guide remains readable without JavaScript.
- Downloads go to the browser’s Downloads folder; on a phone, use the browser’s download menu or Files app.

## Français

**[Ouvrir le parcours en français](../start/index.html?lang=fr).** Aucun compte, portefeuille,
paiement, téléchargement de modèle ni installation n’est nécessaire.

1. **Choisir.** Indiquez le temps disponible et conservez ou modifiez les quatre tâches proposées.
   Utilisez des nombres entiers : 1 à 480 minutes et 1 à 10 points d’importance.
2. **Vérifier.** Sélectionnez **Trouver mon plan**. Vérifiez les tâches sélectionnées, les tâches omises
   et le temps restant. Le calcul compare les 16 combinaisons; les tâches sont indépendantes et indivisibles.
   Cochez la case de vérification ou choisissez **Modifier mes choix**.
3. **Garder.** Sélectionnez **Continuer pour enregistrer**, puis **Télécharger mon plan**.
   Le fichier texte est lisible; le fichier JSON contient les données exactes et le résultat.

Les données restent sur la page et ne sont pas enregistrées par ce planificateur. Rechargez la page
pour les effacer; téléchargez votre résultat pour le conserver. Le site reçoit les requêtes ordinaires
nécessaires pour afficher la page. Aucun achat, publication ni travail externe n’est effectué.
Le bouton **Texte plus grand**, le zoom et la navigation au clavier sont disponibles, sans minuterie.
Les espaces avancés ont leurs propres règles de stockage et peuvent demander une configuration technique.

## Maintained scope and scale

The first-use experience is static, small and independent of a central inference service. The four-task
calculation has a fixed 16-combination bound. This reduces per-user server work and offers a practical
entry point for a broad audience. It is not evidence of billion-user hosting capacity or a public,
multi-tenant agent service. Capacity planning, regional delivery, abuse controls for future APIs,
additional browser and assistive-technology testing, and real-user usability studies remain separate work.
See [release readiness](RELEASE_READINESS.md) for the supported deployment scope.
