# 1.26.3 — An easier first step and more readable planning

**[Make your first plan](../start/index.html#journey)** or visit the
**[homepage](../index.html)**. The guided example needs no account, payment, wallet or installation.
The [English/French guide](ONBOARDING.md) explains the journey; the [operator start guide](START_HERE.md)
covers a separately installed agent.

## What changes

Make-plan buttons now open the task choices directly, so visitors who are ready can begin immediately.
The general **Start here** navigation link still opens the introduction. Both paths keep the existing
Choose → Review → Keep journey and its language and text-size preferences.

Essential planner instructions, task labels and review text are larger and easier to read. The larger-text
option remains available. Reading controls appear only after the page has initialized successfully.
When JavaScript is unavailable or a required module cannot load, readable guidance remains available
without displaying reading controls that cannot respond.

The planner still compares all 16 combinations of four independent tasks within the available time.
It does not perform tasks, call an AI provider or take external action. Review is still required before
saving a plan; text, JSON, on-page and printable copies retain their existing behavior.

## Acceptance and scope

Browser acceptance covers direct make-plan entry, the general introduction route, essential text sizing,
and reading-control readiness with JavaScript unavailable or module loading blocked. Existing exact-asset,
English/French, preference-history, keyboard, responsive-layout, review and download checks remain required
for both the tested site and public release where applicable. All earlier release gates still apply.

These are acceptance requirements, not a claim that this source revision has already passed. The final
`release-manifest.json` and validation archive identify the tested commit and actual outcomes. Automated
browser checks do not replace usability studies with older and nontechnical participants or establish
comprehensive accessibility conformance. No new user-study or billion-user capacity result is claimed.

This focused update requires no native journal, identity, contract or deployment migration. Original
research, diagrams, media and advanced workspaces remain available. The historical mainnet deployment
and its separate commissioning requirements are unchanged; no on-chain transaction is performed.
See [release readiness](RELEASE_READINESS.md) for deployment limits and [operator recovery](OPERATIONS.md)
for local-agent upgrade and backup instructions.
