# Alpha Agent 1.42.0 — Two lists. A clear next step.

The browser-first `/try/` guide makes one bounded task immediately useful: compare two nonpersonal
CSV lists, inspect real obstacles, test an evidence-preserving action view and download reusable results.
The sample requires one click to compute and three clicks to reach its downloads, with no account,
installation, wallet, payment, model configuration or API key.

The guide reuses the unchanged released catalogue engine and discrepancy resolver. It preserves the
original detailed exceptions alongside one proposed action per affected identifier. All conflicting
field values and source row references remain available. It never assumes either input is correct or
equates fewer action records with time saved, better accuracy or less underlying work.

Action plans and full differences download as spreadsheet-safe CSV. A standalone HTML workspace keeps
exact data and identities, settings, limitations and evidence, rechecks saved results on reopening and
computes a new run when the user supplies different data. JSON restore refuses altered results and
imported authority. Processing remains local, with no analytics or external model transport.

The homepage and README feature **Try it now**. The original flagship, source-understanding experiment,
papers, release history and all original Harness/Fleet restrictions are retained. The 1.41.1 workbench
input snapshot fix remains in the ancestry. No held capability or new external executor is introduced.

The [release installation and first-run guide](START_HERE.md) covers the existing native operator.
The runtime owner's retained first-use concurrency correction also serializes creation/read of the
existing local role inventory within the journal transaction. Concurrent work proceeds after setup;
genuinely incomplete inventories still refuse without replacing keys. The browser guide does not
invoke this native path or create credentials. Public-package concurrency verification remains a
separate recorded acceptance step; the earlier 1.41.1 load failure remains retained.

This source candidate requires its own normal PR review/checks and exact-main release/site acceptance.
The existing homepage validator also tests actual guide downloads, two-file import, evidence coverage,
saved-workspace restoration, changed inputs, negative cases, keyboard flow, EN/FR and phone layouts.
Only matching recorded reports establish which of these checks passed.
