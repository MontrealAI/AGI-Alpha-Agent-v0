# Strategy security and compatibility notes

Use the [connected journey guide](STRATEGY_SUCCESSION.md), [compatibility matrix](FLYWHEEL_COMPATIBILITY.json) and [capability register](FLYWHEEL_CAPABILITIES.json) to distinguish implemented, tested, published, installed and authorized work. These notes claim neither a current repository-policy pass nor publication. Local candidate tests do not grant production approval. Required configured review and exact final-source checks must precede release or operational activation.

The root/core changes and the Strategy companion have separate qualification contracts. The companion's existing profile admits exact public Alpha **1.42.0** bytes in a separate Linux x86_64 environment with CPython 3.12.14 and Node.js 24.22.1; its separately enabled native specialist uses SciPy 1.17.0. A newer root release does not become a supported companion runtime automatically, and root/core repairs are not implicitly present in that older runtime. Preserve accepted installations, check the actual package/profile identities and obtain separate qualification for a different combination. The companion payload, frozen wheel/profile and runtime dependency contract are not changed by these root notes.

Before starting, review the exact prepared input, executor/source identity, separate service and improvement caps, expiry and existing approval scope. Follow the packaged [operator procedure](https://github.com/MontrealAI/AGI-Alpha-Agent-v0/blob/c4a7febc02fb9d607e9da5ece2101c4b6b36fc64/contrib/strategy_succession/docs/operator.md) for Pause, Stop, UNKNOWN recovery and rollback. Closing a browser does not cancel an approved bounded request. Pause fences the next checkpoint; Stop permanently revokes that installed envelope. After a crash, inspect effects and retained receipts, wait for lease expiry when required, and reconcile without replay or refund of unknown work. Preserve the last accepted installation and private operator backups; never rewrite source pins or journal history to restore authority.

The legacy HTTP services default to no cross-origin grant. Set `AIGA_CORS_ORIGINS` or `ALPHA_ASI_CORS_ORIGINS` only for explicitly permitted exact HTTP(S) origins, comma-separated without paths, trailing slashes, credentials or wildcards. Unsafe HTTP requests with unrelated, null, duplicate or malformed Origin fields are rejected before mutation. Same-origin and configured origins are permitted; requests without Origin retain the existing API authentication path. This guard is not authentication or WebSocket authorization. The world-model's read-only WebSocket remains outside the HTTP-CORS claim.

The Flask log UI defaults to `127.0.0.1`; `ALPHA_UI_HOST` is an explicit validated operator bind choice. The code does not change deployed settings or establish safety for remote exposure. `VECTOR_HOST` accepts a bare host/port or exact HTTP(S) origin. External targets default to HTTPS. Plain HTTP is limited to validated literal 127/8, `::1` and exact `localhost`; redirects and credential/path/query/fragment smuggling are refused. A bare service target such as `qdrant:6333` now needs actual TLS. The old plaintext Compose route and live Qdrant operation are not qualified. Transports unable to disable redirects fail closed.

JUnit collection and public verification require `defusedxml==0.7.1` in QA/verifier environments only. Bounded regular-file inputs reject DTDs, entities and external references. This dependency does not alter the companion's existing 26-package runtime contract or qualify arbitrary imported documents. Docker image grammar checks prevent option-shaped operands; they do not prove image provenance, container safety or permission to run Docker.

For Memory Fabric SQLite, stop and close writers and preserve a pre-upgrade backup before the additive schema change. Do not use the old five-column positional writer on the expanded table. After any upgraded writes, stop writers and retain a separate upgraded backup. The tested rollback restores the old snapshot to a separate database path before using the old writer. Keep both histories: later records are not automatically reconciled into the restored database. See [versioned legacy identities](LEGACY_CONTENT_IDENTITIES.md) for conflict handling, preserved archive/vote history and the tested procedure. Use an exclusively owned workspace; source identity fences do not make the legacy copy/merge lifecycle crash safe or concurrent-writer safe.

Official `p/python` and the existing local policy remain the primary security check; the bounded Strategy check is additional. Preserve raw findings and repair actual defects first. Licensed upstream YAML, raw diagnostics and private summaries stay local. Public projections retain status, counts, rule/source hashes and IDs, finding positions and measured/unknown costs without full rule bodies. The validation ZIP omits the entire local capture tree, including local public copies, and retains separately qualified downloaded public CI projections. A raw scanner failure remains visible even if a separately reviewed policy disposition is later accepted.

Coverage applies to the OSS rule definitions actually fetched and executed. Registry-reported Pro and other unavailable rules remain excluded and unqualified, including any recorded missed-rule counts; a result for the fetched set is not a claim of zero registry omissions. No account or paid access is requested.

Policy-map updates require a separately reviewed source change: freeze the complete tracked context, exact scanner/rule/target identities and raw report; propose individual identities with rationale and review references; obtain independent and configured review plus exact final-source checks before release or operational activation. Runtime candidates cannot approve maps, edit protected criteria or inherit authority. Changed or missing context, unknown findings, altered rule bodies and unreviewed pins must fail closed. This guide does not activate a map or clear an existing finding.

PostgreSQL/pgvector, actual FAISS, live Qdrant, general desktop or repository execution, financial/contract actions and universal competence are excluded from these checks. Original held Harness/bridge and Fleet restrictions remain. A renamed component, local test or rebuilt package does not clear them; this supported subset is not a complete four-product installation.
