## Installed examples and launch safety

- The wheel includes all six original CSV samples and unchanged copies of the 11 Sector-Shock-10
  fixtures used by Insight. Acceptance compares every bundled file with the original bytes and
  executes all 14 finite catalog commands with Python network calls blocked.
- `check NAME [--json]` reports declared module and bundled-file prerequisites without importing
  optional backends, downloading, creating run state or revealing credentials. `run` performs this
  check before starting a child. Missing weights, live services and provider access still need their
  documented integration checks.
- Launch paths resolve against the installed package. Output directories cannot shadow its Python
  package, and empty or relative inherited Python paths cannot become implicit child working paths.
  A file used as an output directory produces an actionable error while retaining its contents.
- Finite catalog commands disable OpenAI/Anthropic keys and tracing in the child. Tree search uses
  its bundled configuration and random rewriter; Marketplace uses its bundled job; Macro and Era
  use their packaged CSV paths. Parent credentials and advanced standalone options are unchanged.
- Offline children also disable remote Neo4j/PostgreSQL storage, preventing optional memory imports
  from probing a default or inherited database. An empty Neo4j URI selects local storage without
  constructing a driver. Explicitly configured service launches keep their existing connection path.
- Plain self-edit file helpers remain usable when the optional Agents SDK raises an import error
  for unavailable transport extras. This fallback does not claim provider execution.
