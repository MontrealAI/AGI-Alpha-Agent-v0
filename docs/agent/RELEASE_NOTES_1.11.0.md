# $AGIALPHA Agent 1.11.0 — executable Ascension protocol

The original Ascension journey had working analysis and encryption, but its MARK funding and Council
settlement were browser simulations. This release adds an integrated Solidity reference protocol and
an inspectable local-EVM lifecycle, preserving every existing contract and experience.

- ERC-721 Nova-Seeds bind encrypted capsules, indexed FusionPlan commitments and successor lineage.
- A staked, expiring validator risk oracle gates a reversible bonding-curve AMM and plan-restricted
  Sovereign treasury. ENS roles exactly follow the Ascension namespaces.
- Reputation-weighted, collateral-backed auctions reserve reviewer capacity, bind review to delivered
  artifacts, pay in canonical $AGIALPHA, burn 1% of each payout and recover unfinished obligations.
- Explicit reviewer opt-in prevents unsolicited stake/capacity locking. Missing quorum refunds without
  classifying submitted work as a proven failure. Membership revocation is rechecked before payment.
- The native allocation executor, encrypted seed, on-chain lifecycle and accounting run together on a
  local EVM. The Protocol Desk exposes the receipts and includes editable exact-arithmetic calculators.
- New acceptance gates exercise the contracts, native execution, public evidence and browser desk.

[Implementation, arithmetic, recovery and reproduction guide](ASCENSION_PROTOCOL.md).

No migration is required for existing native journals, missions, encrypted capsules or v2 contracts.
The new suite is separate and undeployed. Local fixtures and distinct test signers are not a mainnet
commissioning exercise, independent validation, predictive-accuracy result or claim of autonomous AGI.
