# 1.16.0 — Era of Experience Learning Lab

Era of Experience now runs an actual, bounded learning loop: a contextual-bandit agent selects
an action, observes a synthetic outcome, updates its memory and proposes a policy. Separate
held-out and retention suites compare the frozen candidate with the active baseline. Six gates
check reward gain, incidents, success, cost, retained observation coverage and retention.

Four editable environments cover build routing, sensor triage, reward hacking and environment
shift. Python and browser engines reproduce identical episodes, policies, gates and six-file
review bundles. Verification recomputes the entire run and rejects rehashed alterations.
Input-bound $AGIALPHA review jobs remain unsubmitted, and policy proposals remain unapproved.

The new responsive browser lab provides a performance comparison, exact totals, gate results,
policy inspection, a training episode explorer, settings recovery and local JSON/ZIP exports.
A loopback-only server serves the packaged assets without providers, model downloads or runtime
third-party dependencies. The main notebook and shell launcher now use this supported path.

Original research, architecture, diagrams, notebook, browser replay and service examples are
preserved. The legacy stream has bounded queueing and no duplicate action on UI inspection;
reward parsing handles all generated examples, and plugin boundaries reject non-finite values.
The historical Docker launcher is available through explicit `--legacy`.

Release checks cover deterministic oracles, training/evaluation separation, Python/JavaScript
parity, exact exports, installed assets, preservation, accessible browser journeys, offline
reload and commit-bound public acceptance. Synthetic learning is not general intelligence,
long-horizon planning, real-world deployment approval or evidence of financial performance.
