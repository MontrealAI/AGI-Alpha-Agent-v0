# $AGIALPHA Agent 1.5.0 — Ascension

This release turns the original white paper into a connected, inspectable browser lab and gives the
GitHub Pages entry point a new visual identity. The original flywheels, all 26 catalog entries, native
workflows, local model and earlier releases remain available.

## A complete journey through the paper

- Three editable flagship scenarios: the resilient city, discovery foundry and enterprise frontier.
- Insight compares feasible portfolios; Sovereign computes and visualizes their delivery schedules.
- Nova-Seeds carry the actual scenario, source notes, FusionPlan and native mission inputs. Real
  authenticated encryption, portable downloads and passphrase recovery use Web Crypto.
- MARK models an exact bonding curve and funding reserve. The Council requires two mechanical checks
  and operator acceptance before modeled settlement. Payout burn, combined emission caps, replay
  rejection and token conservation use exact 18-decimal arithmetic.
- Architect compares 20 budget/risk policies and exposes their trade-offs. The Value Reservoir shows
  unspent escrow and modeled treasury balances explicitly.
- The governance observatory includes strategy dynamics, risk arithmetic, action-level risk budgets,
  stake/slash controls, quadratic credits and the eight-day upgrade gate.
- Downloadable native missions, evidence JSON and readable briefs connect exploration to the installed agent.

The unchanged original PDF is available directly on Pages. The implementation guide maps its components
to working code and explains the corrected Table 4 total, Hawk–Dove equilibrium and aggregate action risk.
It distinguishes computed mechanisms, protocol simulations and unsupported research claims.

## Validation and packaging

New independent algorithm and cryptography tests accompany real browser acceptance of the complete
journey, recovery, state invalidation, negative cases, mobile layouts and offline reload. Both generated
site variants and the public deployment run these checks. Existing agent, model, sandbox, local EVM,
contracts, complete Python regression, types, platform smoke and legacy-demo checks remain required.

Release assets contain the tested site, source, wheel, locked runtime, browser model distribution,
implementation/operation guides, validation evidence, manifest and SHA-256 checksums. The release is
published only after the public site passes acceptance and the draft assets have been downloaded and
verified. Earlier published assets and tags are not overwritten.

## Upgrade and recovery

There is no journal migration. Back up private agent state and follow OPERATIONS.md when replacing
the runtime environment. Browser missions are memory-only until you explicitly download them. Keep
Nova-Seed passphrases separately; losing one makes its encrypted capsule unrecoverable. Restoring a
capsule recomputes its plan and starts a new funding simulation.

The cryptography and bounded algorithms execute for real. Economic and governance interactions in the
lab are simulations with no wallet transaction. This release does not establish AGI, autonomous profit,
formal security proofs, independent outcome certification or mint authority over deployed $AGIALPHA.
See WHITEPAPER_IMPLEMENTATION.md for the precise implementation map and reproducible checks.
