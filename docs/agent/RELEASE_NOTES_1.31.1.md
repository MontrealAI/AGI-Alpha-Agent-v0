## Read the evidence correctly

The study used a simulated owner and zero human participants. It repaired two deliberately defective
website fixtures: 8/31 to 31/31 checks on Task A, and 9/35 to 35/35 on Task B. Removing one retained
portability fix reduced Task B to 29/35, with six checks sharing one export cause. Recovery passed
19/19 controlled checks. Scripted setup controls fell from 14 to 11 at equal final quality; human
time savings were not measured.

The study did not execute this repository. Its source inspection remains pinned to the historical
commit `8c027575c850bf5a872e6b11f81933b5e77b6be2`. Publishing the report does not validate newer runtime
versions or establish superiority over other agents, customer acceptance, independent review,
production reliability or general self-improvement. Reader acceptance qualifies the publication only.

The [1.31.0 release scope](RELEASE_NOTES_1.31.0.md), commissioning boundaries and historical 80-case
record retain their original meaning. This maintenance release changes no deployed contract, grants
no execution permission and starts no paid provider session. The release manifest and validation
archive identify the actual accepted commit, checks and published bytes.
