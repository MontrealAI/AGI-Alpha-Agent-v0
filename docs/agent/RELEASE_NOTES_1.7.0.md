# $AGIALPHA Agent 1.7.0 — Nova-Seeds Proof Bloom

Five connected experiences now turn unsupported claims into executable work, replayed evidence and reviewed capability:
Nova-Seeds Proof Bloom, Sovereign Bloom, the Alpha Business Ω-Lattice, Invention Automation and Proof Debt → AGI Jobs.

The new [Proof Bloom foundry](https://montrealai.github.io/AGI-Alpha-Agent-v0/bloom/) adds an opulent forest, ivory and gold
interface, guided next actions, inspectable results, responsive layouts, keyboard operation and offline recovery.
It is linked from the homepage, Insight Atlas and Ascension Lab; all original catalog entries and flywheels remain present.

## Functional changes

- Compile exact source, benchmark and stress jobs from editable bounded inputs.
- Run allocation, scheduling, forecasting or source-research Missions in the browser or export them to the native agent.
- Import replay-verified ProofBundles and approved Ed25519 native returns bound to independently trusted keys and exact inputs.
- Record artifact-bound accept, reject or repair decisions; execution never creates an acceptance decision.
- Promote only after replay, review, baseline, stress and active-lineage gates pass.
- Reuse one exact benchmark in the next mission while requiring fresh probes and decisions.
- Revoke a capability and all descendants; preserve and replay its complete Chronicle history on recovery.
- Export a dossier with canonical JobSpec checksums, unpublished JobSpecURI plans and unminted Nova-Seed metadata.

The release adds adversarial engine tests and mandatory local/public browser acceptance, including actual native execution,
signature and input-binding checks, unchanged download round trips, transitive revocation, WCAG A/AA checks and offline use.
The release archive retains evidence from the exact tested commit and public deployment.

## Scope and compatibility

The portable protocol is `agialpha.bloom.v1`. It does not assert external Evidence Docket 6.1 or AGIJobManager settlement
compatibility. Visionary wealth and production claims remain unproven after a bounded computational capability is promoted.
No NFT is minted, job funded or transaction submitted. Signed native approval is shown separately from the local benchmark.
See the [field guide](PROOF_BLOOM.md) for methods, trust assumptions, bounds and reference source hashes.

### Breaking Changes

None to the existing native Mission API, Insight Atlas, Ascension Lab, original demos or published releases.
