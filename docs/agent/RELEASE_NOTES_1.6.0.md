# $AGIALPHA Agent 1.6.0 — Insight Atlas

This release brings the Living Treasure Map, Second-Order Agency and Alpha Ontology visions into one
connected working browser experience, with a refined visual design inspired by agialpha.com.

- Twelve interactive frontiers, three editable expeditions and exact integer allocation of the illustrative
  opportunity envelope. No rounding loss above JavaScript's safe-number range.
- Resource-constrained agent firms, explicit independent reviewer groups, fault injection, operator capacity,
  baseline/holdout comparisons, eighteen candidate architectures and an inspectable cost/output frontier.
- Searchable typed claim graphs, custom hypotheses, concrete validation briefs, native research missions
  and full dossier exports. References remain distinct from independent verification.
- Evidence bound to exact inputs and recomputed before promotion; unsafe, stale, altered and duplicate
  results are rejected. Reviewed modeled capabilities enter a hash-linked Chronicle with revocation and
  portable, replay-verified recovery. Reuse a reviewed architecture under current resource limits; fresh
  evidence remains mandatory.
- An ivory-and-obsidian homepage and Atlas, sculptural metallic details, keyboard controls, reduced-motion
  support, responsive data views and offline use after caching. The original flywheel and demos remain.
- Recovery downloads automatically compact large histories to stay within the import limit. Evidence
  promotion checks the complete recovery envelope before recording a capability. Regression tests now
  restore the exact downloaded bytes, including three-capability histories and offline revocation recovery.
- Contributor setup applies current package requirements after historical development locks, fixing the
  cryptography downgrade that previously made `pip check` fail.
- The browser lint hook publishes its installation checksum atomically, preventing concurrent
  pre-commit batches from falsely reporting a stale installation. A deterministic concurrency test
  reproduces the original failure; genuinely stale installations still fail. The
  [original failed hook report](release-evidence/insight-lint-race.json) is preserved with its artifact digest.
- The lint hook passes quoted absolute paths directly to ESLint, avoiding the GNU-only `realpath`
  option that failed the macOS smoke gate. Paths with spaces and the concurrent first-use case are tested.

## Scope and recovery

The $15 quadrillion figure remains an editable scenario assumption. Planning fixtures and reviewer
independence are modeled, not measured production performance. Chronicle promotion establishes a local
benchmark result, not AGI, investment returns, independent certification or mainnet settlement. The existing
$AGIALPHA economics/governance simulations and optional native integrations retain their documented limits.

Save an expedition before closing the browser; its plain-JSON recovery file contains all source excerpts
and operator reviews. Restore verifies hashes and replays promoted results. Revoke a capability to retain
its evidence while marking it inactive. For native upgrade or rollback, preserve the old environment,
make a private signed backup and restore into a new home as described in [OPERATIONS.md](OPERATIONS.md).

Branch protection remains an administrator setting; the exact required check names and instructions are
in [release readiness](RELEASE_READINESS.md#repository-administration). It is not silently claimed enabled.
