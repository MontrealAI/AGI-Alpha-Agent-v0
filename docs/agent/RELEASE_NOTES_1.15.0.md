# 1.15.0 — Insight Discovery Workbench

Insight v0 now provides a complete local review workflow: source-linked cross-sector hypotheses,
weighted uncertainty intervals, conservative eligibility gates and an exact review-capacity portfolio.
Five synthetic cases make successful, evidence-deficient and capacity-limited outcomes inspectable.

The browser and Python engines produce identical decisions and six-file evidence bundles. Every
opportunity exports an input-bound, unsubmitted $AGIALPHA verification job; selected opportunities
also export plaintext, unminted Nova-Seed drafts. Dossiers are verified by full recomputation.

The browser adds editable constraints and complete JSON inputs, source inspection, explicit draft
recovery, portable exports, accessible controls, mobile layouts and offline reload. Existing canonical
and mirrored routes remain. Original research, flowcharts, notebook and all launchers are preserved.

Legacy numeric search now expands a real bounded UCB tree and counts each reward once. It uses a local
RNG, valid JSON stdout and collision-safe evidence. Provider use is explicit, bounded and incompatible
with offline mode. The loopback API rejects providers, output paths, ambiguous JSON and oversized
bodies, and limits simultaneous work. Startup no longer installs dependencies automatically.

The maintained notebook pins this release, checks Python compatibility, runs all cases offline after
source retrieval and exports replayable evidence. The release pipeline adds independent portfolio
optimality, 125 Python/JavaScript parity cases, exact export checks and commit-bound public browser
acceptance. Synthetic priorities do not establish forecast accuracy; source references and hashes do
not authenticate evidence, certify compliance or authorize deployment.

Start with [the installation and first-run guide](START_HERE.md), then use the
[Discovery operating guide](DISCOVERY.md) or [complete demo guide](DEMOS.md).
See [release readiness](RELEASE_READINESS.md) for deployment scope and acceptance evidence.
