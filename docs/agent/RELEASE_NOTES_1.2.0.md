# $AGIALPHA Agent 1.2.0

This release connects the original seven agent roles into a persistent, reviewable working agent.
It preserves the original README, flywheels, demos, assets and historical Solidity experiments.
The prior state is archived as `baseline-2026-09-24`.

- Five bounded mission types: source-grounded research with optional real model inference, resource
  allocation, production scheduling, holdout-tested forecasts and isolated Python coding benchmarks.
- Local operator console and CLI; strict inputs, persistent pause, idempotent requests, exact-artifact
  review, approved memory reuse, signed exports, identity and verified backup/restore.
- $AGIALPHA wallet-control proof, pinned chain/token verification, approved-work invoices, confirmed
  receipt accounting, replay prevention and explicit reinvestment earmarks. No wallet-key custody or spending.
- Corrected Pareto dominance/crowding behavior, explicit settings precedence, sandbox fallback,
  exchange testnet selection, SDK tool construction, token checksum and preservation of gallery assets.
- Reproducible runtime dependency lock, install helper, Python wheel, full source archive, checksums,
  release manifest, regression/integration evidence and recovery instructions.

Start with `docs/agent/OPERATIONS.md`. The capability matrix distinguishes implemented behavior from
retained simulations, optional integrations and historical aspirations. Real local model and EVM runs
are recorded; mainnet operation, unrestricted AGI, autonomous treasury spending and guaranteed returns
are not claimed. Optional legacy test skips remain visible in the published evidence.
