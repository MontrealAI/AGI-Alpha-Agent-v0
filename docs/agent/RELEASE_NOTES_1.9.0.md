# Version 1.9.0 — Decisions worth using

The public examples previously emphasized toy landscapes, sample log replays and repeated placeholder
artwork. This release adds eleven practical, editable decision workspaces and connects every original
catalog entry to a relevant task. Original research implementations and paths remain available.

The Decision Studio calculates capital portfolios with prerequisites, discrete supplier allocations,
resource schedules, replenishment quantities, microgrid dispatch, evidence-to-job backlogs and costed
second-order pipeline comparisons. It produces decision briefs, row-level CSV plans, replayable JSON
dossiers and scoped proof jobs. CSV import, explicit local save/restore, cancellation, responsive inputs,
input invalidation and offline calculation are included. Returning visitors automatically load refreshed
assets after a cache upgrade; if they have begun editing, an explicit reload prompt preserves their work.
A Node CLI uses the same computation modules.

The homepage receives distinct domain previews, task-led cards and richer native research, allocation,
schedule and forecast defaults. The original demo routes now lead with a practical workspace link.
The final 198-page manuscript, prior proof protocols, native runtime and original source paths remain intact.
Compatible inference servers can opt into schema-constrained research and code outputs. Existing signed
configurations retain their hashes, and both inference modes continue to reject malformed evidence.

Constructed examples are identified. Arithmetic checks do not authenticate source records. Forecast
policies are selected before held-out evaluation; impossible or losing cases retain explicit holds.
No orders, payments, equipment actions or marketplace jobs are submitted by the studio, and capability
promotion still requires the separate signed evidence and review workflow.

Release acceptance adds independent calculation tests and complete browser-to-CLI replay of actual
user downloads, along with editing, import, negative cases, accessibility, mobile and offline checks.
See the [Decision Studio guide](DECISION_STUDIO.md) for methods, bounds and practical walkthroughs,
and [release readiness](RELEASE_READINESS.md) for the supported deployment scope.
