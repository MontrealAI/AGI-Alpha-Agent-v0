What runs here

Exact integer allocation, deterministic event scheduling, bounded architecture search, typed claim graphs, SHA-256 evidence replay and recoverable local history. No API key, account, hidden server or third-party telemetry.

The planning engine does not generate forecasts or use a language model. The original workspace includes browser inference; the native operator supports local model missions.

What remains a hypothesis

The $15 quadrillion figure is an editable illustration. Task fixtures are synthetic and public; the holdout is separate, not secret. Reviewer independence and validity labels are model assumptions. Passing a fixture does not demonstrate AGI, investment returns, or live $AGIALPHA settlement.

Token mechanics remain inspectable simulations in Ascension. This project is the $AGIALPHA agent project, distinct from AGI Jobs.
