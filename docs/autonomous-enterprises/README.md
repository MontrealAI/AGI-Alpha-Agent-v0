# Autonomous Enterprises — Build the Means of Building

This additive source preview extends the existing capability workspace and its thirteen-section Evidence Docket.
It preserves Discovery Lab, Out-Evolve, the six research stages, original paper files and all existing mission events.
The maintained homepage links to `successor/capabilities/#autonomous-enterprises` in this source tree.
Public deployment requires the existing owner qualification and publication pipelines.

The constructor and checker are separately authored implementations of the selected 23-page manuscript.
No audited manuscript code/results companion was obtained from the inspected public main tree, code search
or recent release assets. This is **an independent reimplementation**, not reproduction of the paper's Python package.

## What executes

- Exact shortest paths over optional durable capability stocks, actual recipe/stock witnesses, a separate decreasing-stock
  dynamic program, capital envelopes, the retention-law witness, dominance and bounded cover certificates.
- All 64 signed/layout candidates at each Walsh size 2, 4, 8, 16 and 32; all four convolution normalizations;
  every one of the 1,024 ordered convolution basis pairs; both complete 32-basis inverse qualifications.
- Inert, content-bound JSON ASTs with structural linear/bilinear semantics, exact bounded rational arithmetic and
  topological dependency admission. Generated data are never passed to an evaluator of arbitrary source code.
- Construction and acceptance in the existing mission chain, freezing before later input generation, five actual
  treatment paths, simulated work reconciliation and a separately checked inverse for a changed kernel.
- Single-use in-memory execution leases. An interrupted/reopened execution reservation is uncertain and cannot
  silently rerun. Unknown historical reservations block a new attempt in the same mission. A genuinely unstarted
  budget refusal records known zero production work while retaining its inconclusive attempt.
