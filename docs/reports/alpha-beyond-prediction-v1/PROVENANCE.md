## Public-data pilot: NIST Gauss1

The pilot uses [NIST Gauss1](https://www.itl.nist.gov/div898/strd/nls/data/gauss1.shtml), part of Statistical Reference Datasets, SRD 140, collection DOI [10.18434/T43G6C](https://doi.org/10.18434/T43G6C). These are **generated reference data**, not observations of physical specimens. NIST's [How to Use instructions](https://www.itl.nist.gov/div898/strd/general/howto.html) expressly describe downloading a dataset, analyzing it, and comparing results with certified values. That is the bounded use performed here.

The dataset appears in the [free SRD catalog](https://www.nist.gov/srd/free-srd). “Free” is not a claim of blanket public-domain status: the relevant [NIST rights information](https://www.nist.gov/open/license) and [dataset disclaimer](https://www.itl.nist.gov/div898/strd/general/disclaim.html) remain applicable. This package does **not** redistribute the raw input observations or per-observation residuals. It provides retrieval instructions, aggregate numerical comparisons, and derived fitted-curve outputs, with no NIST endorsement or certification of those outputs implied.

The expected input is 8,417 bytes with SHA-256 `20d0b85ffc73681ce9bdd69c566e53969a65e0e2192c3de16ad4a1dcfdca6c27`. data/nist/reproduce.py — `data/nist/reproduce.py` (ZIP member) rejects a mismatched file.
