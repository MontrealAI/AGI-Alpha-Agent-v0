### Constructing Adaptable Productive Capabilities Under Deep Uncertainty

**Writer #11 · MONTREAL.AI research contribution**

What useful instrument can we build before we know which assignment will matter? This package constructs a bounded scientific measurement engine, **APERTURE**, that changes its observation model and measurement structure across spectral characterization, causal system identification, and coded-aperture emission imaging. It then tests whether that adaptability provides an advantage over an equally enabled conventional implementation.

**The main result is a tie, accompanied by a serious verification failure.** APERTURE and the conventional modular builder each qualify in **54/96** confirmation cases and choose the same actions in every paired case. The residual checker accepts 94 APERTURE outputs, of which **40/94 (42.6%)** miss the scientific quality threshold. Only **6/32** cases qualify in the held-out imaging family. A capability can execute a new representation without producing reliable scientific answers. Evidence — `evidence/review/scientific_interpretation_review.md` (ZIP member)

The contribution is an inspectable construction procedure, a frozen finite evaluation, explicit authority boundaries, and an informative negative comparison. This is not an observed human-expert trial, autonomous invention, physical validation, or a claim of advantage across unknown futures.
