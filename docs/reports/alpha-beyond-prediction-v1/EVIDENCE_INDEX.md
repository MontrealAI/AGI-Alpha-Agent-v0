# Claim-to-evidence index

This public reading surface accompanies the [complete source and evidence ZIP](AGI_ALPHA_Alpha_Beyond_Prediction_Complete.zip). Extract that archive before running any command. Paths marked **ZIP member** are inspectable files inside its `AGI_ALPHA_Alpha_Beyond_Prediction/` directory. The archive contains all 204 source/evidence payloads and its manifest; no external data download is needed for the synthetic study.

The authoritative 24-page PDF has complete page-by-page visual acceptance — `evidence/paper-qa/FINAL_PDF_QA.json` (ZIP member) and a byte-identical clean typesetting rebuild — `evidence/paper-rebuild/REBUILD_RECEIPT.json` (ZIP member). These checks are distinct from scientific validity, external peer review, or repository release approval.

This index connects the paper's material claims to inspectable package artifacts. A hash binds bytes; it does not establish scientific truth, independent organizational review, or authority to perform another task. The authoritative technical assumptions remain in the frozen protocol — `protocol/PROTOCOL.md` (ZIP member).
