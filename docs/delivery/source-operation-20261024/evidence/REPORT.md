## Reproduce and operate

Use an installed source/release containing this change and a NEW output directory. The POSIX failure harness deliberately
kills only its own first child process; the ordinary operation commands support the existing runtime platforms.

```sh
python examples/transformational-intelligence/source-operation/verify_campaign.py run --plan docs/delivery/source-operation-20261024/plan --output NEW_QUALIFICATION_DIRECTORY
```

From a source checkout, set `PYTHONPATH=.` for that command. For installation and ordinary first-run, status, stop, export
and recovery commands use [the runbook](../../../agent/SUCCESSOR_SOURCE_OPERATION.md). The reference exercise installed a
wheel outside checkout with existing copied dependencies and passed pip check; it was not an anonymous public-release install.
The candidate code requires Python 3.11–3.13; actual reference host Python 3.12.14, pydantic 2.13.5, cryptography 50.0.1.
Jobs, Manager, Fleet, wallet, model provider and all five Alpha contracts were unused and are not qualified here.

Setup, source repair, experiment design, review and fault-controller construction required engineering intervention.

ran without further selection prompts. Human minutes remain unmeasured. The campaign must not be described as autonomous
end-to-end development. Prior development failures (frozen-model mutation, bool-as-int validation and lint line lengths)
preceded the frozen study and were corrected; first failing hook output is retained. No scientific workload was tuned after
its results. Default action scope has no network, paid calls, wallet, deployment or financial effect.

its complete failure/result/accounting fields; the manifest binds all delivered evidence bytes.

## Source review limitations retained

Configured review of this original source found two P1s and one P2: base DiscoveryLoop entry points could miss the operation deadline/home check; a pre-reservation interruption could allow a substituted batch; and a committed child on the final allowed attempt could be stranded. See PR4891 threads4367998541,4367998543 and4367998545. The original campaign used the dedicated operation path and a three-attempt allowance; its computation results remain historical observations. The source is not security-qualified or released. Corrections and fresh control-specific evidence must keep a new source identity; these records are not silently transferred.
