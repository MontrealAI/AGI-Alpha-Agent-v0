Check sender, full destination, method, arguments, zero ETH value and token consequences. Simulation is not a guarantee. Network fees are paid in ETH; your wallet shows the final fee quote. This preview expires after 60 seconds.



6 · Verify the receipt
A submitted hash is not payment success. Refresh to check the actual transaction, receipt, canonical block and finality. Pending, replaced, reverted and unknown states must be reconciled before retrying. This browser automatically saves public transaction intents before signing. Export a backup before clearing browser data. A restored or replacement hash must be checked on-chain; imported records never authorize signing.
Only a finalized transaction using the recorded sender and nonce resolves an uncertain submission. A cancellation or different replacement is never reported as successful execution. Browser storage and this lock cover this origin and browser profile only; other devices and wallet apps require coordination.
