# Independent conventional execution challenge

The known-method control matches the existing conditional-access construction.
The technical-breakthrough claim for this finite target stops here. A useful
formulation, safe integration and inspectable evidence remain possible product
contributions; neither execution parity nor this experiment establishes a
discovery advantage or its absence.

The separate workstream inspected the supplied requirements and existing source
before freezing the campaign. It implemented ordinary uniform-cost state-space
search with a priority queue and chosen-step subset caching, rather than copying
the candidate's depth-first enumeration. It received identical finite predicates,
declared permissions, obligations, budgets, action options and ranking objective.
Every positive path was checked by a separately implemented constraint verifier.
This is algorithmic workstream separation, not an external human review, blinded
invention trial or independent validation of the real-world declarations.

The fresh cases concern release-assurance packets, open transport reports and
public reproduction packets. They test pending and documented permissions,
denied outputs, absent input, obligations, cost, time and node ceilings. They
remain related finite monotone-planning structures, with authored requirements
and acceptance. They do not establish generality across real mission families,
actual delivery of those packets or customer acceptance. Managed-service outside
options are explicitly available in the fresh examples, and the objective often
prefers their documented permissions over cheaper conditional arrangements.

The frozen ceiling was 24 cases and 90 process CPU seconds, with no model calls
or external effects. Measured campaign execution used 0.067242298 process CPU
seconds and 0.067250173 wall seconds in the recorded run. These small timings are
not a frontier-model benchmark or a reliable production performance estimate.
Candidate enumeration visited 200 nodes and the conventional search 93 nodes;
node definitions differ and no speed-advantage claim is made. Authorship, review,
shared compute pricing and complete monetary costs are unknown, not zero.
Customer receipts are zero. Fixtures grant no permission or production authority.

The original complete results and input bytes are retained in `RESULT.json` and
`FREEZE.json`, with exact original source in `SOURCE_v1.py.txt`. Both bind the
exact challenge script; the freeze also binds the candidate source. Freeze
precedes comparison execution, but follows source inspection and input authorship.
No candidate was discovered by this experiment.

Strict typing then found a missing `list[dict[str, Any]]` annotation. The exact
diagnostic and type-only correction are recorded in `TYPE_CORRECTION.json`.
The corrected script passes strict mypy, Ruff lint and format checks. Its separately
named `FREEZE_typecorrected.json` and `RESULT_typecorrected.json` preserve an
identical-input confirmation: again 23 complete ties, one incomplete case and zero
positive-witness failures, using 0.079044154 CPU seconds. The confirmation follows
the original results and is not a new prospective or fresh-case trial. The two runs
use 24 unique cases and 0.146286452 aggregate CPU seconds. Five negative verifier
probes reject obligation violations, missing prerequisites, repeated steps, unknown
steps and an over-budget service; `ADVERSE_WITNESS.json` records them separately.

## Closest established approaches

Primary sources retrieved on 2026-10-27:

- [W3C ODRL Information Model 2.2](https://www.w3.org/TR/odrl-model/),
  Recommendation dated 2018-02-15: models permissions, prohibitions, obligations
  and constraints. Policy representation is established prior art. The synthetic
  predicate schema does not claim full ODRL semantics or policy correctness.
- [Pyperplan's official repository](https://github.com/aibasel/pyperplan): a
  lightweight STRIPS planner originating in 2010/2011. Its documented fragment
  lacks action costs; this challenge therefore uses ordinary resource-augmented
  state-space search rather than claiming that unmodified Pyperplan implements
  the exact objective. No Pyperplan code was copied or installed.
- [Python 3.12 heapq documentation](https://docs.python.org/3.12/library/heapq.html):
  the standard-library priority queue used by the independently written control.

The surviving gap is evidence and operating integration: a recipient's actual
unmet need, trustworthy declarations, permitted execution, complete costs and
accepted outcomes. This campaign finds no surviving algorithmic gap in the
declared finite planning target. A real access or policy-interpretation service
would require additional evidence and permissions that this artifact cannot grant.

## Reproduce the frozen run

From the repository root, with the existing Python dependencies:

```bash
python -m scripts.insight_conventional_challenge run \
  --freeze evidence/decisive-frontier-20261027/conventional/FREEZE_typecorrected.json \
  --output /tmp/insight-conventional-reproduction.json
```

The output path must not already exist. Source changes refuse execution; they
require a separately named campaign, preserving this edition. Timing values vary.
Creating a new freeze is a development action, not retrospective validation of
these historical results.

Environment checks passed before execution. The initial `ruff` command was not
on PATH; invoking the installed module as `python -m ruff` passed formatting and
lint. No comparison failed or required a behavior change to the comparator.
