Results you can test again.

For technical readers: the kit preserves the original harness and adds a checker that rejects missing or different outcomes. Tests run in a new directory.

python verify_and_replay.py --verify-only
python verify_and_replay.py --output /absolute/path/to/new-replay

Python 3.11–3.13 and reviewed Chromium/Playwright are required. Installation and limitations. Expected mechanical results: A 31/31; B 35/35; one-fix removal 29/35; recovery 19/19; owner controls 14 versus 11. A replay tests existing code; it does not generate a new AI solution or measure human time.

Fresh CI evidence is a separate download on the study release. Historical results stay historical. This source kit is not the original 98-file Office/PDF experiment archive.
