# Prospective protocol

This is a small, explicitly bounded experiment. H is a market reference; U, E and E+ use separately initialized
hosted instances with the same inherited model and available tools. U is competent ordinary tool-equipped
operation, not a sampled population of ordinary human users. The trial cannot identify hidden reasoning tokens,
API bills, provider scheduling, or all human research effort. Those quantities remain unknown.

An independent author writes complete customer contracts, starters and acceptance checks. A clean reference
proves feasibility; references and acceptance code are withheld from solver instructions. The public contracts
are authoritative. Tests are fixed before submissions and check contract properties rather than similarity to
the reference. No confirmation score is returned to a solver. All task directories are fresh and all source
hashes are recorded. Four mission clusters are too few for a strong general superiority claim; hundreds of
assertions do not create hundreds of independent missions.

The expert workflow is researcher-authored before the development mission. A further artifact may be retained
from development, with its exact contribution and construction mechanism disclosed. Separate E+ recipients
receive only method bytes, not the development solution or protected acceptance cases. Future task instances
are unfamiliar to those recipients. An ordinary library with identical contents is a mandatory distribution
control. No graph premium is assigned.

The primary envelope is 1,500 wall-clock seconds and 64 logged operations per four-job arm, with a 45-second
timeout per execution. These limits are the same; they are not a token-matched API experiment. The runner
records reads, edits, test executions, elapsed time and hashes. Its protocol does not establish OS isolation.
Actual total research cost and actual accepted-output dollar cost remain null unless metered evidence exists.

All original findings and failed development are retained. Corrections after a freeze receive a new version
and a specific deviation record. They cannot silently convert post-hoc diagnoses into prospective profits.
