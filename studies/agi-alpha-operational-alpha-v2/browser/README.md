## Build from the final evidence

From the study directory:

```sh
python browser/build_demo.py --require-complete
node browser/validate_demo.cjs
```

The generator embeds `opportunity_sections.html`, `opportunity_styles.css` and `opportunity_demo.js` into the
existing bilingual template, then embeds the recorded JSON. The strict build requires final primary, C5,
economic and S3 results, the four conventional mission receipts and all six cash-timing cases. Its receipt
binds the generator, template, components and source files with SHA-256. A build without `--require-complete`
carries a visible development banner and is not a final research artifact.

Browser validation uses installed Playwright and the inspected local Chromium executable. Supply an appropriate
verified executable in another environment. Checks cover desktop, 320/390-pixel mobile, EN/FR, keyboard tabs,
source-bound scientific numbers, every timing mode, retained losses, original economic tables/calculators,
complete translation coverage and no network requests. It records the exact HTML hash and preserves earlier
launch and QA failures. Screenshots under the workspace `browser_qa` directory are internal visual QA only.

The result is verified local rendered behavior, not canonical Pages publication, public HTTPS qualification,
external scientific replication, production security review, actual buyer acceptance or earned revenue.
