## Build from the final evidence

From the study directory:

```sh
python browser/build_demo.py --require-complete
node browser/validate_demo.cjs
```

The strict build requires the final `results/pilot_summary.json`, `results/composition_summary.json`,
`economics/results/summary.json`, all primary per-case acceptance files, and the native integration summary.
Its build receipt binds the exact builder, template and embedded source files. A development build without
`--require-complete` carries a visible development banner and must not be delivered as a completed edition.

Browser validation uses installed Playwright and Chromium. The current validation script names the inspected
local Chromium executable explicitly because the installed Playwright version expected a different absent
browser. Supply an appropriate verified executable in another environment. The script performs actual desktop,
320/390-pixel mobile, language, keyboard, calculation and no-network checks. It records the HTML hash and retains
the original launch failures. Screenshots are internal visual QA only and are not part of this deliverable.

The browser result is local rendered behavior, not canonical Pages publication, public HTTPS qualification,
external replication, production security review, actual customer acceptance or earned revenue.
