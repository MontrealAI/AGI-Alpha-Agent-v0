# Conventional direct-algebra control

This solution uses the same public model files, parameter values, measurement tables and requested outputs as the hosted U/E/E+ participants. It is independently authored and uses established tools: a direct stationary linear solve, SciPy matrix exponentials and NumPy eigenvalues. The H4 generator is assembled from the actual SBML kinetic-law symbols. The fresh Boehm mission reads actual finite-time data and correctly withholds the H4 equilibrium witness.

The author constructed this script specifically for the research protocol. Do not call it a pre-existing zero-cost service, a human trial, or proof that ordinary model users always succeed. Source construction, test and review costs were not metered. Runtime is measured separately from construction and is not compared with hosted wall time as though they were the same resource.

The independent acceptance oracle uses a separately reconstructed generator, SVD stationary solution and Poisson uniformization. Both operate on a supplied mathematical model. Neither establishes physical truth or new biology. Source licenses remain in the common public case.
