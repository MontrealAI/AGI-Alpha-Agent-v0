# Executable connected-production study

The primary study executed six generated nonpersonal projects in three contexts and two complexity strata. Each request produces a source/dependency assurance JSON, a constrained rollout/repair plan and a bilingual HTML dossier. Four cycles and three methods yielded72 joint requests and216 family checks; there are six project instances, not216 independent customer jobs.

## Browser API

The corrected browser-safe module is `companion_v1_1/capability.mjs`:

```javascript
const first = await runProject(base, {arm: 'flywheel', sourceHash});
const parent = await retainedParent(changed, first.state);
const child = await constructChild(parent.parent);
const next = await runProject(changed, {
  arm: 'flywheel', previous: first.state, child, sourceHash
});
```

`changed.cycle` must be2 or greater for fresh changes. First child use must match its actual construction parent. Later uses retain the accepted predecessor's child registry and immutable construction origin. `sourceHash` is the frozen local source identity; it is not a signature. The parent state and capabilities do not grant authority. The development default is in `demo/example.json`.

## What the implementation establishes

The parent records a source/dependency index. The child invokes it to identify changed and transitively affected records, preserves unaffected exact evidence keys, produces a change-impact certificate and regenerates coherent source/plan/document artifacts. Frozen starts and actual preceding schedules are respected in the repair slice. An ordinary content-cache specialist delivers the same supported outputs. The child is authored conventional dependency propagation, with measured binding/validation overhead; it is not autonomous invention of a new algorithm.

Seven history records carry useful artifacts for Identify, Out-Learn, Out-Think, Out-Design, Out-Strategise, Out-Execute and Out-Evolve. They describe artifact provenance, with computation preceding the checkpoint records; they are not independently timed or enforced execution phases. The upstream workbench's embedded generic Jobs compilation is scaffolding with a pre-existing aggregation charter, not a semantic acceptance certificate for these new artifacts. Actual acceptance comes from the separate source/schedule/dossier oracle.

No human duration, complete delivered-business cost, paid demand, collected revenue, autonomous live operation, self-financing, or self-acceleration was observed. Economic numbers elsewhere in the study explicitly source or assume missing inputs. Public source inventories do not certify functional behavior, security or deployed bytecode. Synthetic project dependency declarations do not discover hidden real repository dependencies. Plans do not execute physical rollout.
