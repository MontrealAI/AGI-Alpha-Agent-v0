## Reproduce the known geometric results

Use Python 3.12 and the observed CAD dependencies in [requirements.txt](requirements.txt). A clean-environment installation was not performed; the actual run used the available pinned versions recorded in [environment.json](evidence/environment.json).

From this study directory:

```sh
python reproduce.py /absolute/path/to/a-new-replay-directory
```

The destination must not exist. The runner verifies source, constructor and protocol identities, copies the packaged inputs, regenerates the known historical and disclosed fresh requests, and invokes the strict supplementary verifier. A changed source does not inherit the old freeze. Semantic checks are the replay target: STEP timestamps and execution times can vary. A rerun of disclosed requests is reproduction, not an additional fresh trial.

To check the packaged outputs without replacing the saved verification record:

```sh
python verify_study.py --output /absolute/path/to/a-new-verification.json
```

The current constructor is `src/produce.py`. The public source and its license are in `data/public/`. Each admitted case provides `part.step`, `part.stl`, `part.svg`, `feature_program.json` and `features.csv`. Historical failures and the first incomplete verifier are retained under versioned paths. Do not use the frozen raw comparator or checker as an untrusted intake service or standalone release gate.

## Reproduce the economics

The model uses only Python's standard library. From the economics directory:

```sh
python model.py --output /absolute/path/to/a-new-economic-result-directory
python audit.py --output /absolute/path/to/a-new-economic-result-directory
```

The exact-rational model enumerates three prospect slots, correlated common states, buyer refusal, correction, failure, default and cash gates. It compares stop, first-only and selective-continuation policies under separate preparation, conventional sharing and proposed sharing. The latter two receive identical assets and must tie. The 7,122 weighted histories are mathematical paths, not buyer observations.

At the hypothetical USD1,200 fee and USD2,000 supplied capital, favorable shared selective delivery yields USD146.98 expected prospective profit with a 37.75% probability of loss; the central case yields USD−252.59. A separate illustrative USD2,400 historical build charge reduces the favorable result to USD−2,253.02. The charge is not measured study cost. Initial unrestricted cash of USD1,542 is needed for the first booked attempt; the refundable deposit cannot fund it. Every commercial scenario remains HOLD because buyer need, terms, scope qualification and available funding are unestablished.
