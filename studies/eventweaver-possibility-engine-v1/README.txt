DECISION: NO TRANSFORMATIONAL FLAGSHIP EARNED.

EventWeaver is a functioning bounded temporal-event compiler and a completed,
rejected standalone commercial candidate. Its useful technical result is retained.
The complete-cost commercial experiment says STOP standalone expansion. The
bounded return to search did not earn a replacement flagship. Experimentally
calibrated counterfactual robot experience is the strongest conditional new
opening, but no model, controller, robot transfer or customer outcome was executed
for that opening. Do not present it as a delivered product or this study's alpha.

STRONGEST RESULTS

The original compiler converts one to four A→B→C temporal predicates into explicit
state logic and synchronous Verilog. It delays a decision through the inclusive
veto deadline and preserves group identity. The logical interface is eight event
bits per tick, with synchronous reset, and at most 20 ticks per predicate. The
user supplies already normalized digital events. No photon arrival measurement,
TDC, physical I/O, clock crossing, board deployment, physical timing or optical
accuracy is supplied or claimed.

Fresh confirmation: 24 specifications, 768 traces, 196,608 ticks and 491,520
predicate-tick decisions; all compared execution paths agree. Fifty-two directed
actual-RTL cases and 14 invalid-specification refusals pass. Conventional history
logic ties functional acceptance and is faster in the measured Python workload.

The successor adds an acyclic virtual-event composition grammar that the original
compiler rejects. Its separately frozen confirmation passes 48 traces across six
networks and 6,144 ticks, plus 10 directed cases and nine invalid-network refusals.
Both the independent conventional network and an ordinary library holding the
same retained artifacts tie. This is reusable software, not learned superiority.
The stage named conditioned_calibration emits a Boolean trigger sequence; it
does not measure, perform or verify physical calibration.

A separate, postconfirmation operator-removal study passes six predeclared
fixtures and 88 ticks. Removing delayed veto, group isolation or a required
virtual link changes selected contractual outcomes. Replacing OUR compiler with
competent conventional RTL preserves all six outcomes. Therefore the functions
are necessary for these chosen contracts; the EventWeaver implementation is not
demonstrated to be an indispensable transformational invention.

The selected $1,200 supported-library service policy was frozen after a bounded
development comparison. In 1,024 base histories, mean accepted deliveries are
7.9434, mean operating contribution is -$3,928.41 and mean full-project profit is
-$29,628.41. Fixed campaign cost is $25,700, including $4,100 for successor
research charged once. All 10,240 histories across ten conditional scenarios lose
money. No-launch dominates the tested launch policies. No earned surplus funds
the successor. These are modeled results, not estimates from observed customers.

The independent ledger audit reconstructs 1,265,250 entries with zero arithmetic
or checked decision errors. All base obligations settle. Seven stress histories
end with unpaid lender claims: one no-collection-recourse case ($2,524.62), and
six high-demand cases ($6,285.11 in total across six separate histories). Do not
claim universal financing closure. Full records: results/terminal_insolvencies.json.
Those unpaid balances are measured at the modeled terminal dates; later interest,
recovery and insolvency resolution are not modeled. Renewals use utility and
procurement choices, then assume acceptance and full collection without a second
failure/correction/warranty/default cycle. These limits qualify the lifecycle.

QUICK DEMONSTRATION — PYTHON STANDARD LIBRARY ONLY

Run from this directory in a separate replay copy so the supplied evidence is
preserved. The compiler and simulator require Python 3.10+ syntax; the measured
environment was Python 3.12.14 on Linux. Other Python/OS combinations have not
been qualified by this study.

  python src/eventweaver.py inspect --spec data/demo/spec.json
  python src/eventweaver.py compile --spec data/demo/spec.json --output replay/eventweaver.v
  python src/eventweaver.py compile --spec data/demo/spec.json --format ir --output replay/eventweaver_ir.json
  python src/eventweaver.py simulate --spec data/demo/spec.json --trace data/demo/trace.json --output replay/demo_outputs.json
  python src/successor.py inspect --spec data/successor/spec.json
  python src/successor.py compile --spec data/successor/spec.json --output replay/successor.v
  python src/successor.py simulate --spec data/successor/spec.json --trace data/successor/trace.json --output replay/successor_outputs.json

The CLI creates output parents. The original demo accepts at logical ticks 8, 9
and 20; tick 9 may carry both independent output bits. A deadline veto cancels
one group at tick 19; reset clears pending history. See data/demo/demo.txt and
data/demo/expected.json for the exact trace and masks.
