THE POSSIBILITY ENGINE — LATEX SOURCE EDITION

The complete master is AGI_Alpha_Possibility_Engine.tex. Keep every included
section file, references.tex and the figures directory beside it. The two-page
executive brief has its own master, Executive_Brief.tex.

Build in this directory with TeX Live 2023 or a compatible pdflatex installation:
  pdflatex -interaction=nonstopmode -halt-on-error AGI_Alpha_Possibility_Engine.tex
  pdflatex -interaction=nonstopmode -halt-on-error AGI_Alpha_Possibility_Engine.tex
  pdflatex -interaction=nonstopmode -halt-on-error Executive_Brief.tex
  pdflatex -interaction=nonstopmode -halt-on-error Executive_Brief.tex

The publication build set SOURCE_DATE_EPOCH to 2026-10-28 12:00:00 UTC and
FORCE_SOURCE_DATE=1. This fixes TeX's document date metadata; exact PDF bytes
also depend on fonts and TeX distribution. The edition's distributed files
are identified by SHA256 in the companion manifest.

Packages used: fontenc/inputenc, mathpazo, geometry, microtype, graphicx,
booktabs, longtable, array, amsmath/amssymb, xcolor, tikz, enumitem, fancyhdr,
titlesec, xurl, hyperref and caption. No shell escape, network or external
image generation is required to compile this source bundle.

Every figure PDF needed by LaTeX is included. Source plots and their measured
or modeled input records are in the complete reproducible companion:
  src/analyze_results.py
  results/derived_economics.json
  results/business_confirmation.json
  results/business_confirmation_journals.jsonl.gz
  data/demo/

The paper's full browser edition is generated by web/build_browser.py using
pandoc and bundled local assets. See Developer_Handoff.txt in the companion
for the executed tool versions, reproduction commands and qualification limits.

This is a bounded research edition: STOP standalone EventWeaver expansion;
no replacement flagship earned. The LaTeX source is the complete paper, not
a template or a plan for an unperformed experiment.
