## What was constructed

The instrument reads exact QIF 2.1 semantics, preserves raw signs and units,
constructs CAD-to-requirement witnesses, evaluates record predicates and returns
source-specific acquisition obligations. A statement about all selected values
can survive an unknown permutation. Physical family coverage, individual feature
identity, specimen identity, measurement adequacy and release authority still
need separate evidence. The supplied family selectors, typed missions, public
CAD/QIF sources and existing integrated graphs are disclosed as supplied inputs.

The first useful result is an audit and an exact evidence request. The instrument
does not silently repair units, replace a stronger requested outcome with that
audit, or grant authority because an earlier report passed. The proposed offering
links the real capability to private adaptations and contractual conditions;
the frozen financial program remains artifact-agnostic and did not execute
acceptance-gated sales.

  negative current-software pilot.
