## Independent checking and reproduction

The evaluator imports no instrument implementation. It uses standard-library XML/Expat, Decimal, raw
STEP inspection and direct OCP reimport. OpenCascade is shared infrastructure, not independent physical
ground truth. It checks exact sources, mission and code/dependency identity, units, literals, quantity
coverage, status ancestry, source references, counterexamples, geometry candidates, purpose and authority
separation, and actionable evidence requests.

Nineteen Plate-only adversarial checker tests passed before freeze. Strict mypy passed on four implementation
files and Ruff checks passed. Installed Black had a pathspec import error; Ruff formatted the files.
These focused tests are not the repository's complete release campaign.
