# Retained operating method v1: a claim with an executable witness

Origin: Plate-only development in this edition. This is an operating-policy
artifact, not model fine-tuning, reinforcement learning or a new mathematical
algorithm. Existing unit analysis, source checking and quantifier reasoning are
established expert practice. The candidate improvement is their compact,
reusable execution order and output contract for heterogeneous inspection
packets. No outcome gain is guaranteed.

For each useful requested decision, use this short sequence:

1. **Name the exact decision and quantifier.** Distinguish every selected recorded
   value, every physical member of a feature family, one named feature, one
   specimen, and whole-part release. Keep the user's original requirement.
2. **Bind the claim to literal source objects.** Record file hash, version, object
   IDs, parent result, raw value and raw tolerance. Resolve references before
   using labels. A label contradiction refutes a proposed join; it does not
   discover the true join.
3. **Execute the smallest discriminating calculation.** Apply the exact schema's
   unit/default rule; form the literal interval; test all relevant recorded
   values. If changing metadata is requested, run it as a separate counterfactual
   with an explicit change list. Preserve negative tolerances as defects to
   resolve, not absolute values.
4. **Make the witness falsifiable.** For a universal assertion, produce either
   a complete finite check or an explicit violating value/assignment. If the
   answer could depend on an unknown permutation, exhibit two compatible
   assignments with different feature-specific consequences. Do not infer
   physical coverage from numerical invariance.
5. **Deliver the precise next request.** Name the missing source object,
   authority, specimen/feature relation, standard interpretation or measurement
   evidence and the decision it would unblock. Separate numerical entailment,
   evidence sufficiency and current permission. A prior report is evidence, not
   permission to execute a new mission.

Output per job: requested decision; directly supported facts; executable
calculation/counterexample; remaining conditions; decision-specific acquisition
request. Prefer one compact reusable script over repeated manual transcription
when the cost warrants it. Stop when the question is answered; don't broaden an
inexpensive check into a new research campaign.
