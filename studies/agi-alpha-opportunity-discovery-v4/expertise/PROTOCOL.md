# Small hosted-model operating-method experiment

Frozen before recipient dispatch, 27 October 2026. Four fresh useful jobs from
Box/Cover sources curated by an independent agent after Plate-only method
construction. The jobs share one historical assembly and are not four sampled
customers or independent discovery campaigns. The evaluator's mandatory criteria
are frozen outside the agent packet. The same supplied source selectors, source
files, schema-unit evidence and generic local tools are available to all arms.

H: estimated scope-matched human engineering service; no human trial or quote.
U: a competent ordinary request to the same hosted model, including permission
   to use tools, inspect evidence and correct mistakes. No deliberate handicap.
E: the same model plus an established expert source-audit procedure (scope,
   requirements, provenance, semantics, calculations, independent checking and
   bounded conclusions).
E+: E plus the versioned method in METHOD-v1.md learned during Plate development.
   The new manufacturing core or its completed reports are not supplied in this
   cheap prompting comparison; the core's transfer is tested independently.

Each fresh recipient gets an independent conversation without parent history,
8 total tool calls and at most 1,600 answer words across the four jobs. All may
write and run their own conventional code. Tool and output ceilings are matched;
exact inference tokens, billing, hidden model snapshot and active model latency
are not exposed. The study cannot assert exact dollar-budget matching or complete
cost savings. Record observable calls, wall windows, retries, code, corrections,
failures and any requested customer clarification. Unobserved quantities are
null, not zero. No actual customer participates, so actual customer effort is
unmeasured; a request for more evidence is not assumed to cost nothing.

Agents must not read protected oracles, prior outputs, sibling answers, the
retained instrument or confirmation reports. These are instruction-enforced
boundaries in a shared filesystem, not hostile-host isolation. The public nature
of sources and possible model pretraining contamination remain limitations.
No new training, selection or retuning occurs on these four jobs. Each receipt
is preserved even if its answer fails. Evaluate all mandatory criteria and fatal
unsupported physical claims. Accepted outcomes at the common ceiling are the
primary comparison. At matched accepted quality, complete costs remain unknown
unless the necessary telemetry is actually available. No salary anecdote values
this method. Optional Gym practice is not run without an identified worthwhile
failure and a separately frozen fresh test.
