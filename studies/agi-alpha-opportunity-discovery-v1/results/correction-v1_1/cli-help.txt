usage: continuity_v1_1.py [-h] --packet PACKET --mission MISSION --events
                          EVENTS [--mode MODE] --out OUT

Independent snapshot event assay. No event detection, chronology or cumulative
mutation.

options:
  -h, --help         show this help message and exit
  --packet PACKET    One qualified original snapshot
  --mission MISSION  Fresh local purpose and authority fixture
  --events EVENTS    JSON list: each event is applied independently to the
                     same original snapshot
  --mode MODE        Only independent-snapshots is supported; sequential or
                     other intent is held
  --out OUT
