# Independent review of the executable study

Review date: 27 October 2026. The reviewer used a separate agent role within the same research team.
This is procedural independence, not independent institutional replication, hidden code execution,
or external customer validation.

## Finding and disposition

The final numerical records are consistent with the stated operational acceptance rules and query budgets.
The review found a material information-boundary defect in the original enterprise replay and reproduced it
before correction. The corrected replay reserves cash and capacity using the declared maximum before
reading any protected task outcome. It then charges the observed cost and releases unused reservations.
Both the original failure and the corrected behavior are retained.

The final review executes 20 checks and passes all 20. It covers 1,728 primary and 1,728 robust confirmation

The result is in `independent_review.json`; `review_probes.py` reproduces it. Passing these checks does not
validate the assumed market, prices, simulator expense, physical relevance, model API behavior or live authority.

## Material issue repaired without changing selected policies

Original `economics/run_economics.py` read a fresh row's actual query count before committing a job.
For direct search, the early stopping point is future information. Two artificial boundary cases expose the
defect: a declared 96-query job with enough remaining cash for its eventual two-query success but insufficient
cash for its declared envelope, and the same job with only ten queries of remaining capacity. The original
code delivered both jobs after reading their future outcomes.

`probe_reservations.py` runs these cases against the retained original source and the corrected source.
`reservations_before_correction.json` records both failures. `reservations_after_correction.json` records
both correct refusals, with zero reads of the protected outcome index. The intermediate receipt named
`reservations_original.json` happened to capture the already corrected code during the parallel repair;
its embedded source SHA-256 is authoritative. It is retained as an additional corrected check, not represented
as the original failure.

The review also identified a hidden-truth dependency in operational warranty reserves and a missing diagnostic
assessment charge. The revised code uses observed invoices and paid refunds for operational reserves,
reserves known obligations before expansion, retains failed specialist invocation costs, and charges the
32 distinct healthy/faulty diagnostic observations per development task. These changes are documented in
`economics/RESERVATION_CORRECTION.json`. The original code and original policy freeze remain in
`economics/history/`; the original selected routes, prices and admission decisions are unchanged.

The final economic source hash is
`35e597ba041946821d491478001bb602dbf58ddcf6403ef421644e3f52651588`.
The final result explicitly reports that this source differs from the original policy-freeze source.
That is the disclosed causal/accounting amendment, not an unnoticed source substitution. No confirmation

The implemented and separately frozen acceptance is feasible verified action, with regret reported only as
research analysis. The paper must use that operational definition and disclose the prose erratum rather than
claim global optimality. The frozen offering text also over-specified a response model for every design job.
`economics/CONTRACT_CLARIFICATION.md` preserves that text and explains that direct search delivers the verified
plan and trace; a required validated response model belongs to the separately costed model offering.

The technical seed schedule uses stride 101 for learning and 107 for the fresh task sets. The protocol's shared
stride field should not be interpreted as overriding the executed learning-source schedule. Exact sources,
artifacts and observations remain available for reproduction.

29 interface controls and the 20 final independent-role checks. An earlier Black invocation could not start
because the environment lacked a compatible `pathspec` component; that optional formatter was not counted
as passed. Full repository CI, software publication qualification and deployed security are separate gates.
