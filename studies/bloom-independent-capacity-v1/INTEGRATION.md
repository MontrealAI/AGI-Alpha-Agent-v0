# Integration with AGI ALPHA, SUCCESSOR Ω and the four repositories

This edition adds a small executable research harness to existing published
Alpha machinery. It runs the actual native dispatcher in a disposable local
institution, with independently checked dependency-impact and coverage work.
It does not claim that the whole Alpha distribution was installed or that this
new scientific task was admitted by Manager, Jobs or Fleet.

## What ran

Eight unchanged Alpha Python source files are included under
`integration/vendor/alpha_runtime/`. `integration/vendor/SOURCE.json` binds their
original URLs, Git blobs and SHA256 hashes; the upstream Apache license remains
at `integration/vendor/LICENSE`. A narrow package loader preserves relative
imports. The new wrapper calls:

1. `SuccessorStore.create_institution` and `register_release`.
2. `JobDispatcher.seal` with a real `JobGraph`.
3. `dispatch`, `execute_tool`, and `complete` for source-bound installed
   callbacks using native `ExecutionAuthorization`, `JobContract` and `JobResult`.
4. `SuccessorStore.recover`, `Journal.control(True)`, journal verification,
   backup, restoration, and explicit source/context checks.

The public demonstration completed all seven jobs; its signed journal verifies
48 events. Native `stage_calls` spent 7 and reserved 0. Those counts are
invocations, not CPU instructions, detector exposures or monetary units. Callback
and stage CPU/wall time plus native overhead remain separately measurable in
`results/public-demo/native/native_workflow_receipt.json`.

## The seven stages are real data dependencies

The labels below are explicitly mapped to native job families; they are not
invented upstream API names.

| Stage | Native family | Concrete input → output and check |
|---|---|---|
| Identify 🔍 | `constitution` | Selected case → immutable case artifact, objective, local scope and authority ceiling. |
| Out-Learn 📚 | `evidence` | Case bytes → validated graph, dependency direction, roots and observability limitation. This is parsing/inspection, not a claimed learned discovery. |
| Out-Think 🧠 | `challenge` | Graph and known query batch → conventional workload estimates and selected method context. |
| Out-Design 🎨 | `formation` | Bound case/method → actual graph-specific `operator.json` and construction decisions/cost. The public example uses an ordinary reverse-index construction. |
| Out-Strategise ♟️ | `admission` | Exact operator/case → independent semantic qualification, world/policy/environment identities and payload budget. |
| Out-Execute ⚡ | `verification` | Qualified operator → `impact.json`, checked against independent BFS for each query; exact consumed operator digest retained. |
| Out-Evolve ♾️ | `renewal` | Accepted impact answers → distinct minimum-coverage `successor.json`, checked against exhaustive subset enumeration, then stop. |

Each stage reads the earlier accepted artifact and verifies its saved bytes.
The successor records `consumed_impact_sha256` and
`consumed_operator_sha256`; its selected cover actually depends on those impact
answers. Controlled withholding/replacement interventions assess reusable
information, not a proprietary or economic moat. Conventional replacement
restored the same exact results in all 216 eligible fresh replacement trials.
No second successor is manufactured after the cover plan. No-change cases end
with an empty plan; infeasible coverage is explicit.

The local native compiler requires all seven lifecycle families. Every stage in
this demo performs the listed finite work. It neither invents additional model
training nor invokes an absent external system to fill a diagram.

## World, Policy, Proof and Authority remain separate

| Boundary | Actual native types / fields | Meaning in this edition |
|---|---|---|
| World | `WorldProgram`: `world_id`, `artifact_digest`, `inputs`, `state`, `transitions`, `predictions`, `invariants`, `outputs`, `uncertainty`, `assumptions`, `evidence`, `falsifiers`, `revision_history` | A declared graph and its observability limits; a hash cannot establish missing dependencies. |
| Policy | `PolicyProgram`: `policy_id`, `artifact_digest`, `objective`, `decision_rules`, `admissible_actions`, `constraints`, `abstention`, `escalation`, `dependencies`, `configuration` | Exact reachability/coverage, positive weights, allowed operators, resource limits, stop and refusal behavior. |
| Proof | `ProofProtocol`, `ProofReceipt`: candidate/comparator/environment/evidence bindings and recorded measurement/claim scope | Structural schema records and local semantic checks have explicit scope. A valid hash or local signature is not superiority or commercial validation. |
| Authority | `AuthorityEnvelope`: `grant_id`, mission/release/subject/issuer bindings, actions/tools/targets/resources, validity and context | No AuthorityEnvelope is issued. Native local assignments permit only the installed pure fixture callbacks; no external operation is authorized. |

`integration/adapter.py` can translate an explicitly configured source-bound
study into genuine native schemas. Those structural records are separate from
the actual signed dispatcher run and do not retroactively preregister the
science, admit a foreign campaign, or provide production trust.

All native signing seeds and the dummy token are **public deterministic test
material**. Controller, producer and verifier roles are under one experimental
control; they are not independent organizations. The wrapper accepts only
`execution_mode: synthetic-local`, `authority: none`, and installed callbacks
whose source paths are explicitly bound and rechecked. It does not execute
Python supplied by imported JSON. It relies on reviewed pure callbacks and is
not an isolation boundary for hostile Python plugins.

The inspected Manager/Jobs language is
`successor-discovery-work-request/v1`. Its binding keys are `missionId`,
`revision`, `purposeDigest`, `charterDigest`, `modelDigest`, `sourceDigest` and
`evaluatorDigest`; its six stage identifiers are `learn`, `think`, `design`,
`strategise`, `execute`, `evolve`. That finite language differs from the native
seven-family dispatcher mapping above.

Their receivers expect authentic finite campaign semantics, not arbitrary JSON
relabelled as a Discovery campaign. Capability inspection states
`local-inspection-only`, `externalExecution: unprovisioned`,
`submission: unsupported`, and `authority: none`. Draft commission fields remain
`status: DRAFT_NOT_SUBMITTED`, `capBaseUnits: "0"`; settlement is
`not-connected`. These source facts are not claims that a rejection test for the
new task was executed. Manager USDC6 accounting and Jobs AGIALPHA18 accounting
are distinct. No exchange rate or token-value equivalence is assumed.

Fleet's `agi-fleet/successor-request/v1` binds `schema`, `capsule`, and `plan`.
Its controller checks current principal/session, scope, ticket expiry, runtime
and policy before dispatch; states include `reserved`, `dispatched`,
`blocked-or-uncertain`, and `stopped`. A returned local controller record remains
`independent: false`; checking it does not create permission or production
qualification. Existing held integration lanes remain governed by their owners.

## Customer-owned export and inactive restoration

The demo exports ordinary readable JSON, an interactive offline report, exact
source/context commitments and a real native recovery ZIP. The ZIP honestly
records `contains_private_key: true`; the accompanying scope states that these
bytes are public deterministic TEST ONLY, not external credentials.

The wrapper restores the actual journal, then rechecks graph, policy,
environment, installed source and artifact conditions. The resulting receipt
has `stopped: true`, `global_control: paused`, `active_proofs: []`,
`active_grants: []`, and `continuation_authorized: false`. Native smoke evidence
also confirms dispatch from a restored stopped institution is rejected.

A parent hash, earlier receipt, or successful byte restoration does not renew
proof or authority. New execution requires appropriate current validation; the
fixture deliberately cannot supply external authority. Exported history is
inspectable and portable without an indefinite service or support loop.

## Integration does not change the measured verdict

The actual dispatcher connection is useful execution evidence. It is not a
reason to count native invocation units as money, label local roles independent,
or infer a four-installed-product acceptance. Scientific qualification, native
structural acceptance, actual dispatch, external admission, and commerce remain
separate claims. The source-audited contracts and unconnected routes do not
increase the study's accepted-outcome denominator.
