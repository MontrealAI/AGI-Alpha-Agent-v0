A falsifiable verdict

Five gates. Every result stays visible.

The final system and analysis were frozen before confirmatory cases were opened. Paired cases, independent reference calculations, counterfactual replay, fresh reproduction, and disclosed reporting deviations make the result inspectable. Reproduction was conducted within this research session; it is not an external laboratory replication.

G1 · Reproducibility

EARNED

Deterministic replay matched 2,544 records, all 48 case hashes, and all 480 operator hashes. Measured timings are retained separately; they are not expected to reproduce bit for bit.

G2 · Qualified quality

EARNED

3,024 / 3,024 eligible fresh trials returned the exact answer. 432 / 432 boundary trials behaved correctly. Qualification is conditional on the supplied graph being complete and correct; an omitted real dependency can still produce a false-safe answer.

G3 · Practical CPU advantage

UNMET

The required improvement was at least 10% against both strong comparators. Confirmatory candidate/expert CPU ratio: 0.971 [0.938, 1.005]. Against reverse-index analysis: 0.958 [0.916, 0.998]. Neither upper bound was below 0.90.

G4 · Successor benefit

UNMET

The successor really consumes predecessor artifacts, but the required 20% receiver cost reduction was not established. Retained/rebuilt CPU ratio: 0.778 [0.751, 0.806]; fresh reproduction: 0.805 [0.764, 0.855]. Required upper bound: below 0.80.

G5 · Full-cost economics and demand

INCOMPLETE

No cash revenue, firm offers, or independently supported customer demand. The ledger reconciles 54.2661 documented CPU seconds across five scientific campaigns, five native runs, and three retained early calls. Human work, service allocation, and other material costs remain unknown. Modeled margins are conditional and do not establish competitive advantage.

Useful today

From a package change to a verified next action.

The public practical case resolves pinned Alpha and Manager npm lockfiles into 1,136 nodes, 2,000 dependency edges, two application roots, and 17 package-change queries. An independent Node ancestry check audits resolution. This acceptance case is excluded from confirmatory evidence.

Before · uncertainty

A changed package, two build roots.

Transitive dependency paths are hard to inspect by hand. Guessing which root is affected can omit necessary work or trigger work with no supporting dependency path.

After · inspectable capacity

The conventional operator earns the job.

The expert default chooses a reverse index by the declared operation estimate. Qualification checks root ownership, strictly descending path witnesses, unset cells, and edge closure. All 17 answers match the independent reference.

The successor selects an exact minimum-weight cover of the affected roots. Its three coverage options use explicitly synthetic weights 7, 5, and 10. They are not real test executions, measured test durations, prices, or revenue. Sixteen unresolved optional peers are recorded; this declared package graph is not a complete build or runtime graph.
