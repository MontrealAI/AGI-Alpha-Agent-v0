# AGI ALPHA FLYWHEEL — The Advantage That Funds the Next

**Useful inventory checks. Economic payback remains unproven.**

This additive research edition builds a versioned release-inventory intake asset
and connects it to the actual AGI ALPHA Workbench and TRANSFORMATIONAL INTELLIGENCE
catalogue comparator. It preserves the four preceding studies and their results.
It does not install a new operator, change a contract, collect revenue or promote
a capability on the basis of a hypothetical return.

The repository delivery includes a complete
[companion archive](agi-alpha-funded-advantage-v1-companion.zip). Extract that
archive before following the relative file paths and replay commands below.
The complete tree is preserved inside the archive; the repository additionally
exposes the standalone demo and selected review/evidence files.

## The financing result

All **3,360 primary modeled cash scenarios invest zero**. Complete authoring,
inference, operating and customer-attention costs remain unknown. No additional
provider-attention saving was measured. Raising an assumed selling price does not
create an incremental benefit when the alternatives deliver the same accepted work.

A labeled counterfactual illustrates the threshold: assume a 52-job horizon, a
$20 complete incremental construction envelope, $5 price, two-job collection
delay and **an unmeasured 60-second saving per retained use**. The model funds the
actual Alpha asset after job 13 and reaches strict payback at job 46, ending $3.79
ahead. Zero assumed additional attention saving or $10 of maintenance exposure
rejects that investment. This is conditional arithmetic, not a demonstrated
self-financing enterprise. Every modeled investment refers to the same tested
candidate hash, never an unrelated future capability.

A separate three-minute fallback screen examined pack verification and builder
fixtures after the primary HOLD. Both already had strong ordinary reusable tools;
the screen found no measured recurring burden or demand that justified another
framework. No second speculative candidate was built. Its 116.522-second record
and no-build decisions remain in `evidence/FALLBACK_DISCOVERY.json`; this is
post-primary discovery, not a second confirmation or capability-growth claim.

The finite scenario outputs preserve lower demand, paid failures, maintenance,
delayed receipts and resource exhaustion. The initial $100 seed, $20 shared setup,
prices and aggregate cost envelopes are assumptions. No real funds were spent,
collected or transferred. Tokens, appreciation and customer savings are not cash.

## Reproduce and inspect

Core replay needs Python 3.12 and Node.js with the standard APIs used here;
the recorded local runtime is Node 24.22.1. Alpha's repository pin is 22.17.1,
which was not the runtime used for this isolated study. No new packages,
credentials or live retrieval are required for replay.

```sh
python3 reproduce.py --output /absolute/new-directory
```

The output must be a new directory outside the study. The runner verifies frozen
inputs and dependencies, regenerates confirmation from archived bytes, executes
all three arms, independently audits packs, recomputes and audits economics, and
checks the demonstration handlers. See `REPRODUCIBILITY.md` and `demo/README.md`.
Recorded timing values vary by machine; semantic outputs and accounting rules
must agree. Replay reproduces code execution, not model construction or its bill.

To create one new local pack:

```sh
node implementation/run_one.mjs alpha request.json /absolute/new-pack-directory
```

`request.json` contains `left` and `right`, each with `text` and `format`. Formats
are `auto`, `json`, `csv` and `sha256sum`. The contract and exact bounds are in
`protocol/PROTOCOL.md` and its two pre-confirmation amendments. The downstream
guide and Workbench have smaller cell/output bounds, so some parser-valid inputs
refuse as complete deliveries. Nothing is silently truncated.

To rebuild the paper (XeLaTeX, DejaVu fonts, matplotlib and NumPy required):

```sh
python3 publication/make_figures.py
cd publication
xelatex -interaction=nonstopmode -halt-on-error paper.tex
xelatex -interaction=nonstopmode -halt-on-error paper.tex
```
