# Independent public-tool supplement

The retained conventional constructor remains the matched primary comparator. This supplement establishes what the public `oasdiff` tool can already deliver after competent format conversion. Its semantic findings cover requests, responses, HTTP methods and media types beyond the study's selected structural GET response surface, so its counts and runtimes are not substitutes for matched dossier acceptance.

The production source freeze and original acquisition manifest were checked before every command. Neither was edited. The three unavailable preregistered questions remain blocked; no version was substituted or redownloaded. All commands have captured stdout, stderr, exit status, wall time, child CPU and maximum resident set in the accompanying JSON records.

## Useful decisions supported

For v23→v24, the public tool identifies `VirtualSize` becoming optional in the `GET /images/json` and `GET /system/df` response contracts. A client maintainer can review assumptions that those fields are always present and add handling for their absence. The output repeats the system-data finding for two declared media types; five tool findings therefore do not mean five distinct client failures.

For v24→v25, zero reported breaking findings coexist with 77 changelog items, including optional response additions and removals. This illustrates why the separate exhaustive structural dossier can be useful without claiming to have found a new comparison algorithm. The source documents may still differ from runtime behavior; neither tool result is a live compatibility certificate.

Default `oasdiff` output also explicitly cautions that some `allOf` comparisons are branch-wise. Its public `--flatten-allof` option is an available practical method, not an absent agent capability. This supplement preserves the default output and does not claim semantic conjunction equivalence, runtime enforcement, or a capability absent from public tools.

## Cost and reproducibility

The versions are `oasdiff 1.34.1`, `swagger2openapi 7.0.8` and Node `v24.22.1`. `tool-source-binding.json` binds the executable, package lock and installed converter dependency files. Dependency contents are not copied into the repository. The original pinned lock remains under `comparators/conventional/tools/`.

The first pass ran 22 commands in 5.21646 seconds wall and 7.51155 CPU seconds. The explicit follow-up ran five commands in 1.06390 seconds wall and 1.41140 CPU seconds. Combined observed supplement cost is **6.28035 seconds wall and 8.92295 CPU seconds**, including invalid/raw attempts, conversion, validation, diff/changelog generation, source checks and packaging. These are elapsed and processor measurements, not human-only time or an inference bill. Tool acquisition, original source acquisition and historical construction remain separately recorded and are not silently added again. Complete monetary and human-attention costs remain unknown.

Reproducible sources, command arguments and every partial/result artifact are in `oasdiff-primary-supplement/` and `oasdiff-normalized-followup/`. The follow-up is explicitly post-primary. It strengthens the public alternative and does not revise the preregistered primary outcome.

## Démonstration française

Le comparateur public produit déjà des résultats utiles après conversion correcte des spécifications Swagger2. Pour v23→v24, il signale que `VirtualSize` devient facultatif dans certaines réponses. Le responsable d'un client peut donc vérifier les accès à ce champ et prévoir son absence. Une sortie vide obtenue sur un format non validé ne prouve pas l'absence de changement.

Les trois questions dont la source est indisponible restent des échecs d'acquisition. L'échec initial du convertisseur sur v20 est conservé, puis un essai complémentaire distinct utilise le JSON normalisé déjà figé. Les deux coûts sont comptés. Ces résultats démontrent une capacité pratique d'un outil public; ils ne démontrent ni une demande payante, ni un avantage du graphe, ni la compatibilité avec le comportement réel du serveur.
