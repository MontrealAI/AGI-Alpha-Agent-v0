## What the experiments support

### Primary comparison: 12 accepted cells out of 24 planned

Six preregistered questions were assigned to four arms. Three questions were available and accepted in all arms: **12 accepted comparison cells**, representing three distinct version-pair questions. The locked source URLs for `v27.0.0/api/swagger.yaml` and `v29.0.0/api/swagger.yaml` returned 404. This blocked three intended pairs and **12 comparison cells before execution**. No replacement input was selected. A failed locked URL is not a claim that an entire product release is unavailable.

| Arm | Accepted / planned cells | Recorded total CPU, seconds |

| A — retained conventional Python | 3 / 6 | 1.275 |
| B — full Workbench index | 3 / 6 | 4.658 |
| C — shared registry and incremental index | 3 / 6 | 5.305 |
| D — same catalogue and graph selection | 3 / 6 | 4.864 |

These sums include production, independent verification, packaging and small failure bookkeeping; common acquisition is recorded separately. They are one execution per arm/case, not a stable latency distribution or full dollar cost. The conventional route is the practical starting point for this scoped output. Small registry/graph timing differences do not establish graph value. See the [primary campaign](outputs/primary/campaign.json), [calibration](outputs/primary/calibration.json), [input manifest](inputs/acquired/manifest.json) and [registered protocol](protocol/production.json).

### Transfer: competent recipients, preserved limits

Both recipients independently reconstructed an effective scoped implementation before seeing donor code. The primary `v23.0.0→v23.0.6` pair has byte-identical source YAML and normalized JSON: it is a content-identical control. The other registered transfer pair, `v27.0.0→v27.5.1`, remained acquisition-blocked.

A separately frozen exploratory `v27.5.1→v28.0.0` probe contains **332 changed structural addresses**. Parent arms A/B/C/D passed their narrow structural acceptance. Recipient two's previously selected `swagger-spec-validator` gate rejected the first input before its original, transferred-full or transferred-incremental arms ran. Its HOLD and failed-validation cost remain; there was no repair, efficacy retry or third pair. Read-only standards/tool-source adjudication found the particular required/properties guard stricter than the normative relationship, without adjudicating the whole document. Different acceptance preconditions are not a donor performance loss or universal recipient acceptance.

The exploratory probe does not replace the primary result or enter economic calibration.

### Economics: no funded succession under the frozen conditions

The model executed **384 paired worlds** across 24 assumed market cells and 16 seeds, with four counterfactual policies per world: **1,536 enterprise histories**. There were **0/384 worlds with positive operating surplus**, no recovered full historical/setup cost, and no first or second capability investments. Available investment funds stayed zero. All policies retained conventional A because their investment gates did not pass.

Each enterprise starts with modeled USD 1,000 seed capital and a USD 200 reserve. Human effort, demand, willingness to pay, integration, residual attention, support, maintenance, tariffs and business costs are explicitly assumed; executed resource measurements and a sourced wage anchor are separate. The fixed tariff grid contributes to the result: the reference cost floor of USD 35.10 rounds up to USD 65.38, above modeled maximum willingness to pay. This is a failure under the frozen conditions, not proof that every customer segment or price would fail. See the [full economic interpretation](evidence/economics-review/cost-and-result-interpretation.md) and [frozen model rules](src/economics/protocol.mjs).

## Local quickstart — public Moby JSON only

Keep this directory inside the complete repository: the Workbench and Jobs compiler are imported from existing repository paths. Use **Node 24**, **Python 3.12** and **PyYAML 6** for YAML acquisition/normalization. Exact economic replay enforces the recorded **Node v24.22.1** runtime. Java **17** is additionally required only for the canonical GTFS validator; its public 8.0.1 JAR is not vendored, and its URL/hash are retained in the GTFS source manifest. No Docker daemon, account, wallet or new credentials are needed for these local examples.

Run the following commands from `studies/agi-alpha-work-discovery-v1`. Choose a new output name every time; the initial `mkdir` deliberately fails if it already exists.

The first route provides the retained conventional constructor and its independent verifier.
