# Browser development record

This is a separate small demonstration; no native confirmatory task was used to tune it.

1. The first numerical adapter attempt failed before producing a mission: the upstream workbench accepts integer/string canonical JSON, while the initial adapter supplied raw decimal configuration. The fix places numerical payloads in exact JSON strings at the unchanged workbench boundary. `attempt-01.json` preserves the failure. No vendor source was changed.
2. The first complete four-mission implementation produced valid A/B/C/D outputs and recorded real construction/execution parent calls. Its reference did not yet charge cached-factor retrieval. That omission was corrected for both unchanged-network reference calls before the browser execution freeze. No numerical method or task was altered to seek a win.
3. A source review found that concurrent control writes could race compare-and-swap revisions. Saves were serialized through a write queue with per-run revisions. It also tightened stored pending-reservation validation and preserves human control events/counts across the mission's copied result state.
4. UI QA using fixed 10–15 ms timers sometimes attempted to click STOP/pause while the button was still disabled during initial persistence. The failures are preserved in `fixed-timer-ui-qa-failure.json` and `fixed-timer-recovery-qa-failure.json`. Tests were corrected to wait for an observed pending reservation and enabled control. This correction changed QA, not the browser numerical candidate or its outcomes.
5. Final QA binds its results to the separately recorded browser execution identity. All prior scientific editions and native confirmation evidence remain unchanged.

The browser's numerical tariff omits hashing, serialization, rendering and storage, now explicitly disclosed in the UI and README. Its resource allowance is not called earned capacity. Final live numerical results and reconstruction/reference costs are in `qa/fresh-evidence.json`; the browser remains an educational causal demonstration separate from the native full-cost result.
