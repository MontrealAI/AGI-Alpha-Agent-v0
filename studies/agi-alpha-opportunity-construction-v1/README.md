## Reproduce

Use CPython 3.12 and Node.js; exact tested versions are CPython 3.12.14 and Node v24.22.1. The constructor, independent oracle and commercial simulation use standard-library Python. The requirements file supplies native cryptographic and optional publication dependencies.

From an authorized local checkout of the repository containing this directory:

```bash
python3 -m venv /tmp/agi-alpha-care-env
/tmp/agi-alpha-care-env/bin/pip install -r studies/agi-alpha-opportunity-construction-v1/requirements-research.txt
/tmp/agi-alpha-care-env/bin/python studies/agi-alpha-opportunity-construction-v1/src/reproduce.py --all --output /tmp/agi-alpha-care-reproduction
```

The wrapper writes outside the immutable study directory. It replays 109 origin/original/boundary cases with the corrected instrument, 60 independent oracle cases, 20 fresh-corruption fixtures and 20 commercial day witnesses. It reproduces the corrected 1800-world confirmation and 1800-world broad sensitivity byte-for-byte, verifies frozen input/source hashes, rechecks native commitments and exercises local authenticated research access. Replaying published cases is reproduction, not a new fresh experiment.

For a faster staged run:

```bash
python3 studies/agi-alpha-opportunity-construction-v1/src/reproduce.py --technical
python3 studies/agi-alpha-opportunity-construction-v1/src/reproduce.py --economics
python3 studies/agi-alpha-opportunity-construction-v1/src/reproduce.py --verify
```

Run one declared case directly:

```bash
python3 studies/agi-alpha-opportunity-construction-v1/src/e1_instrument_v2.py compare \
  --input studies/agi-alpha-opportunity-construction-v1/technical/origin_case.json \
  --output /tmp/agi-alpha-care-origin.json
```

No paid model API, wallet, live ENS, customer account or on-chain action is required. Source research and model-generated discovery reports cannot be regenerated deterministically from an unobserved serving checkpoint; their original bytes, queries and sources are preserved.
