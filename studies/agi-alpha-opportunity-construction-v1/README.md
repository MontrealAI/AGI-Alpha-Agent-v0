## What the study establishes

A bounded opportunity search led to a **confidential pre-emergency reserve-pool feasibility instrument**: three parties can jointly check all declared simultaneous-demand scenarios while the computation releases one aggregate bit per input world. An actual three-process MPyC implementation agreed with an independent assignment oracle on **240/240 fresh synthetic worlds**. A separately tasked recipient executed the harder 41-scenario successor mission. An ordinary library with identical information tied exactly.

The same offering has **modeled contribution of $9,323.85 per accepted-equivalent assessment at a $12,000 fee**, after variable costs including failed bookings. Its **complete 180-day venture loses $30,146.88 on average** in 1,000 fresh modeled worlds. A separately frozen follow-up testing all nine conditional-commitment policies on 1,000 new worlds produced no launches. **No launch is the best tested decision.** Actual collections are zero; complete actual research expenditure is unknown.

This is a tested application hypothesis and reusable research instrument. It does not establish a new cryptographic method, a world's-first offering, superior discovery to humans, production confidentiality, physical grid qualification or a profitable operating business.

## One connected mechanism

The discovery record begins with broad needs and fixed search budgets, not this final application. Two ordinary and two expert hosted searches produced twelve candidates. A label-masked prior-art review rejected the first round; an adaptive second round remained bounded. The final application is explicitly attributed to the coordinating agent's cross-round synthesis. Ordinary search contributed the reserve problem; expert exploration contributed ways to inspect meaning and information boundaries. This is not an E-over-U discovery win.

The construction changes an information-sharing restriction: compute the common feasibility predicate across private inputs instead of requiring central possession of every raw constraint. It preserves all single/pair scenarios and, in the successor mission, all triples; distinct assets, eligibility, availability and withholding remain binding. A correct negative assessment is a useful accepted answer. It is not a failed delivery or proof that real-world reserve collaboration is impossible.

The native integration reuses existing Insight serialization, Discovery parsing, Nova-Seed project/capsule functions, FusionPlan compilation and MARK arithmetic. Insight's generic-schema refusal is preserved. The artifact functions package the supplied opportunity and work plan; they do not discover or validate the scientific claim. Native signatures and a transactional journal enforce local query grants. A simulated `successor.agent.agi.eth` mapping authenticates only the existing worker role. Live ENS, token operations and funds transfers are zero.

## Quick reproduction

Use Python 3.12.14 and install the small native-authority dependency set into your own environment:

```sh
python -m pip install -r requirements-study.txt
python -B src/reproduce.py --destination /tmp/reserve-reproduction-01 --port 19100
```

Choose an unused destination. The runner verifies every technical freeze binding, regenerates both cohorts, executes three actual localhost workers for each mission, replays the identical ordinary library, and compares every scientific result and input byte. It does not overwrite the study. See [REPRODUCE.md](REPRODUCE.md) for economics, authorization, native artifact and publication commands.

The MPyC 0.11 wheel and its unchanged Python sources are bundled under their original MIT license. The worker uses that source closure directly. No model API key, live ENS identity, wallet or paid customer connection is needed for reproduction. Replaying deterministic seeds is a reproducibility check, not a new prospective experiment.

## Smallest useful next validation

The immediate unknown is whether a real coalition would fund and act on this exact information product. Before paying for production readiness, seek one consenting three-owner group with a funded decision, a written acceptance predicate, disclosed data-preparation burden and a real procurement timetable. Test whether an approved confidential broker or existing sharing provider already supplies a sufficient outside option. Stop if the bit cannot change that decision, members cannot authorize the inputs, or willingness to pay cannot support readiness and acquisition.

The model's conditional-launch threshold requires four high-value $18,000 commitments in its illustrated conservative case. A controlled positive branch demonstrates the rule can pass; it does not demonstrate those buyers exist. All nine prospective conditional policies failed to launch under the unchanged sparse pipeline. Additional Gym work and specialist retention therefore remain optional future proposals, not an executed investment or presumed engine of growth.
