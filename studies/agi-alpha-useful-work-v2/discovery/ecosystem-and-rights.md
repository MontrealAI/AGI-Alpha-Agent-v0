# Verified ecosystem roles and reuse rights

This component study executes a local, source-pinned dependency assessment. It
does not turn a merged source change into a released or production-qualified
offering. The prior source/release audit is preserved byte-for-byte under
`prior-ecosystem-audit/`; its dated release and workflow states remain historical
snapshots. The current first-delivery handoff independently rechecked Alpha main
at `92064005b55d4fec0effbb2acacc8403bb551f3e`, its instructions, and the identical
consumer/native-lock Git blobs. That check supplies neither release acceptance
nor a new operator policy.

## AGIALPHA and USDC routes remain distinct

The preserved contract audit verifies source functions, not deployed state or
transaction execution:

- **Alpha Ascension AGIALPHA18:** bounty escrow, bids/stakes, awards, submission,
  committee validation, refunds and payout; AscensionMark maintains restricted
  contribution reserves and approved bounty allocations. Reserve principal is
  not enterprise profit.
- **Jobs v0 AGIALPHA18:** source token
  `0xA61a3B3a130a9c20768EEBF97E21515A6046a1fA`, immutable reward escrow,
  staking/slashing and role-specific fee/reward mechanisms. Token holding alone
  does not imply unrestricted enterprise-profit rights.
- **Manager USDC6:** a different immutable six-decimal token route, with escrow,
  performance/validator/dispute bonds, exact incoming transfers, deferred claims
  and reserved-balance-aware withdrawals. Its route-specific recipient splits
  are not the provider's operating profit margin.

No transaction is needed to demonstrate this useful local work. Token issuance,
appreciation, buybacks, distributions, holder rights and financial authority are
not inferred. The new component packet does not alter contracts or combine
USDC and AGIALPHA obligations into a single fungible cash balance.

## Rights and active-use conditions

`native/LICENSE.Alpha` and `canonical/LICENSE.Alpha` preserve the original Apache
2.0 notice. Vendored AGIJobs retains its MIT notice and upstream provenance.
Each prepared Python environment preserves all ten distribution notices and an
index mapping them to exact official wheel identities: seven MIT, Starlette and
idna BSD-3-Clause, and typing-extensions PSF-2.0. New curator/replay source is
marked Apache-2.0. A public source handoff containing Alpha consumer code retains
the Alpha notice; a later offline wheel companion must preserve the wheel
notices as well. No private guidance document is distributed in this lane's
public handoff.

An active retained capability must be requalified when its contract, source,
environment, package bytes, import bridge, dependency closure, platform, input
rights or required controls change. A changed manifest without matching source
bytes is not a valid retained identity. Preserve evidence and return an explicit
incomplete decision when required inputs cannot be verified. Fallback is the
preserved complete manual workflow with its legitimate reusable tools and
caches. Retire active use if the need disappears, the scope is unsupported, or
complete maintenance cost is no longer justified by measured useful value.
Retirement does not erase previous negative results or receipts.
