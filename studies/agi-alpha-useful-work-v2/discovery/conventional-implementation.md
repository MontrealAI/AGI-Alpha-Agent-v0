It preserves the original 15-second timeout and 524,288-byte limit. It does not call `create_app`, initialize Journal, create credentials, contact a network service or perform operator actions.

The same 61 common requirements generate ordinary unittest cases. Expected invalid-input rejections count as passing assertions, not discovered defects. Explicit `model_validate`/`model_validate_json` methods, nonfinite materialization and type-exact accepted serialization remain distinct. Raw observations precede assertions; failures retain their observations and traceback. Additional lossless ASGI traces make each current observation artifact approximately 2.20 MB, an explicit storage difference from the smaller manual record.

The unchanged verifier consumes `manual-component-observations/v1` with `native-fastapi-bridge-v2`. Extra producer, unittest, interpreter and raw-trace fields do not replace verification. The assembler checks job/source/worker/environment/observation/verifier identities, pre/post execution bindings, output hashes and pair manifests. Timeout, launch failure, missing evidence or inconsistent bindings prevent a positive decision. Complete negative verifier evidence is allowed: worker exits 0/1 and verifier exits 0/2 have different meanings, with strict integer checks.

If the baseline satisfies the contract and the proposed profile has verified behavioral mismatches, the result is `COMPONENT_REGRESSION`. Missing or invalid evidence produces `INCOMPLETE_HOLD`. Preservation advances only the finite component work package; the current native lock remains pending full application qualification.
