## Run

From this project root, use a new output directory for every edition:

```sh
python analysis/final_delivery_cost_supplement.py \
  --plan analysis/final-delivery-cost-plan-03.json \
  --out ../../deliverables/final-delivery-cost-v2/draft-new
```

This currently emits `DRAFT_NOT_FINALIZED`. Once the exact mandatory receipts have been supplied in a new plan:

```sh
python analysis/final_delivery_cost_supplement.py \
  --plan ../../deliverables/final-delivery-cost-v2/cost-plan-final.json \
  --out ../../deliverables/final-delivery-cost-v2/supplement-01 \
  --finalize
```

It does **not** mean complete monetary cost or investment repayment. Output preserves the exact plan, raw receipts, normalized resource records, extended evidence, canonical account view and its own enclosing construction receipt.
