# Preserved matrix action investigation

These files are byte-identical copies of the executed investigation. The preservation manifest records all original file digests. Historical paths in protocols and reports refer to the workspace where execution occurred.

The numerical records are preserved evidence, not new experiments. To rerun, copy this directory to a separate working directory first so that original protocol and result files remain unchanged. Run `python matrix_action_probe.py`, then `python assess_probe.py`; NumPy and SciPy are required.
