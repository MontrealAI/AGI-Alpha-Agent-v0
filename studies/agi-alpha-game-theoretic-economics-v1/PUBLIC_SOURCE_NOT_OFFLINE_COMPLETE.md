# Public source selection — not a standalone offline companion

This additive research source selection preserves new code, frozen protocols, calibration sources, selected outcomes, paper, demo and upstream copyright notices. It omits the complete campaign cash/event histories, wheel binaries and most inherited raw production evidence. A checkout of this selection alone cannot reproduce the production extension or fully audit all original histories. Use the separately provided complete companion for those operations.

The self-contained HTML includes the four executed decision packets and works without installation. The market core and tests use the included unchanged canonical modules under installed Node.js. The paper PDF is directly readable; its source rebuild needs the documented TeX toolchain. Original source provenance is preserved, and upstream sources retain their own licenses.

From this source directory, installed Node.js is sufficient for these controls:

```sh
node market/tests/test_market.mjs
node market/deployment-robustness/test-funding.mjs
node review/audit.mjs
```

The funding helper is a read-only view of supplied account histories. It does not create money, alter the frozen investment policy or admit a second asset. Full campaign replay/audit and production replay require the complete companion's preserved history/input closure, including wheels where applicable. Figure regeneration also needs the complete recorded data; finished figures and the PDF are included here.

This directory is prepared for review. Creating a GitHub commit or pull request is a separate publication action. It does not replace any repository CI/release requirements and is not permission to run a held deployment or operator profile.
