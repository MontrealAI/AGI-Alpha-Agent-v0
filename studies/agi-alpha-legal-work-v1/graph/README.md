# Two-asset sharing and freshness panel

This panel binds the exact frozen reference resolver and amendment resolver to a bounded Ontario mutual-NDA research scope. It reuses the existing `authority.mjs`, `commitments.mjs` and `selection.mjs` without edits. The same source, dossier, scope and dependency are available to a direct local recipe, an indexed registry and graph selection.

Admission here means **fixture-only permission to reuse the exact source-fidelity composition**. Twelve current-source stage/case combinations over six development documents were checked with the independent evaluator's source-reference and changed-coverage functions. No answer keys entered the panel. Legal-rule classifications, enforceability and professional acceptance remain unassessed; this is not a legal-correctness attestation.

The direct recipe verifies the same implementation, dossier, current authority and dependency bindings without validating a shared graph root. Registry and graph use the existing complete shared-root verification. Construction and per-selection CPU, file reads, bytes hashed, proof checks and authority checks are recorded. There is no artificial registry retrieval delay. A two-asset graph cannot establish a scale or monetary advantage.

Fixture names use the exact direct `*.agent.agi.eth` form. The fixture attestation signer and fixture root writer have different operation grants. They are labels, not accounts or credentials. LIVE admission refuses because there is no authenticated eligible agent. Existing AGI Jobs `*.club.agi.eth` validation, contracts, wallets, monetary allowances and settlement remain untouched.

The commitment suite is inherited **SHA256_RESEARCH_V1** with its explicit research canonicalization and Merkle policy. These roots and proof loops are not asserted to match a deployed Solidity ABI, live ENS namehash or on-chain signature. A historical valid fixture attestation does not authorize current use after scope change, expiry, revocation, supersession or an unvalidated rollback.

Run the local source-fidelity qualification, construct the panel, freeze source and catalog identities, then measure:

```sh
python graph/validate_development.py
"$CODEX_PRIMARY_RUNTIME_NODE" graph/legal-graph.mjs build
```

The distributed `source-freeze.json` must match before measurement. `results/controls.json` retains each refusal reason. Rebuilding after scope or source changes requires a new dossier, attestation and current root; the current package refuses reuse of changed identities. Restoring old bytes alone does not clear a newer scope or lifecycle state. Full human revalidation and maintenance costs remain unknown.
