# Publication source subset

The original equal-access packet was frozen before recipient runs. This directory is a post-run publication subset. It preserves the exact publisher XML/PDF articles and supplements, complete mechanical text companions, and historical task instructions. The historical instructions accurately describe the original run packet, which also included publicly downloadable author-linked OSF data and codebooks. Those OSF files are not redistributed here because an independent license was not verified. Their stable URLs and original hashes are recorded in source_receipt.json.

The publication receipt supersedes the original receipt only for redistribution. Transient signed download query parameters are removed; source content hashes and stable publisher retrieval URLs are preserved. No original recipient input, output, or frozen grading criterion was changed. Do not publish the original full source_packet.tar.gz, which retains the omitted OSF files and unsanitized historical receipt.

The frozen private verifier is published unchanged for audit and expects the original local data layout, including an optional count cross-check from OSF data. Its archived verification result records that check; the published summaries, key, and recipient calculation code are sufficient to reproduce the requested numerical contrasts without those raw data.
