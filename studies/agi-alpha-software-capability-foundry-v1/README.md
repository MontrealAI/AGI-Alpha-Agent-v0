# AGI ALPHA FLYWHEEL — The Software Capability Foundry

**From verified improvements to better means of improving.** Independent research edition 1.0, 25 October 2026.

A bounded Git snapshot reader makes two real source-verification call sites cheaper while preserving exact bytes and output semantics. A prospective experiment then asks whether retaining that capability improves the process of building the next capability against strong alternatives.

The practical repair succeeds. The stronger process claim remains **HOLD_FLYWHEEL_SUPERIORITY**. In one frozen campaign, all 1,344 outputs pass their applicable correctness, lineage and budget checks, but the flywheel/direct-specialist CPU ratio is 1.0574 [95% interval 1.0246, 1.0899]. The direct specialist remains the incumbent. Complete research payback, monetary profit and acceleration remain unproved.

These are 24 generated instances from one public ecosystem on one host. Repeated measurements are aggregated within an instance. The construction mechanism is a bounded deterministic template, not a measured autonomous language-model invention process. Exact hashes and internal role separation do not provide OS isolation or organizational independence.
