# AGI ALPHA productive-transfer contribution

This additive research package preserves the original primary failures and the prior game-theoretic studies. It executes a DUPLEX-inspired source-extraction adaptation through the actual unchanged source-only AGI ALPHA product and SUCCESSOR Workbench, then compares an ordinary retained extractor on separately registered fresh inputs.

**Scope:** inert source-level call binding and a bounded maintenance recommendation. No behavior/security/release approval, actual customer acceptance, payment or deployed-contract change. Complete historical model/authoring costs remain unknown. Actual collections are $0.

## Read first

- `publication/AGI_ALPHA_Productive_Transfer.pdf`: full paper, methods, results and limits.
- `publication/AGI_ALPHA_Productive_Advantage.html`: offline English/French evidence and conditional market demonstration. Open directly in a browser; no account, network fetch or service is required for the embedded experiment.
- `protocol/primary-protocol.json` and `protocol/followup-protocol.json`: separate prospective protocols. Never pool the follow-up with the failed primary.
- `results/independent-audit/FINDINGS.md`: primary source-inventory successes, unfair conventional proof threshold and incomplete handoffs.
- `market/PRIMARY_GATE_STATUS.json`: original production gate stays HOLD.
- `resources/accounting/final-snapshot/cost-summary.json`: final accounting cutoff and what is measured, what remains unknown and how shared construction avoids double counting.

## Runtime and deterministic replay

Python 3.11–3.13 (executed 3.12.14), Node.js (executed 24.22.1). Production and market source use standard libraries and vendored source closures; no framework installation, provider key or paid call is needed to replay the recorded work. The repository's general client version is Node22.17.1; this study did not qualify the entire repository on that environment.

From this package root:

```bash
python src/reproduce.py --campaign primary --out /tmp/alpha-primary-replay-new
python src/reproduce.py --campaign followup --out /tmp/alpha-followup-replay-new
python -m unittest discover -s development -p 'test_*.py'
node --test market/test_transfer_adapter.mjs
```

Use new, nonexistent replay destinations. Replays use the exact recorded prospective A/B responses and freshly execute the product/Workbench. They compare full semantic results except process resource measurements. They are **not new model extractions or additional customer jobs**. Candidate and input identities are verified before execution. Original frozen outcomes are never overwritten.

The unchanged original candidate, model prompt and compiler remain under `src/` and `protocol/`; C2 and common package corrections have separate versioned files. Original source hashes are retained in `protocol/candidate-freeze.json`. Current model-provider identity/billing detail is not fully exposed by the research session; the raw task/prompt/response identities and action logs are retained instead of inventing API charges.

## Market reproduction

The original market sources and protocols are under `market/inherited/`. New source differences are explicit in `market/market-transfer-core.patch`, generated by `derive_transfer_core.py`. All economic cells were specified before outcomes. The production bridge refuses incomplete packages or a favorable subset substituted after evaluation.

The original 166-cell three-arm campaign remains **GATED_UNEXECUTED** because C2 fails the full registered set. Do not run that campaign on a favorable subset. The executed, separately registered A/B diagnostic preserves all four accepted A/B jobs, gives C2 no financial curve, and assumes no unmeasured B benefit:

```bash
node market/accepted-ab-diagnostic/run-diagnostic.mjs --output /tmp/alpha-ab-market-replay-new
python market/accepted-ab-diagnostic/audit-diagnostic.py /tmp/alpha-ab-market-replay-new /tmp/alpha-ab-market-replay-audit.json
```

Its 24 stress cases × 8 paired seeds produced 384 histories, zero investment, zero B-minus-A profit, and twelve profitable worlds per arm; every scenario mean remains negative. See `market/accepted-ab-diagnostic/analysis/ANALYSIS.md` for all cases and the important limits of this structural negative control. The frozen protocol/README inside that directory are preserved prospective documents; current outcomes are in its `results/` and `analysis/`.

An unknown actual monetary cost produces `IDENTIFICATION_HOLD`; explicit conditional scenarios do not fill in that unknown. Hypothetical construction envelopes include unsuccessful attempts and complete integration/authoring allocation. Actual token issuance, savings and valuation are not profit. Only currently available collected operating surplus can finance an earned-funded construction decision. No untested second capability is inserted.
