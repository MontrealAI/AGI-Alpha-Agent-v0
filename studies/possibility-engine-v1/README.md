## What the runnable constructor does

Input is JSON describing two through eight known, labeled sixteen-node graphs, allowed actuator/sensor pairs,
positive integer experiment costs, uncertainty intervals and an observation-time grid. Every graph must satisfy
the supported six-regular identity `A² = 4I + 2J`. The constructor returns a minimum-cost distinguishing experiment
portfolio, analytical output envelopes, explicit infeasibility when appropriate, and executable RC netlists.
It can require survival of one lost experiment or one lost access terminal. A lost terminal removes experiments
using that port; it does not remove a node from the internal network.

The model assumes uniform edge rate, uniform leakage, known labels and bounded gain/error. It is not an arbitrary
thermal-system identifier. The circuit experiment initializes capacitor charge; it is not a fabricated sensor or
a physically executed impulse. See the [frozen acceptance protocol](protocol/ACCEPTANCE.md).

## Quick verification

The observed numerical environment is Python **3.12.14**, NumPy **2.3.5** and SciPy **1.17.0** on Linux x86-64.
The direct Python dependency pins are in [requirements-study.txt](requirements-study.txt); this is not a complete
operating-system or transitive binary lock. The economics module itself uses the Python standard library.

From this study directory, with those dependencies available:

```sh
python3 -B reproduce.py --output /tmp/possibility-engine-quick-review
```

The output directory must not already exist and must be outside the study. The wrapper verifies the exact freeze
and original seed bank, copies the necessary files, reruns the joint and successor deliveries, checks their
semantics and minimum costs independently, and runs the fourteen scoped unit/control tests. Original evidence
is read only. Command output and a reproduction receipt are retained in the new directory.

For a new supplied brief, use the constructor's actual CLI with a separate output directory:

```sh
python3 -B src/engine.py /absolute/path/to/brief.json --output /tmp/new-experiment-delivery
```

## Full replay

The reviewable source checkout keeps runnable code, the primary examples and summary receipts visible.
The **complete companion ZIP** preserves every raw world, netlist, run log, predecessor copy and failed attempt.
The ZIP uses LZMA compression; the Python standard-library extraction command below supports it.
Positive visual-QA raster intermediates can be regenerated from the included PDFs; the review receipts remain included.
Start the full replay from that complete archive, extracted into a new directory:

```sh
python3 -m zipfile -e AGI_ALPHA_FLYWHEEL_COMPANION_v1.zip /tmp/possibility-engine-complete
cd /tmp/possibility-engine-complete/possibility-engine-v1
```

Choose an extraction path that does not already exist. Then run:

```sh
python3 -B reproduce.py --mode stage-full --output /tmp/possibility-engine-full-review
sh /tmp/possibility-engine-full-review/REPLAY_COMMANDS.sh
```

Staging copies the full study and preserves copied original results under `original_results/`. The generated
commands replay the original issued seeds, reconstruct all enterprise journals, audit the summaries and references,
and stage only the fresh-case circuit files. Reusing these seeds is reproduction, not new independent confirmation.
The final circuit command runs the independent ODE check. Add `--ngspice /absolute/path/to/ngspice` to the staging
command to include the native comparison; `--library-dir` is available for a separately provisioned library path.
No package download, installation, publication or external service call is performed by the wrapper.
