## Recommendation

The leading construction is an **intervention foundry**: a researcher supplies rival mechanistic models and a desired scientific distinction; the constructor identifies why existing controls cannot reveal it, synthesizes a changed control/readout arrangement, and emits an executable experiment that makes the distinction observable within stated error and resource limits. The valuable future state is that researchers can investigate hidden mechanisms without assuming that their current instrument's inputs and outputs are the permanent limits of what can be known.

The headline must be the newly answerable scientific question. A report that merely says a model is unidentifiable, or an optimizer that selects a slightly better input from an unchanged standard experiment catalogue, fails the user's transformation test. The candidate must construct an enabling operation or representation and execute its essential mathematical/computational step. A physically interpreted design remains a simulation-qualified design until hardware tests exist.

A competent ordinary experimental-design system may find the same enabling experiment. That does not erase the useful change relative to the named restricted instrument, and does not by itself erase the business. It does defeat an exclusive algorithmic or retained-capability advantage claim. The selection below deliberately does not impose exclusive novelty as a prerequisite.

## Four substantially different possibilities, before commercial narrowing

These were considered for the activity they would make possible, before asking what is easiest to benchmark or sell. The order reflects the strength of the whole construction thesis for this bounded campaign, after accounting for ongoing repository work. It is not a ranking by market size or access to a dataset.

### 1. Make hidden mechanisms experimentally distinguishable by constructing the missing intervention

**Future state.** Scientists can ask which internal process produced a result even when every ordinary observation available from the present apparatus gives the same answer. Intelligence changes the experiment that can be performed, not only the sophistication of inference.

1. If this succeeds, beneficiaries will be able to discriminate specified hidden mechanisms using a constructed external experiment, which their current fixed control/readout arrangements do not adequately enable.
2. The constraint we are changing is the inherited set of actuation and observation operations; an information-theoretic indistinguishability under that set is genuine, while treating the set itself as immutable can be optional.
3. The new means we will construct are a model-to-obstruction analysis, an admitted control/readout constructor, an executable excitation programme, and an independently checked decoding or discrimination rule with a declared uncertainty envelope.
4. The recent frontier change that makes this plausible is the demonstrated combination of model-written scientific code, mechanistic hypothesis proposal, executable experiment design and tool iteration; specific accessible capabilities must be taken from the separate frontier evidence matrix rather than inferred from model names.
5. The first useful commercial outcome is a bounded computational experiment-design package for a laboratory or instrument developer: supplied rival models, a feasible new experiment specification, executable runner, predicted separating observations, uncertainty limits and a handoff for laboratory commissioning.
6. That first outcome exercises the larger transformation because it must create an observation that the original apparatus cannot produce and must preserve the original scientific decision and physical-control constraints.
7. The next productive possibility it could open is a successor that uses the retained model-to-experiment compiler to decide which additional actuator, readout or controllable reset would unlock a different scientific question, with integration and qualification charged again.

**Concrete construction.** Use a finite candidate family of stable continuous-time diffusion or transport networks. Under uniform actuation, several different networks can have the same output trace for every allowed temporal input. The constructor must find this invariant, then synthesize an affordable spatial actuation mask or coupling arrangement that makes their transfer responses distinguishable. Search can include time programmes and output combinations, but must also include the enabling interface. Independently compute responses from matrix-exponential simulation and a separate transfer-polynomial or resolvent implementation. Robust acceptance must account for gain, offset, timing and coefficient uncertainty; require disjoint output sets or an explicitly limited discrimination margin. Preserve cases where no admitted interface works.

**Decisive instance.** For a graph Laplacian L, dynamics dx/dt = -(L + kI)x + b u with b equal to the all-ones vector and a uniform initial state remain in the uniform eigenspace. Different internal graphs therefore produce the same point-sensor trace. A localized or otherwise nonuniform b can excite informative modes. The enabling operation is selective actuation. This is an elementary, known structural mechanism, not a new graph-theory result. The constructor's useful task is to find the specific admitted actuation/readout programme that distinguishes a beneficiary's supplied hypotheses at acceptable cost and robustness.

**Required alternatives.** A same-information maximin optimal experimental-design baseline with the same admissible new interfaces; an expert use of current AI with equal construction and tool access; and an ordinary code library containing the same components. A passive-observation ceiling is a mechanism control, not the primary competitor. Current literature already studies active model discrimination, so absence of an adequate product category remains unestablished until researched for the particular beneficiary.

**Fresh successor.** After freezing the parent compiler, supply a different task: distinguish fault location or boundary exchange on a larger network, or design a second actuator that identifies a previously inseparable pair. Compare retained compiler, plain artifact library, and fresh expert construction. Charge extraction, validation, integration, upkeep, unsuccessful search and verification. Do not call simple portability skill compounding.

**Reason to select.** The task directly builds a means of discovery, admits a clear before/after information distinction and an independently executable hard step, and avoids reproducing the existing scalar drift-cancellation, calorimetry and synthetic spectroscopy instruments. The physical implication must remain conditional.

### 2. Make one-off useful mechanisms manufacturable from behavior and local stock

**Future state.** A person who needs a special motion, force response or repair can obtain a manufacturable mechanism defined by its required function and materials at hand, without waiting for a component category to exist.

1. If this succeeds, beneficiaries will be able to obtain a one-off mechanism meeting a specified force/displacement behavior under local manufacturing constraints, which catalogue components and a fixed inherited design do not adequately enable.
2. The constraint we are changing is dependence on an existing geometry and stock component family, while preserving material strength, energy, fabrication and safety limits.
3. The new means we will construct are an expressive geometry grammar, a mechanics-based constructor, a fabrication representation and an independent performance test.
4. The recent frontier change that makes this plausible is experimentally demonstrated generative inverse design using algebraic geometric representations, combined with present coding and simulation tools.
5. The first useful commercial outcome is a simulation-qualified, fabrication-ready passive component design with agreed dimensional and load limits.
6. That first outcome exercises the larger transformation because the created geometry must realize a function absent from the supplied component catalogue rather than merely redraw a part.
7. The next productive possibility it could open is a successor fabrication jig or test fixture built using the first component family, enabling a new class of designs to be manufactured or characterized.

**Hard step and comparison.** Construct, export and independently simulate a compliant mechanism under multiple load cases, comparing topology optimization, expert CAD plus current AI, and a standard component assembly. Finite-element model agreement is not physical qualification. Avoid using a learned surrogate as both constructor and truth oracle.

**Why not the bounded flagship here.** Root reports an active portable-CAD lane (#5003); physical qualification is also absent. Keep this vision, but do not duplicate that owner or claim a new manufacturing capability from a CAD file alone.

### 3. Make individually unviable needs jointly produce a new capability

**Future state.** Several organizations can jointly commission a capability none can rationally finance alone, where the combination of their requirements reveals a shared technical construction that did not previously exist.

1. If this succeeds, beneficiaries will be able to acquire an otherwise unbuilt shared capability through mutually acceptable staged commitments, which fragmented bilateral purchasing does not adequately enable under the stated financing constraints.
2. The constraint we are changing is the combination of duplicated construction cost, fragmented commitments and cash timing, not the need for real participants, rights or working capital.
3. The new means we will construct are the shared productive core, beneficiary-specific adaptations and an executable commitment, delivery and risk allocation arrangement.
4. The recent frontier change that makes this plausible is improved technical synthesis and multi-agent tool use that can search both the technical dependencies and the arrangements making them affordable.
5. The first useful commercial outcome is an accepted shared-core build supporting several bounded deliverables, with each buyer's outside option and rights preserved.
6. That first outcome exercises the larger transformation because neither separately built services nor coordination without the technical core achieves the qualified outcome within the specified constraints.
7. The next productive possibility it could open is a different capability whose construction reuses the first core and can therefore support a smaller or previously unfinanceable beneficiary coalition.

**Hard step and comparison.** Construct the actual shared core, then solve participation and cash constraints under competitor imitation, withdrawal, correlated delivery failure and free riding. Compare ordinary entrepreneurship allowed exactly the same coordination and engineering. An internally feasible allocation does not establish agreement or demand.

**Why not the bounded flagship here.** Root reports an active production-hypergraph lane (#5005); choosing another abstract complementarity example would duplicate an active construction and repeat the unbuilt-core gap that INVENT THE ECONOMY explicitly identifies.

### 4. Let small scientific communities operate a new composite instrument without owning a complete laboratory

**Future state.** A community can conduct a scientifically coherent experiment whose necessary capabilities are scattered among existing facilities; their combined apparatus supports a question no participant can answer separately.

1. If this succeeds, beneficiaries will be able to execute a cross-facility experiment with sufficient calibration, sample continuity and timing to answer a new question, which independent access to the facilities does not adequately enable.
2. The constraint we are changing is incompatible experimental interfaces and fragmented access, while preserving calibration validity, custody, physical transport and lawful authority.
3. The new means we will construct are a shared experimental state representation, missing apparatus adapters, cross-instrument calibration and a control protocol that survives the actual handoffs.
4. The recent frontier change that makes this plausible is demonstrated laboratory interoperability and AI-assisted experiment orchestration, together with frontier coding and computer-use tools.
5. The first useful commercial outcome is a commissioned composite experiment for one instrument-development or materials question, delivered with the actual measured outcome and reusable apparatus integration.
6. That first outcome exercises the larger transformation because the combined apparatus must acquire a scientifically useful observable unavailable to any component facility alone.
7. The next productive possibility it could open is a successor experiment that combines the retained instrument with one additional capability to investigate a different phenomenon.

**Hard step and comparison.** An actual apparatus-to-apparatus test is necessary for a physical claim. A digital twin can test control logic, failure handling and limits, but cannot replace that experiment. Compare a centralized lab, standard middleware and expert integration, including shared fixed cost and coordination burdens.

**Why defer.** It is a strong long-horizon possibility and a plausible successor to the intervention constructor. This environment lacks instrument access and permitted physical commissioning, so a complete claim would be conditional. Merely generating adapters would be an interface project, not the transformation.

## Pre-build acceptance implications

- Freeze the scientific distinction, original available operations, allowed construction grammar, uncertainty, resources and failure definition before fresh confirmation.
- Require an actual constructive output, not a proposed future actuator represented only as a cost line. The executable component can be completed locally; physical manufacturing remains conditional.
- Use a competent same-information baseline permitted to invent the same interface. Preserve ties and wins by conventional methods prominently.
- A useful early offering can be a reproducible computational design package, but its contract must sell that package, not a claim of physically demonstrated discovery.
- The selected instrument should have an interpretable failure or refusal region: nonseparable models, insufficient actuation, noise overwhelming the margin, invalid dynamics assumptions, and a cheaper conventional alternative.
- Root should choose the initial technical scope after the separate frontier and ownership findings. This memo supplies the ambition and construction requirement; it is not a retrospective explanation of whichever benchmark happens to pass.
