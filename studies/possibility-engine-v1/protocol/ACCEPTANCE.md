# Acceptance protocol v1 — before fresh confirmation

The mission is to make a supplied finite hidden-network distinction answerable by constructing complementary access. This is a computational study; a circuit input is not fabricated hardware. The hypothesis family is explicitly limited to validated sixteen-vertex graphs with A²=4I+2J, degree six, known labels, uniform unknown edge rate, uniform leakage and readout gain. New questions beyond this family must be refused or separately qualified.

## Frozen scientific criteria

1. Exact integer identities and an independent nonisomorphism witness establish the original all-waveform ambiguity. Equality at finitely sampled times alone is insufficient.
2. Current access, added actuators alone, and added sensors alone remain nondiscriminating for the aligned primary pair. A valid joint addition produces disjoint output ranges despite independently unknown parameter values for the two alternatives.
3. Bounds use all allowed rate, leakage and gain values plus bounded additive error. The continuous analytical extrema are evaluated in IEEE754 with outward numerical padding; this is not a formal floating-point proof. Acceptance requires margin greater than 1e-10.
4. The nominal development box is rate[0.8,1.2], leak[0.05,0.15], gain[0.95,1.05], error±0.005. Observation times are 0.050–0.500 in0.001 normalized increments. New supplied grids and bounds are accepted only within input limits.
5. Independently stamped RC ODE predictions must agree with selected nominal outputs to absolute1e-6. SPICE, if available, has the same predeclared1e-6 numerical tolerance. These are computational tolerances, not manufacturing tolerances.
6. Twenty-four fresh binary cases and twelve fresh successor cases use post-freeze verifier-issued seeds. Cases include relabelings, changed independent uncertainty boxes, alternative costs and restricted access. Exact independent enumeration must match feasibility and minimum integer cost. High-noise, identical-model, inaccessible-port and malformed inputs must be refused.
7. Successor missions distinguish six candidate networks, including one-experiment or one-terminal failure where specified. A terminal failure removes every experiment using that terminal; obligations may be correlated. Every remaining model pair must remain separable under every declared failure.
8. Compare against independent same-information algebraic/exhaustive construction and an ordinary directory containing identical reusable source and artifacts. A conventional tie preserves the enabling construction but defeats exclusive or retention-specific advantage.
9. Preserve every failed development attempt, correction and fresh-confirmation outcome. After source freeze, substantive repairs require a new protocol/source version and new independent seeds. No selection of favorable confirmation worlds.

## Costs, effort and capacity

Count source construction, failed searches, extraction, integration, numerical checks, independent review, upkeep and exception handling. Deterministic code execution is measured. Human-hour scenarios and session model costs remain estimates, not metered facts. No human operator intervention is silently replaced by a zero cost.

## Enterprise confirmation

The economics module specifies its own integer-cents journal, twenty-four policy trials in two bounded twelve-policy rounds, buyer outside options, competitor responses, supplier and common shocks, funding, all operating costs and complete runoff. Its selected policy, scenario definitions and code are hashed before fresh seeds. Outcomes are conditional simulations. Profit, cash, deposits, outstanding obligations, collections and financing are reconciled independently. No-launch is compared explicitly; the least-loss launch is not relabeled as profitable.

## Promotion gate

A model-level capability change is not sufficient for a commercial flagship. A real beneficiary application must require the distinction, permit the new access, and survive comparison with available experimental-design expertise. Physical scope requires calibrated component and timing bounds, an independently operated fixture, incomplete-model controls and beneficiary acceptance. No theorem novelty or exclusive algorithm is required, but this study must not equate a classical witness with a validated market.
