    Traditional human workflow · prospective baseline

    1. Open both exports in ordinary spreadsheet or database software.
    2. Join by path; check missing rows and differing values.
    3. Group exceptions and preserve source references.
    4. Review, correct, and deliver the package.

    Competent workers may use formulas, queries, scripts, and reusable templates. This workflow was not timed in a new human trial.

    1. Run the released reconciliation CLI on the same two inventories.
    2. Preserve complete differences and grouped actions.
    3. Check outputs with an independent Python/SQLite oracle.
    4. Hash, package, and retain the executable successor.

    Defaults are an illustrative arithmetic example, not wage benchmarks or measured task times. Use a fully loaded employer rate and include every attributable non-attention cost.

    Transparent equations and allocation assumptions

    Let w be hourly employer cost, h traditional minutes, r residual system minutes, k other system cost, and pH / pA acceptance probabilities.

    Human cost / accepted = (w × h / 60) / pH
    System cost / accepted = (w × r / 60 + k) / pA
    Break-even h = (r + 60 × k / w) × pH / pA
    Attention freed / accepted = h / pH − r / pA

    Expected retries use the same per-attempt resources and constant acceptance probability. Traditional extra software fees are zero in this simplified scenario; include them in the employer rate or extend the paper’s ledger. Infrastructure constraints, demand, staffing decisions, and queueing are outside this calculator.
