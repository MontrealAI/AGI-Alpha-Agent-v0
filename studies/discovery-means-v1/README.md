## Reproduce

Use a checkout of this contribution. Its inherited base is
`12770c22b4a9f90f2013bbfb64242f912ba5071e`. Follow the implementation README for the observed limited
editable installation and its dependency qualification. It is not a clean locked release installation.

```sh
python3 -m venv --system-site-packages .venv-discovery
.venv-discovery/bin/python -m pip install --no-deps --no-build-isolation -e . -e contrib/discovery_means_v1
.venv-discovery/bin/python studies/discovery-means-v1/reproduce.py --repo-root . --out /tmp/discovery-replay-fresh
```

The output directory must not exist. The wrapper verifies the instrument, native predecessor, protocol,
task and evaluator identities before rerunning the finite comparison. It re-audits saved hosted outputs;
it does not rerun a hosted model. A post-publication replay is reproduction, not fresh confirmation.
The original absolute paths in frozen receipts are provenance, not portable defaults.

`evaluation/portable_replay_receipt.json` records successful execution from an unrelated working directory.
The exact native custody command and inexpensive first-use JSON example are in the implementation README.
Scientific results did not require paid APIs or physical equipment. This does not make research effort free.
