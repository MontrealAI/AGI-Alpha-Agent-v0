\section{Reproduce, inspect and extend}

The complete companion preserves the authoritative author PDF with its LaTeX, bibliography and editable PDF/SVG figures. It also contains the frozen source and protocol, mission inputs, exact outputs, failed proposals, intervention records, independently implemented checker, historical audit and the original Strategy Laboratory archive. The preferred Edition 02 is a separate preserved publication; no file in that edition is replaced.

\subsection{Three entry points}

\textbf{Use the planner.} Open the standalone \artifact{AGI_ALPHA_Strategy_Laboratory.html} in a current browser. The default action computes a useful plan from editable synthetic inputs, checks it locally and offers JSON/CSV exports. There is no account, installation, wallet, model endpoint or API key. Browser work runs only while its page is open. A saved checkpoint permits an explicit later resume; it is not a background service.

\textbf{Inspect the experiment.} The evidence view clearly marks recorded confirmation. The complete archive's \artifact{EVIDENCE_DOCKET.json} connects material claims to files and source identities. \artifact{SHA256SUMS.txt} checks the packaged payload, while \artifact{protocol/STUDY_FREEZE.json} binds prospective execution and evaluation files. The development and historical directories retain their distinct evidence classes. They cannot be relabelled as fresh confirmation.

\textbf{Run the companion.} The root reproduction guide gives the exact clean-output command, environment pins and expected bounded outputs. Node 24.22.1 runs the workbench and strategy controller; Python 3.12.14 runs the separate checker. The native reference uses NumPy 2.4.6 and SciPy 1.17.0. The browser itself has no external library dependency. Reproduction executes into a new directory and first verifies the frozen source. It never overwrites the original recorded run or silently rebinds a changed source.

\subsection{What is fixed and what is editable}

The strategy language, checker, source-binding controls, discovery opportunities, task distribution, comparator policies, resource limits, primary analysis and stopping rules were committed before confirmation. A reader may study or extend them, but a change requires a new source identity and new evaluation. Reusing an old favorable outcome is not qualification of that change. The manifest is an integrity check, not a signature from an independent institution. The source identity begins \artifact{7e5a1dd2dcf7}; the 52-file prospective freeze begins \artifact{6d0308707f39}. Both full hashes and the pre-execution public record on \href{https://github.com/MontrealAI/AGI-Alpha-Agent-v0/issues/4850#issuecomment-6390926576}{issue \#4850, comment 6390926576} are in the evidence docket. The paper can be rebuilt with \smallcode{bash paper/build.sh} using XeLaTeX and BibTeX from TeX Live 2023. Figure generation uses Matplotlib 3.10.8. The build pins metadata time, document identity and fonts. The delivered verification record reports a clean rebuild from the packaged source, page rendering and inspection, and saved-copy hash checks. The original author PDF stays inside the archive even if a document-serving system adds provenance metadata to a separately served copy.
