# AGI ALPHA Flywheel — The Capability Advantage

**Game-Theoretic Economics of Skills Earned Through Demanding Work**  
Research edition, 26 October 2026. Additive study namespace:
`studies/agi-alpha-capability-advantage-v1/`.

## Result

Demanding numerical work produced a useful executable contribution. An independent
agent's reduced-space design method ran **9.87× and 129.91× faster** than the
original recipient's design solver on two new cases, with both methods meeting
the same numerical contract. These are **solver-only** timings. The reverse
acquisition added no accepted task and did not improve that recipient's timing.

The frozen primary cohort completed **144/144 accepted evaluations**: 12 connected
forward/calibration/design chains, three stages and four arms. All arms accepted
all 12 chains. Total complete invocation CPU was:

| Arm | Method | CPU seconds | Elapsed seconds |
| --- | --- | ---: | ---: |
| A | Independent retained reconstruction | 99.785358 | 98.681532 |
| B | Validated searchable registry | 112.469447 | 110.852694 |
| C | Validated skills graph | 114.748178 | 113.070371 |
| D | Strong conventional implementation | 182.853930 | 181.728966 |

Independent reconstruction succeeded within its allowed budget and was fastest
overall. Sharing added **zero accepted primary jobs**. Registry and graph used
the same selected capabilities and produced identical numerical arrays. No
incremental graph advantage or scarce underlying mathematical capability is
established.

The separately frozen market campaign completed 2,304 paired simulated worlds,
9,216 primary enterprise histories and 46 additional same-world financial
controls. **No G2+G3 later-investment bundle qualified for financeable succession**
in B or C. Whole-project B−A value was positive in 87 worlds and negative in
2,217; the 144 condition/cost cell means were positive in 8 and negative in 136.
These are counts in a designed sensitivity panel, not real-market probabilities.
C−B was tied in the cent-denominated ledger in every world; unrounded computation
retains small differences. See the full analysis and paper for all outcomes.

**Actual customer collections: zero. Actual all-in research cost and historical
return: unknown.** Monetary rates, future demand, buyer value, receipts, residual
attention, useful life and competition are explicit model assumptions. The model
does not count internal transfers, token issuance or appreciation as enterprise
revenue.

## Scientific contract and comparison

The operator is a grounded positive-conductance graph. The retained methods solve
its sparse response, fit bounded grouped coefficients to partial observations,
and allocate a constrained edge-conductance budget to minimize the worst
compliance over supplied load scenarios. The verifier assembles and checks the
answer independently, including held-out prediction and a finite-model numerical
optimality bound. A valid component does not automatically validate a composition.

Primary sizes are 100, 625, 1,600 and 2,500 nodes, with respectively 4/8/12/16 loads,
4/12/20/32 calibration parameters and 8/24/48/80 design variables. There are three
fixed cases in each stratum. All inverse outcomes seal before design release;
each arm's design uses its own accepted fitted parameters. Hidden answers are
absent from skill records and retrieval indexes.

A is an independently authored retained implementation. B is a competent indexed
registry with the same evidence and dependency planning available to C's graph.
D is an independently authored strong conventional method. The constructors
could use public mathematical methods and realistic construction budgets. They
are same-session model instances with different work histories and retained
software, not independently trained foundation models or live ENS identities.

The connected workflow and subsequent contribution are executed. The initial
three algorithms were prototyped together, and the task sequence was planned.
This is not evidence of autonomous discovery or improving development efficiency
across successive capability generations.

## Reproduce without adding observations

The executed environment was Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0,
threadpoolctl 3.6.0 and Node v24.22.1. BLAS threads were limited to one. Solvers had
a 3 GiB address-space limit; complete native acceptance was limited to 60 seconds.
The repository's operational Node 22.17.1 qualification is a separate gate.
`protocol/runtime-environment.json` records the actual research environment.

After extracting the complete companion, use an environment with these existing
dependencies. The scripts do not install packages, authenticate identities,
access a network, spend money or settle a job.

```sh
python reproduce.py
python reproduce.py --reverify-vectors
python reproduce.py --audit-market
```

The first command checks source identities and reconciles saved records. The
second additionally runs the frozen independent verifier on saved numerical
vectors; the third reconciles every preserved financial history. None executes
capability solvers or reruns the market. New audit reports are written under a
fresh timestamped `replays/audit-*` directory. Original audit reports and frozen
evidence are unchanged.

Explicit archival replays write to new directories under the extracted study:

```sh
python reproduce.py --execute-primary replays/primary
python reproduce.py --execute-market replays/market
```

The primary replay uses already released archived inputs and cannot enlarge the
held-out sample. Market replay uses exactly the registered panel, seeds and
costs. Output directories must not already exist. Original evidence is never
overwritten. CPU and elapsed times can differ on other machines.

Development controls can be checked separately:

```sh
node economics/test_network_market.mjs
python economics/test_build_calibration.py
```

The economic controls are synthetic software tests, not further market worlds.
The complete histories are newline-delimited JSON in
`economics/results-primary/complete-worlds.jsonl.gz`; stream-decompress them rather
than loading every world's detailed records into memory at once.

To rebuild figures and the paper in an existing scientific/LaTeX environment:

```sh
python publication/analyze_results.py
cd publication
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
```
