# Review and delivery scope

This is an additive research contribution under Alpha issue 4850. The proposed
GitHub review changes only `studies/agi-alpha-capability-advantage-v1/`.

The GitHub review contains the executable source, inherited native modules,
frozen protocols/calibration, primary invocation ledger, admission evidence,
independent audits, all financial cell/paired-case summaries, paper and bilingual
demonstration. `publication/github-review-manifest.json` identifies these bytes.

The complete companion delivered with the paper additionally contains all raw
task/oracle files, numerical output arrays, native packs, development/stress
records and the full 134 MB compressed financial event histories. Those bulky
raw files are not duplicated into this source review. Reproduction commands in
README apply to the **complete extracted companion**, not to a partial source
checkout. The original raw files, historical failures and unknown costs are
preserved in that companion.

The implementation was exercised through the existing Workbench extension seam
as bounded, source-bound local research. No operational Harness/Fleet adoption,
live ENS authentication, customer settlement or public release is represented
as complete. Existing integration and mutation owners remain in control.

Numerical and economic evidence passed its registered tests and independent
reconciliation. Scoped Ruff feedback has 11 diagnostics in the frozen scientific
source; it is not a pass. The two new publication/reproduction helpers were
formatted separately without changing frozen experiment code.
Frozen scientific source was not reformatted after outcome generation.
Repository-wide pre-commit, strict typing, full coverage, installed acceptance
and hosted release/security gates are not claimed to have run or passed.
Browser startup was blocked by the execution sandbox; HTML logic/translation/
evidence checks passed, while rendered browser layout QA remains NOT RUN.

The draft review preserves all existing gates. It does not request a release,
merge, security exception, token action or disposition of another owner's held
operation.
