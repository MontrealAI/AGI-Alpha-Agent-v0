## Reproduce the bounded study

Python 3.12.14, NumPy 2.3.2, and Node 24.22.1 were used. The repository's preferred Node version remains 22.17.1; this isolated replay is not full runtime qualification. No model API key, wallet, ENS account, or buyer is needed.

```bash
python reproduce.py
```

The replay stages a temporary copy and runs seven commands. It replays the U/E probes, both targeted imaging probes, contact/randomness probes, 21 independent numerical cases, cost arithmetic, and the native source bridge. Deterministic outputs must match archived results; cryptographic salts and sealed bytes may change while recovered genome and plan agree. Original evidence is not overwritten. Hosted discovery sessions cannot be deterministically rerun from this package; their prompts, budgets, outputs, and query logs are archived.

For a new environment, install NumPy 2.3.2 in a separate environment. Paper regeneration additionally uses ReportLab, Markdown, BeautifulSoup4, Matplotlib, Pillow, and pypdf; exact installed versions are in `provenance/runtime.json`. Run `python paper/build_publication.py` after reading the paper source and the normal artifact-authoring instructions of your environment. Rendering is optional for scientific replay.
