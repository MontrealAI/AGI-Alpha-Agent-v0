# Connected example: a hypothesis that correctly remains research-only

The linked example is E4, quantum transmission through completely depolarizing channels. It is supporting research, not the flagship.

1. **Opportunity hypothesis.** Preserve quantum information through channels that erase it in a definite sequence. The user did not supply this application.
2. **Transformation.** Coherently control cyclic order and herald an output branch, retaining the original quantum-information purpose and reporting consumed resources.
3. **Construction.** Execute exact Kraus enumeration. Four channels give probability 7/16, fidelity 5/7, and normalized Choi partial-transpose minimum −1/14.
4. **Documented comparator.** The 2021 cyclic-order paper already constructs this capability; the 2025 silicon-photonic preprint reports an experiment. The proposed small heterogeneous extension follows by continuity from a strict known entanglement margin.
5. **Accepted result.** A known mathematical result was reproduced. No new productive outcome, field link, or customer delivery was accepted.
6. **Economics.** No qualified offering, selling price, demand, hardware cost, or operating profit is established. Customer collections are zero; actual research billing remains unknown. Hypothetical token quotes are local fixtures, not cash.
7. **Inheritance.** Existing Insight, encrypted Nova-Seed, FusionPlan, and MARK inspection carry the rejected hypothesis, source bindings, uncertainty, rights and next-experiment gate. Nineteen checks preserve research-only status. The adapter adds no production authority.
8. **Fresh successor work.** Numerical confirmation uses a different Kraus basis and N=2–6; it establishes implementation agreement. A future scientific successor must first supply a separated useful regime, substantive prior-art difference, resource-matched coherent-control comparator, and complete loss/channel-use/cost accounting. All four prerequisites are currently unmet.

This is a complete evidence trace with a deliberate stopping point. It does not substitute a known result for the requested novel profitable construction. The same files in an ordinary directory preserve the same scientific information; provenance does not establish a network moat or independent transferred competence.
