## What the code does and does not establish

`completeJobs()` constructs illustrative bundle records and marks the current jobs accepted. It does not execute the named substantive research jobs or authenticate the listed reviewer strings. `proofScore()`, `worthUtility()`, and `canonicalScore()` combine slider values and the presence of local bundle/replay metadata. They are instructional scores, not measured frontier performance or economic-value estimates. `advanceFrontier()` increments display scores; those increments do not measure a changed feasible set. `generateNextMission()` selects from a small set of harder-mission text templates. Text generation alone does not establish more difficult useful work, successful transfer, or recursive improvement.

The following source-level limitations remain part of the foundation's history:

| Function | Static finding | New research control |
|---|---|---|
| `canonicalReview()` | It changes status to `canonical-admitted` after score checks without requiring a prior Chronicle admission or rejecting terminal lifecycle states | Canonical promotion requires current, separately validated admission |
| `generateNextMission()` | It takes the last Chronicle entry without rechecking the referenced skill's current status; `retireSelected()` changes the registry status but retains that Chronicle record | Current lifecycle, evidence, scope, and dependencies are checked before future use; terminal history cannot restore influence |
| `gateStatus()` | It reads the currently selected proof-level policy rather than a manifest-bound immutable policy version | Assessments and attestations bind explicit policy/Beta versions |
| `composeSelected()` | It creates a candidate composition from inherited illustrative evidence/scores | The new composition must receive fresh assessment and retain exact current dependency pins |

These findings are about the supplied prototype's implementation. They do not establish frontier-model limitations, commercial failure, or the invalidity of the architecture. They motivated explicit controls while leaving the original source unchanged. The new module reuses existing generic authority/commitment primitives rather than copying this UI's scoring into a scientific model.
