# Post-freeze caveat: optional meta endpoint

The frozen optional experiment classified `invalid_pass` as a proposed improvement without checking whether any improved candidate had actually been selected. The main commercial engine and paired Alpha probe require that additional check and are unaffected.

Reading all saved traces found **six non-inventive fallbacks** reviewed unnecessarily in every arm, at seeds1040063,1040085,1040103,1040179,1040206 and1040208. Five passed the local review falsely. Thus the frozen summary's **21 local false passes** in each arm comprise **16 invalid actual method proposals plus five fallback outputs**. They must not all be described as newly invented methods, and none is a graph admission.

The extra review charge is exactly USD81.35 per arm across256 campaigns. It is matched case by case between baseline and retained-screen arms. Removing these identical charges in a diagnostic calculation leaves **every paired cash-saving difference unchanged**, as well as the131/132 useful-method counts and the1,056-campaign resource-saving break-even. The registered variable-cost totals remain as published; this note does not replace or rerun the experiment. The large failure to recover full lifecycle cost remains.

All frozen source and result files are preserved. The reproducible post-freeze classifier is `results/analysis/review_meta.py`; its complete machine-readable caveat is in `results/analysis/meta_readout.json`. This is an implementation limitation of the optional endpoint, not evidence about frontier-model limits.
