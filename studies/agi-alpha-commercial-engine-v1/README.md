## Supported business result

The concrete internal buyer is MontrealAI's maintainer of the native AGI ALPHA
application. The usable offering is a bounded component-compatibility decision
packet: exact source and dependency profiles, declared requirements, recorded
before/after observations, checked decision, a component-lock patch and EN/FR
next actions. The completed packet remains in the separately delivered companion.
It does not establish customer purchase, whole-application qualification or
permission to change an installed application.

The existing writer's single frozen comparison contains six historical
dependency transitions and 18 arm assessments. All three arms completed six
scoped component outcomes. The retained and strong conventional automatic
builders both removed the assisted incumbent's explicit per-mission finalization.
The conventional result is preserved. Finalization steps are not measured human
minutes, extra customer jobs or monetary savings.

Actual customer collections are zero. Complete monetary delivery/construction
cost, matched professional duration, price acceptance, paid demand, actual profit,
asset repayment, financeable surplus and self-acceleration remain unestablished.
The numeric commercial scenarios are explicit hypotheses. Their labels and full
inputs travel with their outputs; they do not establish a commercially proven
self-financing enterprise. The next-item USD200 envelope is explicitly
unselected and unjustified. The owner has already corrected regression-import
coverage within the existing product work; it is not an invented future project.

## Run the independent commercial adjunct

Use an already available Node.js 22+ runtime. No npm package, network access,
credential, operator session or payment is required. From this directory:

```sh
node tests/commercial.test.mjs
node src/commercial.mjs evidence/commercial-input.json > commercial-result-replay.json
node src/commercial.mjs --template > unknown-input-template.json
```

The focused controls are implementation checks, not additional customer jobs or
fresh scientific confirmation. The original experiment is not rerun here.
The copied canonical modules are unchanged AGI ALPHA APIs; their exact identities
and original source paths are in `evidence/canonical-identities.json`.

The model keeps paid and accrued economic costs separate from paid-cash
projections, outstanding obligations and reserves. Duplicate charge identities
are refused. Every required delivery/construction category is represented and
unknown amounts remain null. Modeled receipts never become observed collections.
Buyer savings and token value never become incoming cash. No spending or
capability promotion is authorized by this module.

## Build the manuscript source locally

The manuscript is `publication/paper.tex`. With an existing Python environment
containing NumPy and Matplotlib, and a standard pdfLaTeX installation:

```sh
python3 publication/make_figures.py
cd publication
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
```

The figure script creates the missing `figures/` directory. Compiling creates a
local reference PDF; it does not replace the original reviewed PDF identity or
publish a binary. TeX needs the article class and the packages declared at the
top of `paper.tex`. No package installation is initiated by this contribution.

## Demonstration source

`presentation/demo_template.html` has placeholders, not an embedded product
archive. `presentation/build_demo.py` requires the separately delivered exact
Reviewed product ZIP. The file is intentionally absent from this text-only PR.
With that independently obtained packet and the existing Python standard library:

```sh
python3 presentation/build_demo.py \
  --data evidence/demo-data.json \
  --packet /path/to/full-companion/deliverables/AGI_ALPHA_Upgrade_Decision_Packet_Reviewed.zip \
  --output commercial-demo-local.html
```

The builder verifies the expected packet basename, SHA-256 and ZIP CRC before
embedding it. It creates a local EN/FR demonstration, not an operated service.
The complete companion's portable verification/economic-replay helpers are not
included here because their required primary evidence and ZIP inputs are absent.
Historical diagnostic paths in source records remain documentary.
