# Reinvestment companion — useful work, cash and subsequent methods

Open `AGI_ALPHA_Reinvestment_Policy_Demo.html` in a modern browser. This standalone file opens offline and starts with the exact recorded native publication brief and presentation, their acceptance evidence, and downloadable originals. The financial view selects from the separately frozen, independently audited simulation. It does not execute the financial model or make remote requests.

The companion contains four distinct views:

- **Work, cash and next methods:** 144 primary financial cases, 32 demand sensitivity cases, twelve monthly accounting views, customer comparisons and separate source-linked USDC/AGIALPHA settlements. Every displayed numerical result is bound to a pointer in the audited output. Unknown or empty served-cohort comparisons remain unavailable.
- **Successive missions:** the original local evidence module, exact parent artifacts, successor repair and fresh transfer. The module really executes locally. Downloads, STOP, rollback, recovery and tamper refusal retain the canonical implementation.
- **Recorded evidence:** preserved native observations and scientific limitations.
- **Approved executor:** existing approved route instructions. Authenticated execution is **NOT RUN**; this companion does not establish a new remote executor.

The financial simulation preserves collected cash versus invoices, customer versus provider accounts, reserve requirements, unspent allocation, failed construction and unfavorable outcomes. Starting USD 25,000 is provider cash, excluding customer costs; the earlier operating study used a different combined-resource budget. Hypothetical USD 0.50 variable cost and outcome-world gains remain unvalidated assumptions. Candidate promotions are simulated. Settlement worker receipts exclude unrelated beneficiaries and enterprise expenses. No quoted token price is represented as an observed market price or an appreciation forecast.

## Rebuild

From `reinvestment_amendment_v1/`:

```sh
python browser/build_companion.py \
  --results outputs/run-002/results.json \
  --token-results outputs/token-run-002/token_waterfalls.json \
  --cash-audit evaluation/INDEPENDENT_AUDIT.json \
  --token-audit evaluation/TOKEN_AUDIT.json
```

The builder checks all 68 frozen files, public authorization, audit/output/model identities, exact native artifacts and unchanged original companion. It performs zero financial scenario calculations and writes only this derivative browser directory. Its ZIP downloads contain frozen inputs, exact results, source, audits and recorded artifacts, with reproducible member hashes. The downloaded full evidence bundle includes both model reproduction commands. Source-only downloads also require the frozen inputs in the full bundle.

Run `python browser/qa_companion.py` with the existing local Chromium/Playwright installation. The QA is presentation and control validation, separate from scientific and financial inference. `QA_REPORT.json` binds the result to the exact HTML hash; failed development attempts remain in `QA_ATTEMPTS.jsonl`. Internal `qa/` screenshots/downloads and `__pycache__/` are excluded from publication packages.

The independently audited financial and settlement rows remain **SIMULATION**. Numerical consistency is not empirical business performance, actual revenue, paid demand, current-chain verification, realized liquidity, newly demonstrated capability or self-acceleration. The browser opens no wallet, remote executor, account or network connection. Source links are ordinary user-clicked navigation. Actual financial execution and authenticated approved-executor execution are **NOT RUN**.
