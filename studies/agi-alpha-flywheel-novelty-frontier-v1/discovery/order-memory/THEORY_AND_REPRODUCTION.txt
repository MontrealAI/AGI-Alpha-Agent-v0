ORDER-HISTORY CODING: CONSTRUCTED EXPLORATION WITH A FAILED NOVELTY GATE

Purpose and scope
A possible application is battery-free event-history recording. The executed experiment is only an abstract binary information model. It does not simulate a material, reproduce a force-displacement experiment, establish buyer acceptance, or measure physical cost. The original event-history connection was generated by the research agent; its proposed repair is ordinary parity coding and therefore fails the requested substantive novelty gate.

Model
There are n labeled events, each occurring exactly once. Their history is a permutation pi. For every unordered pair {i,j}, one ideal pairwise memory bit records whether i occurred before j. There are m=n(n-1)/2 such bits. A known erasure replaces a bit by an unknown symbol; this is different from an unmarked wrong bit. All possible histories and erasure locations are included in the tests.

Proposition 1: one-copy pairwise records are vulnerable to one erasure.
Take any two adjacent events i,j in a history and exchange them. Their order relative to every other event remains the same. Exactly their mutual pair bit changes. Erasing that bit makes the two histories indistinguishable. This gives minimum Hamming distance one for the complete pairwise record. More strongly, if a pair is not recorded at all, some histories cannot be distinguished even without damage.

Under uniformly enumerated histories and erased pair positions, an erased pair causes ambiguity precisely when its events are adjacent. There are n-1 adjacent pairs among m pairs. The ambiguous fraction is (n-1)/m = 2/n. Under adversarial erasure, every history has a defeating erasure location. Uniform-case fractions must not be presented as adversarial guarantees.

Proposition 2: the pairwise-copy class needs at least 2m bits for arbitrary one-erasure recovery.
Every unordered pair can occur adjacently in a history. If any pair is represented fewer than twice, erase its only stored copy and use the adjacent-swap witness from Proposition 1. Thus every pair needs two copies. Two independent copies of every pair suffice for the specified known-erasure model. This lower bound concerns architectures storing only individual pairwise comparisons, with no extra side channel or encoding. It is not a bound on arbitrary digital codes or all physical materials.

Proposition 3: one conventional parity bit suffices in the abstract encoded model.
Append p = XOR(b_1,...,b_m). If one data bit is erased, it is determined by p and all remaining bits. If p is erased, all data bits remain. Therefore m+1 stored bits suffice. Ordinary parity is prior art; this proof is not claimed as a new code, theorem of coding theory, or new material capability.

One parity detects every single unmarked bit substitution when no erasures are present, because total parity changes. It cannot generally correct a substitution: for adjacent histories, the two codewords differ in their mutual-comparison bit and the appended parity bit. A received vector halfway between them is one bit away from either history. Two known erasures can likewise defeat recovery; all such cases in the chosen finite instances are retained in the results.

Physical cost boundary
An abstract appended parity bit is not a demonstrated passive mechanical recorder. A physical implementation may require extra gates, couplings, ancillas, energy, signal routing, manufacturing tolerances and readout burden. The comparison m+1 versus 2m counts abstract stored bits only. It cannot be used as a bill of materials, a device-price estimate, a claim of net energy saving or an equal-resource mechanical comparison. Identified general hysteron synthesis and existing mechanical logic are the relevant stronger controls. A useful eventual implementation could have ordinary engineering or commercial value even while novelty fails.

Implemented validation
mechanical_memory_probe.py exhaustively checks four events and independent precedence/inversion-parity recovery. A four-edge cycle has 14 distinct orientation readouts across 24 histories; the complete six-edge pairwise record has 24. This is an abstract graph statement, not an asserted correction of the cited full physical experiment.

order_transfer_study.py and transfer_frozen_config.json were written and frozen by a recorded source hash before enumerating the new sizes n=5 and n=6. The general theorem and n=4 exploratory results were already known. These are fresh-size implementation checks of a known construction, not blind discovery trials, historical replay, unexpected scientific predictions, or model-versus-human comparisons. The configuration records this boundary explicitly. No randomness is used; a random seed is inapplicable.

The independent recovery oracle generates orders consistent with observed precedence constraints and checks parity using inversion counting. It does not call the encoder. A separate ordinary-library repair reconstructs the erased bit with XOR before precedence decoding. Both agree on every one-erasure case. Technical reuse therefore transfers, while superiority over an identical-information library is zero in this comparison. Operational Alpha is unmeasured.

Results
n=4: bare pairwise 72/144 one-erasure cases uniquely recover; parity 168/168.
n=5: bare pairwise 720/1,200; parity 1,320/1,320. Parity leaves 1,560/6,600 two-erasure cases ambiguous. All 1,320 single-bit substitutions detected.
n=6: bare pairwise 7,200/10,800; parity 11,520/11,520. Parity leaves 13,680/86,400 two-erasure cases ambiguous. All 11,520 single-bit substitutions detected.
Each parity system includes an additional eraseable parity position; denominators reflect all positions in that system. These are exact finite fractions, so confidence intervals for a sampled population would be inappropriate. Generalization outside this model remains unmeasured.

Reproduction (Python standard library only)
python3 mechanical_memory_probe.py
python3 order_transfer_study.py --config transfer_frozen_config.json --output-dir transfer_validation
The source hash must match the frozen configuration. Outputs include summary JSON, every enumerated new-size erasure case in deterministic gzip JSONL, and a hash of the uncompressed case stream. Wall-clock timing is a local measurement and naturally changes across reproductions.
