# Proposed prospective discovery comparison

**Status: specified for a future run; not executed in this edition.** No result in the paper is attributed to this
protocol. The current search was adaptive and retrospective. It had no matched ordinary-user or human-expert arm, so
it cannot estimate a discovery advantage or support beyond-human foresight.

## Freeze before starting

An independent coordinator should prepare an initial packet describing broad consequential needs, available resources,
legal/physical constraints and a dated technical frontier. Exclude this paper's intended opportunity, its counterexamples,
its candidate list and any later outcomes. Hash and timestamp the packet, allowed source snapshot, evaluation rubric,
model identifiers, tool permissions, inference settings, per-arm budgets and termination rule before any arm begins.
Do not use this paper as a hidden target and then infer discovery from rediscovering it.

Use three independently assigned arms: U, representative ordinary use of the same frontier model; E, expert AGI ALPHA
operation with grounding, decomposition, alternative formulations and adversarial verification; H, appropriately scoped
human specialists if available. If people are unavailable, an explicit model or analyst proxy must be reported as a
proxy and must not be named a measured human baseline. A trained specialist E+ is a later test on new work, not part
of selecting the first opportunity.

## Concrete budget proposal

The coordinator may amend these values **before** freezing them. This is a bounded starting design, not a power claim.

| Resource | U and E, each |
|---|---|
| Model | One identical exact official model ID and access tier, recorded at execution |
| Inference | Maximum 200,000 input and 40,000 output tokens; all retries charged |
| Sources | Same dated corpus and at most 40 external queries / 20 full-text opens |
| Compute | 60 CPU minutes, 2 GB written outputs, no paid external execution |
| Search wall time | Three hours |
| Candidates | At most seven serious candidates; early rejected probes retained |
| Construction | One selected candidate, maximum eight hours and $500 marginal paid resources |
| Authority | Read-only public sources and local experiments; no production actions |

U receives a competent ordinary prompt, a realistic opportunity to ask questions and the same accessible information;
it must not be deliberately crippled. E receives the expert operating procedure. If arm outputs differ in token usage,
report both achieved quality and actual complete cost rather than pretending equal realized spend. H receives the same
purpose and source boundary; model its relevant compensation and resource costs separately instead of treating
equal wall time as equal economic cost.

## Independent scoring and decisive tests

Before seeing arm labels, reviewers assess four separate dimensions: substantive novelty against the strongest located
prior art, useful beneficiary outcome, technical feasibility, and commercial plausibility. Each requires cited evidence
and an explicit disconfirming condition. Do not collapse agreement among related models into proof. Include a domain
reviewer where available, a source-checking reviewer and a reviewer instructed to search for a conventional equivalent.

Use construction acceptance as the decisive gate. Keep the original useful purpose and its difficult cases. A candidate
does not qualify because reviewers liked its narrative, because the other arm did not mention it, or because it used
the AGI ALPHA vocabulary. Missing candidates in a small sample say nothing about what all humans could conceive.

Allow multiple arms to find the same opportunity. Record first-discovery time, source access, hypothesis revisions,
failure recovery, accepted output and total costs. Score counterexample detection positively without relabeling it as a
productive breakthrough. An unselected study remains a valid outcome.

## Confirmation and uncertainty

Freeze a selected construction and commercial policy before fresh tasks, data or simulations. Keep exploratory tuning
separate. Use paired tasks and common random numbers where meaningful; include all failures. Report exact counts for
exhaustive finite populations and intervals only for sampled outcomes with the sampling process stated. Repeat across
independently specified opportunity packets before making a general search-superiority claim.

Historical replay, if later used, requires a verifiable information cutoff, source-version restrictions, contamination
checks and documented exclusion of outcome-bearing material. A current model may retain later knowledge; without a
credible leakage control, call the exercise retrospective reconstruction. No replay is included here.

## Retention and successor gate

After profitable or otherwise justified originating work, compare E+ against E and an ordinary library containing
identical information on new recipient missions. Keep extraction, validation, sharing, invocation and maintenance in
bucket B, excluding learning already charged once to bucket A. Optional Gym investment belongs to C. Include a
no-benefit outcome. Record rights, scope, version, dependencies and authority separately. Adopt only when incremental
value exceeds extra cost under credible demand.
