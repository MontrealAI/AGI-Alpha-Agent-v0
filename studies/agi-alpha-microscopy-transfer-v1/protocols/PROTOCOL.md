# Microscopy transfer: prospective study protocol

Edition: 1.0.0. Declared 2026-10-27, before implementation and confirmation.
Source base: 47c17f6aca6b1bb8779dd3e47d5ba5f8af3329f4.

## Opportunity and original purpose

Deliver source-qualified quantitative measurements of existing segmented objects when a research
image is reused in a different physical coordinate frame. The original useful purpose is the count
of supplied nonzero label IDs, the measure of their supplied voxel support in native physical space,
the geometric measure after an explicitly declared affine map, and their native/mapped centroids.
Segmentation validity, complete-cell identity, registration correctness, clinical inference and
intensity-based biological conclusions are outside this contract.

The instrumental restriction under test is mandatory rasterization onto a common target grid before
answering these queries. The replacement is to compute source moments once and push the requested
quantities through the declared affine map. This is established mathematics, not a new algorithm.
The contribution is a reusable scoped instrument, observed transfer, an inspectable purpose-preserving
witness, and conditional delivery/retention economics.

## Comparisons and falsifiers

1. Constructed instrument versus independent conventional physical-space computation using standard
   NumPy/SciPy facilities. Both receive identical arrays, transforms, requirements and permissions.
2. Common-grid nearest-neighbor label resampling is a diagnostic alternative, not a proxy for ordinary
   use of a frontier model. It may change measured support or lose small labels. These defects do not
   imply that competent image analysts are unable to avoid them.
3. A separate recipient executes the exact frozen module on an independently selected second study.
   An ordinary directory with the same module bytes and rights is an equal-content library control.
4. H is equivalent formatted image-analysis service with sourced rates and assumed hours. U, E, E+
   are separately identified same-model configurations if live hosted trials can be run; absence of
   such trials leaves their quality/cost advantage unmeasured. Deterministic scripts are not U/E.

The technical hypothesis fails if any accepted result violates the original quantity definition,
label identity, units, direction of transform, scope, source-byte binding or numerical tolerance.
Numerical acceptance: relative measure error <=1e-9 and centroid max absolute error <=1e-8 micrometers
against the independent finite reference; label-ID set must be exact. Invalid, unsupported or ambiguous
missions must return HOLD/REJECT with a reason, not substitute an easier request.

If competent conventional code meets the same contract, report useful construction and conditional
economic improvement, not uniquely enabled work or a frontier-model superiority claim. No graph
premium is claimed if identical-content library access ties. Failure of a candidate or economic
admission does not erase useful delivery or prevent a properly labeled research-only transfer.

## Development and confirmation

Develop only on IDR0062A image 6001240 plus authored analytic fixtures. A different IDR study and
timepoint is selected by a separate curator before outcome inspection and remains uninspected by
the instrument author until source, method and acceptance commitments have been written.
Confirmation consists of fresh transforms, meaningful adversarial semantics and the held specimen.
The author will not change the frozen instrument in response to confirmation; defects are preserved
and any repair becomes a new prospective version with separately labeled evaluation.
This is independent task curation inside one AI-assisted team, not external scientific validation.

## Evidence and costs

Array/metadata downloads and executable outputs are observed; affine perturbations are authored
experiments; model API prices and service rate pages are sourced; time estimates, customer decisions,
prices, demand, failure/default risks and collections are assumed/simulated. Runtime elapsed times
are machine observations, not human labor or model billing. No actual customer collection exists.
Unknown complete authoring/model costs remain unknown in the actual native ledger.

Separate A paid-outcome delivery, B additional retention/admission/sharing/upkeep and C optional
research. Research is not recast as customer-funded. Model H/U/E/E+ with zero and negative transfer
benefit, voluntary participation, refunds/default, common failure, liquidity, upfront reserves and
justified stop. Freeze economic policy before fresh seeded worlds. Simulated intervals reflect the
chosen assumptions only. Hold enterprise resources constant across policy arms.

## Boundaries and publication

Use existing Journal, trust, lifecycle and A/B/C accounting with explicitly fictional identities.
New microscopy scope is not admitted to the protected production capsule scope. No live ENS,
wallet/settlement, paid API or production publication occurs without the existing authorized process.
Add isolated study files only; preserve prior papers, source histories, active owners and publisher.
Publish a complete reviewable draft and canonical-publication handoff, with exact-source verification.
