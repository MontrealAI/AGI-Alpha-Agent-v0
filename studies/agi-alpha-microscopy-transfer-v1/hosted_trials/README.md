# Proportionate same-model U / E / E+ trial

Three separate hosted workers received the same twelve authored input contracts, numerical quality
requirements, Python/tool access, and a ceiling of ten tool invocations and ten minutes. They used the
same inherited frontier runtime without model overrides. A pretrial commitment records the actual
task/input and workflow hashes. These are constructed small tasks, distinct from the 48-map public-data
confirmation suite; eight require numerical delivery and four appropriate refusal.

| Arm | Information available | Accepted |
|---|---|---:|
| U | Complete ordinary request and all required data/definitions | 12/12 |
| E | Same request plus the concise frozen expert verification workflow | 12/12 |
| E+ | E inputs plus the exact recovered retained executable | 12/12 |

Ordinary use was not deliberately deprived of tools, mathematical definitions, acceptance conditions
or the permission to verify. Each arm used four underlying tool calls (eight when orchestration
wrappers are counted). Workers were instructed to read only their own supplied task/output material;
they were separate contexts within the same research team and shared workspace, not independent
external evaluators or cryptographically isolated processes. No cross-arm leakage was observed, but
strong external isolation was not established.

The common scorer was applied by the root investigator to saved answers after all trials completed.
It uses an all-voxel mathematical reference, finite-value checks, exact label/count checks, native and
mapped quantities, and the same refusal conditions. `scoring.json` records every case. The three arms
tie. E versus U and E+ versus E are therefore both zero accepted-outcome gain on this tiny sample.
The trial cannot establish the absence of a benefit on more demanding work.

Full token counts and attributable billing were unavailable. U recorded a wall time; comparable whole
trial clocks for E/E+ were not recorded, so no latency advantage is inferred. No human review minutes
are fabricated. A receipt-generation missing-import correction in U is preserved without changing
its already computed numerical answers. Token/billing absence means unknown, not zero.

Reproduction re-scores these historical saved outputs. It does not rerun the frontier workers or
claim a new independent model trial. No API subscription entitlement or paid provider execution is
inferred from the hosted interface. Refer to `evidence/model_economics_sources.md` for separately
verified official API model identifiers, capabilities and prices.
