## Demonstrated scope

The frozen implementation matched an independently authored internal checker on 24 constructed cases using the exact source catalog and supplied finite task grammar. A distinct recipient agent actually used the same source on dry-context and wet-context/monarch-host work. Ordinary and expert baseline actors also produced correct reports and retained their own scripts. No incremental monetary advantage is established.

Source coverage means facts documented in the selected guide context. Qualified lot coverage means compliance with declared fictional evidence rules. Neither means current inventory, ecological suitability, viable seed, nectar output, habitat restoration, customer acceptance or authority. The input charter and structured requirement mapping are supplied, not autonomously inferred. A mixed-purpose planting beyond the one-resource-mode grammar needs a new contract.

## Known defects beyond the demonstrated corpus

- Omitted required quoted price can default to zero.
- Unsupported nonempty host strings are accepted by the frozen compiler.
- Missing catalog source traceability is not generally rejected.
- An empty lot identifier is not emitted in the required canonical form.
- A missing catalog nectar key can raise an uncaught exception.
- Numeric and list bounds do not completely match the broader independent protocol.

These defects are preserved. Do not infer general validity from a returned report or treat the current implementation as a production validator. A corrected version must receive a new identity and prospective acceptance. A caller must independently qualify its exact inputs and mission meaning; this record does not grant authority.

```bash

```
