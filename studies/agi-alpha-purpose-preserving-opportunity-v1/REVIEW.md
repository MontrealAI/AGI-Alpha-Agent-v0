# Internal independent review

Date: 27 October 2026. Reviewer: a separate same-session AI research agent, after all primary
workflow outputs were frozen. This is an internal review, not external peer review, a customer
trial, an ecological certification, or a repeat experiment by an independent institution.

## Disposition

The study can support a carefully scoped research edition with a **negative commercial and
additional-Alpha finding**. It does not establish the requested stronger chain of valuable
newly feasible ecological work, customer acceptance, complete observed economics, and profitable
retention. Its useful contribution is an inspectable documentary instrument, real execution and
transfer, fair strong-baseline comparison, explicit accounting, and a justified stop.

The 24/24 frozen-corpus correctness result and 72/72 saved workflow-output grades reproduced.
They are finite fixture results. Five additional post-trial diagnostic cases expose broader
contract failures, so general schema compliance and production admission must be withheld.
These diagnostics do not rewrite the predeclared confirmation score. Both results belong in the
abstract/results narrative and the qualification record.

## P1: General contract compliance is not established

`review/diagnostics.json` preserves each complete mutated task and catalog, the independent
oracle's expected report, the frozen compiler's actual report or exception, and the mismatch.
These are deliberately selected post-confirmation diagnostics, not protected fresh confirmation.

| Diagnostic | Observed frozen v1 behavior | Required interpretation |
| --- | --- | --- |
| Required `quoted_price_cents` omitted | Defaults to zero and can pass; oracle classifies malformed input | Required-field validation incomplete |
| Unsupported `required_host="swallowtail"` | Accepts the host value and returns an unmet obligation; oracle rejects the input | Supported host grammar differs |
| Catalog taxon `source` omitted | Can return a positive screen without the required source; oracle rejects the catalog | Source traceability is not generally enforced |
| Empty-string row `lot_id` | Blocker stores `""`; contract requires null | Canonical output mismatch |
| Catalog `nectar` key omitted in nectar mode | Uncaught `KeyError('nectar')`; oracle treats missing evidence as unknown | Robust missing-field handling absent |

The distributed source-derived catalog has the relevant fields, and the protected packets do not
contain these five mutations. Consequently the published fixed-corpus result remains accurate,
but “all valid inputs,” “full contract compliance,” “production-ready,” or equivalent claims
would be false. Production admission requires a new version with explicit schema validation,
fresh prospective acceptance, and a policy for unrepresented mission requirements. The frozen
core and its original SHA were not changed during review.

The compiler also declares bounded lengths, counts and numeric magnitudes not all expressed in
the independent protocol. Its manifest should be read together with these implementation bounds
and this review. Fixed source evidence and a finite task grammar, not arbitrary botanical or
procurement inputs, define the demonstrated scope.

## P1 resolved: Replay originally failed to verify confirmation bytes

The first replay script checked the method freeze but merely read the confirmation manifest. It
would have recomputed answers for changed packet bytes without detecting that the frozen cases
had changed. This was a reproducibility defect, not evidence that the actual stored packets were
modified.

At the parent's request, the unfrozen `reproduce.py` was hardened after primary results. It now:

- Verifies the confirmation-to-method manifest SHA link and all method and confirmation file
  hashes and byte lengths before running the experiments.
- Verifies the frozen catalog and oracle commitments, the distributed catalog's equality, and
  exact packet membership and counts.
- Recomputes the independent oracle's reports and requires exact equality with the frozen
  expected reports before grading the compiler.
- Verifies the saved workflow evidence manifest and identical frozen inputs, including the exact
  E+ retained compiler bytes, then regrades all 72 saved reports.
- Explicitly states that saved-output regrading does not rerun or retime frontier model agents.

`review/replay_validation.json` records seven rejected corruption attempts in temporary copies,
a successful relocated standard-library replay from an unrelated working directory, a successful
in-repository native replay, 18/18 native checks, and byte-identical economic report reproduction.
Ruff lint/format and strict mypy passed for the hardened replay. No frozen method, case, answer,
workflow output or economic result was edited. The earlier replay remains an earlier execution
record rather than retroactive proof that its script performed these stronger checks.

## P2: The workflow result demonstrates parity, not robust added Alpha

All three agent configurations produce 12/12 correct reports in each round. U and E may construct
and retain their own scripts, as required for a competent comparison. U's elapsed trace is
competitive with or faster than the expert conditions. One same-session actor per condition and
two task sets do not establish a population-level Operational Alpha effect, a frontier provider
benchmark, or a causal learned advantage.

The actual frozen artifact is reused on a different wet-context mission with a monarch host and
changed provenance. This supports an executable-transfer statement. It does not establish that
retention beats the recipient's available conventional workflow after acquisition, adaptation,
serving and maintenance costs. The ordinary-library identical-content control ties, so there is
no observed graph-specific capability benefit.

Elapsed times are recorded command-to-verification intervals. Provider tokens, billing, model
response IDs, actual recipient effort, full acquisition costs and production service latency are
not observed. Wall-clock seconds must not be multiplied by an assumed hourly labor rate or used
as a matched-dollar-budget comparison. H is an estimated reference, not an executed human trial.

## P2: The economics is a conditional accounting control

The arithmetic correctly separates refundable deposits, earned revenue, receivables, defaults,
refunds, owner capital and operating reserves. Work required for the hypothetical paid outcome,
including its learning subset and shared construction, enters A. Additional retention enters B;
optional development enters C. No second cash payment is invented when an uncollected receivable
is written off.

However, H/U/E/E+ each receive the same assumed three labor hours. The selected price, world
weights, effort, costs, willingness to pay and outside option are not calibrated observations.
The null-control note appropriately withdraws any implication that these are realistic mandatory
human-review minutes or an empirically optimized commercial offer. Publish the USD 400 result as
an accounting illustration, not a market price or viable operating recommendation.

Actual sales and collections are zero; complete research cost, profit and available funds remain
unknown. The accounting simulator cannot fill that evidentiary gap. The two-buyer technical and
coordination combinations assume their enabling states; they do not discover customers, qualified
biological methods or a coalition. The conventional expert's equality is stipulated by equal
information, not a separately measured field result.

The offer selector maximizes assumed contribution and then checks liquidity. It is not a general
joint constrained optimizer that searches again for the best feasible alternative after a
liquidity failure. This does not change the stored example's stop, but the script should not be
marketed as a general pricing/financing optimizer. The reserve policy and complete world list
are assumptions, not proof against unmodeled risk.

## P2: Purpose and biological evidence remain bounded

Researchers supply the original charter, machine-readable requirement mapping, catalog and lot
facts. Retaining the prose verbatim does not prove that all meaning has been extracted. The
information-loss witness is a concrete implementation of a known issue, not autonomous discovery
or a new theorem. Source flowering intervals and guide planting contexts are not nectar output,
site suitability, current availability, viable seed, survival or restoration success.

The pre-confirmation scope addendum distinguishes the mesic development example, fresh dry packet
A and fresh wet packet B. It also discloses the all-rows resource-mode rule. A mixed-role planting
with separate nectar, pollen and host plants needs a new task contract; declining the current
nectar claim cannot be presented as evidence that those species produce no nectar.

## P3: Native boundaries are useful but do not confer live authority

The native adapter executes existing repository interfaces and enforces the tested signature,
scope, mission, replay, expiry and revocation boundaries. Its supported invocation inspects source
bytes. Fictional ENS associations and temporary local signers do not authenticate live agents or
authorize production ecology. The unsupported ecological capsule is correctly refused. Admission
and scientific acceptance must remain separate even when an artifact's identity is stable.

## Publication recommendation

Publish as an additive, reviewable research edition preserving all negative findings and original
freezes. Make the successful finite-corpus transfer, equally successful baselines, additional
post-trial defects, unknown complete actual cost, zero customers and stop decision visible near
the front. Retain the artifact for reproducibility and bounded investigation; do not count it as
economically admitted Alpha, claim specialist ASI, or activate a production shared service from
this evidence. A corrected general-purpose release must earn fresh acceptance prospectively.
