## Economics without invented cash

The original 224 evaluations form an **uncalibrated null-cost control**. Equal three-hour allocations are not measured or realistic automated-delivery costs or mandatory human review. H is an estimated three-hour, USD 100/hour equivalent service, not a market quotation. All prices, buyer values, effort, probabilities and funding inputs are assumptions.

The control separates A complete delivery, B additional retention and C optional development. Required job learning and shared construction enter A once. It preserves deposits, liabilities, revenue, collections, defaults, refunds, obligations and reserves separately. It demonstrates an E+ stop and a physical-construction stop under its inputs. Read [the interpretation correction](economics/NULL_CONTROL_NOTE.md) before using any number.

Review found that the original selector ranked contribution before checking liquidity. The separate [corrected policy](economics/feasible_policy.py) filters complete alternatives for readiness, acceptance, positive contribution and every cash prefix before ranking. Source and contract were frozen before six fresh diagnostic sets. The rule can admit affordable worthwhile retention and later select a better conventional alternative. Its attestation fields are declarations, not authenticated customers or verified demand; it grants no authority and establishes no actual profit.

The separate retention boundary uses assumed fixed cost USD 100 and USD 2 serving per reuse. At 25 qualifying uses, gross incremental benefit must exceed USD 6 per use. No measured benefit or demand supports economic admission. The asset is retained for research, and further speculative investment is stopped.

## Reproduce the evidence

Python 3.11–3.13 is recommended. Core confirmation, saved-output grading, economics and policy diagnostics need only the standard library. Run from this directory and choose a new output path outside it:

```bash
python3 reproduce.py --output /tmp/alpha-replay-new
```

The script verifies linked freezes and immutable bytes, recomputes fixed expected answers, grades all 24 compiler reports and all 72 saved workflow reports, copies the compiler into an ordinary library, replays the original accounting and runs the separately frozen policy cases. It refuses to overwrite an existing output directory. Regrading saved workflow files does not rerun model agents or reproduce their timing.

For the native adapter, place this directory under `studies/` in the exact pinned parent repository, install its required dependencies, then run:

```bash

```

The adapter imports real existing interfaces but uses temporary local signing fixtures. Its supported invocation inspects source bytes. It does not execute a newly admitted ecological capsule, authenticate live ENS agents, touch wallets or settle Jobs. Unsupported production admission is correctly refused.
