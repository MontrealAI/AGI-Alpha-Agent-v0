# Preserved workflow observations

Three fresh same-session actors received identical source facts, the complete acceptance contract and the same tools. Their initial instructions differed only in the declared U/E/E+ workflow condition and, for E+, access to the frozen compiler. All actors could program, check their work and retain their own round-A artifacts for B. They received no external scores or correction feedback before B. This is a within-session exploratory assay, not a representative sample of ordinary users.

Every file copied here retains its original bytes. Python scripts use a `.py.txt` archival extension to preserve the raw experiment without treating those scripts as production package code. `MANIFEST.json` binds original names, byte counts and hashes. Some raw scripts contain the trial's original absolute working-directory paths; replay of saved reports is portable through `../reproduce.py`. The frozen artifact itself is portable independently.

`../WORKFLOW_PROTOCOL.json` is the pre-output method record. The exact acceptance contract and scope addendum are preserved in every arm. Each arm's `TASK_MESSAGES.md` archives the exact A/B assignments from its available conversation context. `PROMPTS.md` is a shorter reconstructed summary, not a provider API request log. Provider request IDs, token bills and instruction-dispatch timings were not exposed. Actor receipts preserve first-command timing, tool operations, retries, verification and limitations.

The independent checker accepted all 72 saved reports. An accepted report may correctly reject malformed input or report unmet obligations; it is not a positive purchase approval, a restored habitat, customer acceptance or paid revenue. All 24 task identities are reused across the three conditions and are not 72 independent tasks.

Implementation work in these archival files is researcher-created and carries the repository's Apache-2.0 license. No protected answers were supplied to actors. Protected evaluation files are disclosed separately for post-study reproduction and are excluded from the capability distribution. Procedural filesystem isolation was used; it is not a security boundary.
