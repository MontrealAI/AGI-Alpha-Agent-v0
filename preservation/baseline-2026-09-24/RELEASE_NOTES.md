## Verification scope and known baseline status

Publication checks exact source hashes, original branch heads, Git object
integrity and a fresh restoration of the complete history. The publisher also
compares every uploaded asset's SHA-256 and size before exposing the release.
These are preservation checks, not application or production qualification.

The baseline's [PR CI passed](https://github.com/MontrealAI/AGI-Alpha-Agent-v0/actions/runs/25188568601).
Its [full Integration CI failed](https://github.com/MontrealAI/AGI-Alpha-Agent-v0/actions/runs/25188568593)
in Python tests, pre-commit checks and documentation checks; the CI watchdog
continues to report that integration failure. These existing conditions are
recorded without changing the source or claiming they have been repaired.

### Breaking changes

None. This is a named archival checkpoint; original package/component version
labels and behavior are preserved. It does not certify existing aspirational
claims or indicate that the full project is complete.

The preservation tooling is additive and lives on a separate publication
branch. `main` and all original branches remain at their captured commits.
GitHub discussions/settings, secrets, running deployments, external downloads
and resources hosted outside Git are outside this source/history archive.
