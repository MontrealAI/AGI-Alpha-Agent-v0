# Source-evidence scope

The upstream-source-audit directory preserves the public source snapshots inspected before experiment design. The initial Alpha audit retains its original source pin and historical coordination boundary; later main-branch changes are documented in source-audit.json. The literature-design-notes file records early primary-source support and candidate design considerations. It is not the final executed protocol; protocol.json, amendments, source freezes and retained run records determine what actually ran.
