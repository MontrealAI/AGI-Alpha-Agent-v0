**Reproduce from a repository checkout.** Python 3.11–3.13 is required; this experiment used 3.12.14.
Install the repository's supported dependency set through its existing instructions. MPyC 0.11 is already bundled
in the separately pinned research source; no paid API, wallet or live identity is required.

Obtain the unchanged research dependency in a separate checkout/worktree at commit
`66adcbcf4978ae985c7a023232125e566752d516`. Set `RESERVE_RESEARCH` to that checkout's
`studies/agi-alpha-opportunity-construction-v1` directory. Run from this engineering checkout's root:

```sh
python scripts/check_python_deps.py
python check_env.py --auto-install
python -B -m pytest contrib/reserve_output_boundary/test_boundary.py -q

```

Choose unused output paths and unused loopback ports. Never overwrite the retained evidence. Exact source hashes are
checked before fresh execution; changing code requires a new protocol/freeze and new unused confirmation seeds.
Replaying the existing seeds is reproduction, not a further prospective result. Process IDs, keys, nonces, transport
telemetry and elapsed times are expected to differ. Scientific bits, decisions, financial scenarios and source bindings
are the meaningful comparison fields.

`audit.py` operates only on explicitly public synthetic hypotheses. It never receives live private inventory.
It checks the entire output vector and the declared observer side information, including every possible output fiber.
It refuses a whole batch if any possible answer has fewer than two distinct secret alternatives. A refusal is therefore
not selected using the actual secret. The hypothesis domain and observer knowledge remain supplied assumptions.
Two alternatives do not imply differential privacy, absence of partial disclosure, or equal posterior probability.

The separate permutation oracle checks the useful feasibility predicate; a separately implemented relational checker
checks the disclosure result. Both were written in this engineering session. They are algorithmic controls, not
organizationally independent validation. Identical-information ordinary reuse ties the preflight.

The existing one-use grant remains independently necessary and cannot be created by importing an assessment.
Native grant/cost journals contain local private fixture state: keep them private. Only public receipts are included
here. Existing full-state rollback limitations remain unchanged. No model is asked to inspect private owner inputs.

There is no new production endpoint, catalog, history store, release, frontend build, ENS authority or payment path.
Integration requires the existing engineering/research owners, final-source review and the repository's full release
gates. No canonical Pages publication or live served-byte acceptance is claimed. Rollback is removal of this additive
directory; the pinned upstream source and existing flagship remain untouched.
