# Invention automation: executable continuation

The purpose is to discover and construct a means that changes a consequential
business's feasibility. This contribution implements a necessary bounded repair
mechanism. It does **not** establish a profitable business or a compounding
invention machine. Preserve the stronger conventional defaults.

The legacy `invention qualify`, `qualify-resume` and `qualify-reproduce`
commands, and their direct orchestration APIs, now fail closed. Their original
protocol authenticated a quantity anywhere in an excerpt without binding it to
the claimed source field and span. Historical schemas, static proof helpers and
original artifacts remain available as unqualified evidence. Current source
admission uses `invention critic-loop` with an explicit `--context` and a freshly
frozen critic verifier; `critic-resume` accepts only that protocol's checkpoints.
Old freezes and checkpoints cannot be silently upgraded to the new protocol.

The implementation is in
`alpha_factory_v1/core/runtime/invention_automation/`. It is registered on the
actual `alpha-agent` command surface, alongside the recovered transfer and
discovery commands. The existing protected exchange supplies custody, inspection,
encrypted delivery, settlement, refunds and conservative investment protection.
There is no replacement settlement engine and no real payment route.

The new typed strategy representation composes measurement, conditional guards,
funding, production, independent inspection and settlement. Its expressions
check currency/boolean types, observation availability and bounds. Generated
strategies cannot select Python, shell, network, file paths, wallets or hardware.
Two installed adaptation families rewrite execution order and synthesize cash
guards from reproduced technical/economic witnesses. This is a bounded grammar
extension, not general open-ended scientific invention or global novelty.

From the repository root, in the tested editable environment:

```sh
alpha-agent invention run contrib/invention_automation/example-request.json --output /tmp/invention-example-NEW
alpha-agent invention repair contrib/invention_automation/example-request.json --witness studies/invention-automation-20261029/results/component-pilot-v2/technical-witness.json --output /tmp/invention-repair-NEW
alpha-agent invention run /tmp/invention-repair-NEW/revised-request.json --output /tmp/invention-corrected-NEW
python contrib/invention_automation/run_study.py --output /tmp/invention-pilot-NEW
python -B -m contrib.invention_automation.verify --root . --run /tmp/invention-pilot-NEW
```

Every output path must be new. Incomplete and failed outputs are retained;
automatic retry with a reset allowance is not supported. The separate verifier
uses a Linux libseccomp filter to deny write opens, filesystem mutations, new
sockets and exec. It reads SQL with `mode=ro`. Its code is frozen before each
panel, and it never imports the candidate interpreter. Shared author, host and
assumptions limit independence to procedural separation. It is not external
certification or a general hostile-native-code sandbox.

python -m pytest -o addopts='' contrib/invention_automation -q

The four historical education offices share provenance. They are not admitted
commercial customers, and their apparent load differences are not identified
treatment effects. The screening model is not the full OpenDSM/CalTRACK method.
The original position-alignment defect and its correction remain in study
history; pooled residuals now require common complete calendar weeks.

Installation was actually exercised using `pip install --no-deps --no-build-isolation
-e .` and the existing `alpha-agent` executable from outside the repository.
Use the project's supported dependency profile; the exact observed development
environment is recorded in the study. The broad setup's optional fallback added
unneeded dependencies; disposable browser files and bytecode were reclaimed.
Full repository CI, hosted release qualification and physical-business validation
were not run or claimed. Do not repeat an unbounded full install in this resource
envelope. No dependencies, wallets, providers or grants are provisioned by a
strategy file.

The component pilot ties its competent component reference in all fourteen
paired fault cases. This does not compare a completed energy service against the
strongest commercial workflow. Candidate corrections cannot establish that
missing comparison. No fixture margin is reinvestable operating-business money.
