# Operate the fixed Strategy Succession candidate

Use an existing approved Alpha operator home. This program never initializes an
operator, grants a new key, changes security settings, funds work or installs a
daemon. The runtime profile admits only exact public Alpha 1.42.0 source and the
listed fixed worker/transport/UI bytes. A different version or source identity
is unqualified and must receive separate review; changing a label or rebuilding
does not admit it.

## Start useful work

1. Create and activate a separate Python 3.12 virtual environment, then install
   the verified public Alpha wheel and this candidate wheel there. Preserve all
   existing accepted Alpha environments. Check the package/profile identities.
2. Launch `strategy-succession-engineering --home /absolute/path/to/existing-approved-home`.
   The server binds only `127.0.0.1`, uses the existing token and disables access
   logging. Add `--native` only within an explicitly approved local solver scope.
3. Open `http://127.0.0.1:8768`. Enter the existing operator token using your
   approved credential-access method. The page clears the input after connection
   and keeps the token in memory only. Do not place it in URLs, exports, prompts
   or browser storage.
4. Choose **Start**. The server prepares a fixed plan; preparation performs no
   mission work. Inspect its exact input, executor identity, source hash,
   separate service/improvement caps and expiry. Editing the form does not
   change that prepared plan: choose Start again for different inputs.
5. Approve that exact plan and start it. One bounded worker action executes the
   initial plan, changed requirements and repair. The browser does not trigger
   the phases one by one. Inspect each checked schedule and the method that
   actually supplied it. Keep or export useful results and strategy records.

The supported planning grammar contains 1–18 jobs, bounded durations/crew,
dependencies and a finite calendar. It accepts public or synthetic nonpersonal
data. It produces planning artifacts. It does not inspect arbitrary repositories,
execute imported code, control a general desktop or cause physical work.

The ordinary portfolio remains a valid incumbent. Native deadline/makespan
specialists and the matching repair specialist are available only when the
operator enables their separate allowance. Construction may defer, reject a
candidate or retain the incumbent. Local correctness qualification does not
establish economic value or production authority.

## Budgets and evidence

Service work and improvement work have separate protected accounts. A journey
reserves both caps atomically before the fixed action gateway dispatches it. The
browser cannot select a host path, executable, endpoint, policy, source or cap.
The process admits one active request; request count, lease and expiry are
bounded by the installed profile.

`service_work` and `improvement_work` are declared work units.
`native_calls` counts actual attempted calls. The legacy API field
`native_solve_seconds` records **charged solve allowance seconds**: two seconds
are charged before each fixed two-second native attempt, including failed or
uncertain attempts. It is not measured CPU or elapsed time. The actual solver's
reported timing, wrapper/process wall time, CPU, import/check time and unknown
opaque work remain separate telemetry. Never convert one counter into another
or turn these figures into monetary savings. Human effort, device cost and
monetary cost remain unknown.

The signed Alpha journal records reservations, observed increments, source and
request commitments. Each actually checked phase receipt is committed before
the worker is acknowledged and allowed to proceed. It includes the task,
selected method, result, independent checker output and original receipt hash;
the transport adds source/plan binding and a separate digest. At most three
ordered partial receipts are admitted. Duplicates cannot add another artifact,
repeat cost increments or relabel a prior delivery as another phase.

Known completion commits the result and actual separate counters before the
HTTP reply. A known verification failure is retained as rejected with its costs.
Exported records carry local attribution and empty proof/authority lists.
Self-reported confidence, a signature or a native solver status alone is not
independent correctness proof. Scientific results, engineering checks,
operational permission and production admission remain distinct.

## Pause and Stop

**Pause** fences new work and interrupts active work at its next bounded
checkpoint. **Stop** permanently revokes this installed envelope. The existing
Alpha journal-wide pause also fences preparation, approval, reservation,
checkpoints and completion. Native or other fixed child processes are bounded
and killed on refusal; an in-flight operation can have an uncertain outcome.

Closing or disconnecting the browser does not terminate an already running
local executor. Its one explicitly approved bounded request may continue until
completion, STOP, lease expiry or process failure. The browser is not an
unattended agent. Stopping the local process stops further progress; this
candidate installs no background service or indefinite recurrence.

A retained `running` record is not proof that its process is still active.
Status distinguishes work observed in this executor from **awaiting evidence**,
and separately reports whether the recorded lease is current or expired. A
restarted executor does not guess that the old process completed, disappeared
or is safe to replay.

## Recover an UNKNOWN outcome

Do not interpret a lost response, stale running lease, partial result, process
crash or timeout as safe failure. The full uncertain request reservation remains
charged. Already committed phase receipts survive. They do not authorize the
remaining phases to resume.

1. Reconnect and inspect retained status, the active/expired lease, observed
   counters, partial receipts and export. A completed duplicate returns the
   original committed outcome without executing again.
2. Verify the executor process and any child have stopped. A current active
   lease cannot be reconciled. Inspect the actual target/result; do not infer
   that unobserved work was free or never ran.
3. For an unknown or stale expired running record, use the existing
   `/api/strategy-executor/reconcile` operation with `plan_id`, the exact current
   status `record_digest` and an operator `note` describing what was observed.
   This records a judgment; it grants no proof and refunds no unknown allowance.
4. The reconciled plan remains permanently non-replayable. Further work needs a
   fresh plan and explicit approval within remaining protected capacity. A
   stopped envelope cannot be resumed. Obtain a separately reviewed installation
   or policy decision when capacity or authority is unavailable.

Do not replay phase commands manually to bypass this refusal. No automatic
prompt-by-prompt recovery, duplicate delivery retry, grant restoration or
production promotion is implemented.

## Restore and rollback

Use the existing Alpha verified backup procedure for private operator recovery;
keep private backups separate from mission exports. A copied or restored journal
at another home does not inherit this transport's old execution grants: approval
binds the original local home/database incarnation, and the transport refuses a
different incarnation. Historical signed evidence remains inspectable. Fresh
local execution requires an explicit separately reviewed authorization path;
do not clear or rewrite the old signed records.

Keep the last accepted public Alpha release and candidate package intact.
Rollback means stop this candidate, inspect and reconcile uncertain work, then
use the previously accepted installation through its own authorized process.
It does not mean downgrading source under an old live grant, rewriting pins or
erasing rejected/failing histories. This engineering contribution does not clear
any held Harness/bridge or Fleet review, merge or native execution restriction.

## Read the cost record

Construction and service use different protected accounts. The ledger records failed proposals, current checks, retrieval, retained reports and workbench integration. Native calls reserve two solve seconds before each attempt; physical solver/startup/checker wall and CPU measurements stay separate. These allowances are not measured CPU time or money.

The report keeps API acceptance, browser acceptance and crash/recovery attempts separate. A killed request retains its full unknown reservation, even when one checked phase survives. It is not a free failed attempt. No automatic retry is available.

Model inference calls are zero for these fixed algorithms; model-assisted authorship, setup and review effort remain unknown. Python HTTP/journal/cryptographic overhead, whole QA/development cost, hardware and currency totals are not fully measured. Forecast maintenance is a declared assumption, not an incurred saving. No synthetic work-unit reduction is revenue or profit.
