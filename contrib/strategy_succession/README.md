# Strategy Succession engineering candidate

Plan a software release, adapt that project's requirements, then repair its
actual preceding plan while preserving committed work. One explicit approval
starts the three bounded phases. Inspect the selected method, independently
checked schedule, retained strategy records, actual ledger and rejected or
deferred improvements.

This additive candidate uses the public **AGI ALPHA 1.42.0** runtime's signed
journal, action gateway and authenticated local request boundary. It includes the
fixed browser interface, worker, exact scientific source subset, source guards,
licenses and an operator profile. It installs no background service and creates
no credential. Launch requires an **existing approved operator home**.

The candidate version is **0.1.0rc1**. It is intended for the existing Alpha
repository's reviewed `contrib/strategy_succession` lane and a later additive
asset through the existing publisher. A built wheel is not a public software
release or production admission.

## Install and open

Use the independently verified public runtime wheel and this candidate's actual
wheel in a **separate Python 3.12 virtual environment**. Preserve every existing
Alpha installation; do not downgrade a newer accepted runtime. The public runtime download is:

[alpha_factory_v1-1.42.0-py3-none-any.whl](https://github.com/MontrealAI/AGI-Alpha-Agent-v0/releases/download/v1.42.0/alpha_factory_v1-1.42.0-py3-none-any.whl)

Its SHA-256 is
`fff8c6c8a8dbeeebf1f91cc8e9a3fae17113baac93b6ed0d6096ecb59d072554`.
The installation profile also checks the installed Alpha Python source. Do not
assume a PyPI distribution provides these exact public bytes.

```sh
python3.12 -m venv /absolute/path/to/strategy-candidate-env
. /absolute/path/to/strategy-candidate-env/bin/activate
python -m pip install ./alpha_factory_v1-1.42.0-py3-none-any.whl
python -m pip install ./agi_alpha_strategy_succession_engineering-0.1.0rc1-py3-none-any.whl
strategy-succession-engineering --home /absolute/path/to/existing-approved-operator-home
```

Open `http://127.0.0.1:8768`. Enter the existing operator token in the local page;
it stays only in tab memory. Choose **Start**, inspect the fixed input, source,
expiry and separate budgets, then **Approve and start work**. Review the actual
results and use **Keep** or **Export**. **Pause** and **Stop** fence the executor
at its next bounded checkpoint. See [the operator guide](docs/operator.md) before
handling interrupted or uncertain work.

The ordinary fixed portfolio is available without native solver permission.
The separately admitted native specialist requires an explicit operator launch:

```sh
strategy-succession-engineering --home /absolute/path/to/existing-approved-operator-home --native
```

`--native` remains local planning work. It does not enable a desktop, network
agent, live contract route or physical operation. Each attempted native call
charges its fixed solve **allowance** before execution; observed solver, process
wall and CPU measurements remain separate.

## Build and verify the package

The package includes only explicitly listed payloads. Builds fail if the current
worker or installation profile disagrees with source; the build does not rewrite
approval hashes. Private homes, credentials, local environments, caches and
development receipts are excluded.

```sh
python -m pip install setuptools==84.1.0 wheel==0.48.0
SOURCE_DATE_EPOCH=1792800000 python -m pip wheel --no-build-isolation --no-deps . --wheel-dir /absolute/path/to/build-one
SOURCE_DATE_EPOCH=1792800000 python -m pip wheel --no-build-isolation --no-deps . --wheel-dir /absolute/path/to/build-two
```

Compare the two wheel SHA-256 hashes, then install the actual wheel into a
different environment outside the source checkout. Verify every guarded package
file, `--help`, the installation profile and the authenticated local API journey.
`requirements-qualification.txt` pins the complete observed core dependency
closure; it is a version inventory, not a claim that dependency wheel hashes or
every platform have been qualified. The package and public runtime wheel have
their own exact byte identities. Browser acceptance remains a separate check.
